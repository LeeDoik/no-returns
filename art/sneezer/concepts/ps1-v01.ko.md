# 재채기 상자 — PS1 스타일 시안 v0.1

[English](ps1-v01.en.md)

상태: 스타일 비교용 제안. 최종 스타일로 확정하지 않았으며 실제 3D 모델과 게임 적용은 미완료입니다.

[PS1 시안](sneezer-states-ps1-v01.png)은 [병맛 표정 시안 v0.2](sneezer-states-v02.png)를 내장 이미지 생성 도구로 편집한 결과입니다. 평상시·예고·분출의 구도를 유지하면서 각진 형태, 거친 텍스처, 단순한 명암과 픽셀 바람을 적용했습니다. [정확한 생성 프롬프트](generation-ps1-v01.json)를 함께 보관합니다.

육안 검토: 세 표정과 상자 정체성을 유지하며 기존 시안보다 각진 형태와 거친 표면이 읽힙니다. 재채기 상태에 아래쪽 치아가 추가되어 치아 배치는 모델링 시 통일해야 합니다. 실제 PS1 하드웨어 제약, 폴리곤 수 또는 내부 렌더 해상도를 검증한 결과가 아닌 이미지 시안입니다. 코드·맵·씬은 수정하지 않았습니다.
