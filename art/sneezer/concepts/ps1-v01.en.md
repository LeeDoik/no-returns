# Sneezer — PS1 style concept v0.1

[한국어](ps1-v01.ko.md)

Status: proposal for style comparison. The final style is not approved; the actual 3D model and game integration are incomplete.

The [PS1 concept](sneezer-states-ps1-v01.png) edits the [comic expression concept v0.2](sneezer-states-v02.png) with the built-in image generation tool. It retains the idle, warning, and release composition while introducing angular forms, coarse textures, simple shading, and pixelated breath. The [exact generation prompt](generation-ps1-v01.json) is saved alongside it.

Visual review: the three expressions and box identity remain recognizable, with more angular forms and coarser surfaces than the previous concept. The release state adds lower teeth; tooth placement should be unified during modeling. This is an image concept, not a verified demonstration of PS1 hardware limits, polygon counts, or internal rendering resolution. No code, maps, or scenes were modified.
