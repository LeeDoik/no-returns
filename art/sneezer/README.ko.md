# 재채기 상자 — 디자인 시안 v0.2

[English](README.en.md)

상태: 검토용 제안. 최종 디자인, 3D 모델, 게임 적용은 미완료입니다.

## v0.2 — 병맛 표정 수정

[수정 시안](concepts/sneezer-states-v02.png)에 반쯤 감긴 멍한 눈, 드러난 앞니, 재채기 때 구겨지는 상자와 들리는 덮개를 추가했습니다. 사용자 요청에 따라 코믹함을 강화한 제안입니다. 내장 이미지 생성 도구로 v0.1을 편집했으며 [정확한 생성 프롬프트](concepts/generation-v02.json)를 보관했습니다. 육안 검토상 세 상태가 구분되지만 치아 형태는 상태 사이에서 완전히 일치하지 않아 모델 제작 시 통일해야 합니다. 아래는 보존한 v0.1 기록입니다.

[디자인 시안](concepts/sneezer-states-v01.png)은 왼쪽부터 평상시, 재채기 직전, 분출 순간을 보여줍니다. 내장 이미지 생성 도구로 제작했습니다. 정확한 영문 생성 프롬프트는 [생성 기록](concepts/generation-v01.json)에 있습니다.

갈색 골판지 상자, 종이 테이프, 큰 눈과 눈썹, 작은 코를 공통으로 유지했습니다. 재채기 예고는 찡그린 눈과 부푼 볼로, 분출은 열린 입과 옅은 파란 바람으로 표현합니다. 팔과 다리는 없습니다.

육안 검토: 세 상태의 상자와 테이프 배치가 일관되고 표정 차이가 읽힙니다. 시안의 볼과 입은 입체적으로 복잡하므로 실제 게임 모델에서 단순화할 필요가 있습니다. 이미지 우측의 바람 효과는 화면 가장자리에 가깝습니다. 이 이미지는 재질이나 표정 스프라이트로 직접 사용하는 파일이 아닙니다.

다음 단계: 디자인 검토 후 별도 Blender 파일에서 모델과 표정 변형을 제작하고, 실제 게임 카메라 거리에서 가독성을 확인합니다. 다른 세션의 코드·맵·씬은 수정하지 않았습니다.
