# 트레일러 초안 01
[English](README.en.md)

2026-09-17 · TRAILER-DRAFT-01 · 분위기·편집 검토용, 실제 게임 플레이 아님.

[한국어 자막 영상](NO_RETURNS_Trailer_Draft_01_KO.mp4) · [연속 장면 미리보기](contact-sheet.jpg) · [한국어 자막](captions.ko.srt) · [영어 자막](captions.en.srt)

75초, 1280×720, 24fps. Higgsfield Kling 3.0으로 생성한 6초 영상 2개와 기존 시안의 이동 편집, Higgsedit 타이틀·컷 편집으로 구성한다. 영어 임시 음성은 Windows Microsoft Zira이며 한국어 자막을 화면에 표시한다. 음원은 직접 합성한 임시 테마·저음·확인음과 생성 영상의 환경음이다. 최종 성우·음악과 실제 게임 촬영은 포함하지 않는다.

## 구성과 출처

- 00–03 채용 광고 타이틀, 03–08 외부 시안, 08–13 생필품 회사 카드.
- 13–18 도착 시안, 18–24 생성된 배송 이동, 24–28 1인칭 운반 시안.
- 28–33 안정된 억제장치 시안, 33–39 생성된 외곽 생물 접근.
- 39–45 리스너를 기다리는 동료, 45–48 구조, 48–51 철수 시안.
- 51–58 수령 확인·영수증, 58–62 사용 흔적, 62–67 선내 귀환 시안.
- 67–69 암전·반복 확인음, 69–75 타이틀·태그라인.

생성 영상은 총 12초다. 원안의 지구 기록 필름은 기존 외부 시안과 회사 카드로 대체했다. 협동 유인·구조는 정지 시안으로 표현했으며 실제 상호작용을 입증하지 않는다. 기존 선내 시안과 단말기는 최신 Unity 모델의 정확한 외형이 아니다. 생성된 직원의 화물·동작 연속성에는 차이가 있어 출시용으로 그대로 사용하지 않는다.

[출처·생성 기록](provenance.json)에 원본 경로, 모델, 작업 식별자, 구간을 기록했다. 참조 YouTube 영상·음악은 제작에 사용하지 않았다. 기존 원본 시안은 수정하지 않았다.

## 재편집

1. make-temp-voice.ps1은 임시 영어 음성을 재생성한다. 음성 파일도 보관한다.
2. Python 3와 FFmpeg로 prepare-media.py를 실행하면 원본 시안에서 편집용 크롭·이동 영상을 다시 만든다.
3. Higgsedit 사용 가능한 환경에서 NR_TRAILER_MEDIA를 이 폴더의 절대 경로로 설정하고 higgsedit build edit.jsx를 실행한다. 그림 마스터는 picture.mp4다. 호스팅 환경의 Higgsedit로 제작했으며 로컬 npm 공개 패키지 설치는 확인되지 않았다.
4. python finish.py가 임시 사운드와 한국어 자막을 합쳐 최종 MP4를 만든다. narration.json이 한영 대사·타이밍의 원본이다.

내보낸 영상·원본 생성 클립·임시 음성은 Git LFS로 관리한다. 재생성용 중간 크롭은 원본과 스크립트로 복원한다. 원본·스크립트 전체 ZIP의 외부 업로드는 자동 승인 검토에서 거절되어 수행하지 않았다. 클라우드에서는 영상 결과만 내보냈다.

## 검토 범위

파일 길이·프레임·음성 트랙, 전체 디코딩과 최대 음량을 검사한다. 생성 클립의 1초 간격 프레임과 최종 연속 장면을 직접 확인한다. 사람의 전체 재생·청취, 분위기 평가와 공개용 권리 검토는 별도다. [현재 검증 기록](../../docs/current/trailer-draft.ko.md)을 참고한다.
