# NO RETURNS — 반품 불가

[English](README.en.md)

> 택배가 살아 있습니다. 그래도 배송은 해야죠.

**현재 버전: 배송 신전 플레이테스트 0.9.0 · 2026년 9월 8일**

혼자 또는 2~4명이 살아 있는 택배를 배송하는 Godot 3D 협동 게임입니다. 택배를 제물로 바치는 우스꽝스러운 배송 신전에서 세 계약을 완수하고, 공동 수입으로 장비를 고르며, 동료와 릴레이하고 포장쥐에게 빼앗긴 상자를 회수합니다. Steam Windows 출시가 목표이며 현재는 Blender·Higgsfield 아트를 적용한 개발 빌드입니다.

## 0.9.0 아트 적용

직원·포장쥐·상자·시설 등 모델 13종과 재질을 적용했습니다. 직원의 걷기·운반 자세, 쥐의 발·꼬리, 상자 표정과 뚜껑, 쿠션과 발판이 기존 플레이 상태에 맞춰 움직입니다. [실행·편집 안내와 남은 출시 작업](docs/art/02-release.ko.md).

2026년 9월 9일 사용자가 제공한 GLB에서 41개 뼈와 Tripo 동작 7개를 확인했습니다. Blender에서 운반 3개·공중 2개·던지기 후속 동작을 추가하고 Godot에 적용했습니다. 원본과 편집용 파일을 보존했습니다. [적용 결과와 검증 범위](docs/art/04-animation-integration.ko.md).

## 0.8.0 연결된 배송과 반응 소품

레일을 접수실에서 분류 턱까지 연결했습니다. 접착+점프 상자를 함께 보내거나 재채기로 화물을 넘기고, 분류대 아래 둥지의 쥐를 쫓을 수 있습니다. 맵에는 POP 에어캡·UP 발판·TILT 탑 24개와 재채기에 흩날리는 기존 문서 13곳이 있습니다. 문서 18장이 뭉치로 날아갔다 풀리고 8초 뒤 복구됩니다. [작동 방법과 확인 범위](docs/prototype/08-reactive-delivery.ko.md).

모두 같은 **0.9.0 ZIP / 프로토콜 10**으로 실행하세요. 이전 버전별 기록의 빌드 안내보다 이 안내가 우선합니다.

## 바로 실행

**[NO_RETURNS.exe](build/NO_RETURNS_0.7/NO_RETURNS.exe)를 두 번 클릭 → 혼자 캠페인 시작.** 이전 창은 닫아 주세요. 에디터 없이 실행됩니다. 친구에게는 [Windows ZIP](build/NO_RETURNS_0.7_Windows.zip)을 전달하고 전체 압축을 풀어 사용하세요.

개발 프로젝트에서는 [PLAY.cmd](PLAY.cmd), 같은 PC의 두 창은 [PLAY_TWO.cmd](PLAY_TWO.cmd), 네 창은 [PLAY_FOUR.cmd](PLAY_FOUR.cmd)를 실행합니다. 한 명이 협동 캠페인 방을 만들고 나머지는 주소를 입력해 참가한 다음 방장이 시작합니다. 같은 PC 주소는 `127.0.0.1`입니다. [EDIT.cmd](EDIT.cmd)는 에디터를 엽니다.

## 0.7에서 달라진 것

- 계약 3개를 순서대로 완수하는 한 판. 계약당 기본 240초이며 인원과 단계에 따라 목표가 늘어납니다.
- 정상 배송 10, 릴레이 추가 5, 계약 성공 20크레딧. 공동 금고로 작업화·시간 연장·경적을 구매하고 전원 준비 후 다음 계약으로 이동합니다.
- 다른 직원이 3초 안에 3m 이상 떨어진 공중에서 받는 릴레이. 잘못된 배송·반복 집기·자기 받기의 추가 보상을 막았습니다.
- 계약 2~3에서 화물을 훔치는 포장쥐. 예고를 보고 대응하거나 R 경적으로 쫓고, 둥지에서 상자를 회수합니다.
- 단계별 조작 안내, H 도움말, 계약·금고·준비·장비 결과 화면, 한·영 UI, 음량·시야각·전체 화면과 로컬 완주 기록.
- 버전이 다른 손님의 입장을 막고 캠페인·크리쳐 정보를 별도로 동기화합니다. 방장이 규칙과 보상을 판정합니다.

기존 32×36m 야간 물류센터, 양쪽 우회로, 오른쪽 역전 컨베이어, 네 화물, Q 위치 알림과 3분 연습도 유지합니다. 조명은 6.5m로 높였고 중앙 벽 사이에 있던 벨트는 오른쪽 운반 통로에 있습니다.

기본 조작은 WASD 이동, 마우스 시점, Space 점프, E 집기·받기·놓기, 왼쪽 클릭 던지기, Q 알림, F 벨트 역전, R 경적, H 도움말, Esc 메뉴입니다. A/B 라벨과 같은 배송구에 넣으세요. 첫 화면 또는 Esc 메뉴의 설정에서 조작 키를 바꿀 수 있습니다.

## 검증 상태와 출시까지 남은 것

동작 검사 30개, 실제 두 프로세스 시나리오 8개, 네 프로세스 시나리오, SteamPipe 생성 도구 검사를 통과했습니다. 캠페인 완주·공동 구매·준비 투표·절도와 경적 회수, 실제 비행 릴레이, 바닥에 안착한 화물의 둥지 운반, 첫 실행 설정, 중복/늦은 참가 완주 기록을 확인합니다. 이동 스냅샷은 최대 검사 상태 1,280바이트, 별도 캠페인 정보 ≤2,048, 크리쳐 ≤256바이트입니다.

**Steam 출시는 아직 아닙니다.** Steamworks 미등록·실제 App/Depot ID 미확보 상태입니다. 현재는 방장 PC가 서버인 ENet 직접 주소 방식이고 Steam 친구 초대·중계는 없습니다. 별도 PC/외부 네트워크, 대상 기기 성능, 독립된 친구 그룹 재미 검증, 최종 아트·상점 이미지·트레일러·권리 검토, Steam 설치와 Valve 심사가 남았습니다. 자동 검사 결과를 재미나 인터넷 연결 품질의 증거로 해석하지 않습니다.

## 0.7.1 포장쥐 수정

가까이 보이는 상자를 지나치던 문제를 수정했습니다. 오른쪽 통로에서 6m 탐색 → 접근 → 1.4m 안에서 절도 예고로 이어집니다. 계약 2부터 활동합니다. 기존 0.7 실행 파일·ZIP 경로를 최신 수정본으로 갱신했으며 설정 폴더는 유지합니다. [수정 기록](docs/development/2026-09-07-packrat-search.ko.md).


## 0.7.2 배송 신전

창고를 거대한 박스 사장이 내려다보는 배송 신전으로 바꿨습니다. A/B 배송구는 밥을 달라는 거대한 얼굴, 쥐 둥지는 이달의 직원 전시입니다. 입고는 제물 접수처, 벨트는 승진의 길입니다. 한·영 표어, 보라·금빛 배경, 작은 장식 움직임을 적용했습니다. 양쪽 운반 동선과 배송 규칙은 유지합니다. [컨셉·적용 기록](docs/superpowers/plans/2026-09-07-shipping-shrine.ko.md).


## 0.7.3 직접 편집하는 맵

**[EDIT_MAP.cmd](EDIT_MAP.cmd)**를 두 번 클릭하면 편집할 맵이 열립니다. 벽·조명·배송구·벨트·쥐 영역·시작점을 직접 배치하고 Ctrl+S → F5로 확인하세요. 벽 예제는 외형과 충돌 크기가 함께 바뀝니다. **[한국어 맵 편집 안내](docs/development/map-editing.ko.md)**에 첫 벽 이동부터 맵 확대까지 정리했습니다.

친구에게 보낼 때는 **[BUILD.cmd](BUILD.cmd)**로 실행 파일을 다시 만들고 같은 ZIP을 사용합니다. 프로토콜 8에서 서로 다른 맵의 입장을 거절합니다. 저장한 맵이 실행 시 다시 생성되지 않습니다.


## 0.7.4 넓어진 배송 신전

**48×60m, 이전 면적의 2.5배**로 확장했습니다. 안쪽 배송구까지 운반하며 인수인계 쉼터에서 화물을 모으거나 릴레이할 수 있습니다. 왼쪽은 항상 열린 우회로, 중앙은 직원/상자로 발판을 눌러 여는 지름길, 오른쪽은 예고 후 바람으로 상자와 직원을 미는 특급로입니다. 문은 발판을 떠나도 6초 유지하여 혼자 통과할 수 있습니다.

새 장치도 Godot에서 위치·방향·시간·세기를 편집할 수 있습니다. [편집 안내](docs/development/map-editing.ko.md), [확장 기획·검증](docs/superpowers/plans/2026-09-08-shrine-expansion.ko.md). 프로토콜 9이므로 친구 모두 같은 새 ZIP을 사용하세요.


## 0.7.5 굽은 골목

왼쪽은 S자, 오른쪽은 가로 송풍을 지나 꺾이는 동선으로 바꿨습니다. 문 앞뒤 연결길에서 중간에 경로를 바꿀 수 있습니다. 직선 유도선을 굽은 화살표·색 선으로 교체하고 모퉁이에 시야를 가리는 벽을 배치했습니다. 새 벽과 참고 경유점도 직접 편집할 수 있습니다. [변경 계획·검증](docs/superpowers/plans/2026-09-08-winding-shrine.ko.md).

실내에는 접수·포장·휴게·보관 소품 29묶음, 선반 상자 96개, 벽 포스터 18개와 배관·깃발을 채웠습니다. 소품은 직접 옮길 수 있고 고정 가구에는 충돌이 있습니다.

## 0.7.6 실내 구역과 화물 창구

접수실·분실물 서고·문지기 대기실·바람실·A/B 배송실에 벽과 부분 지붕을 추가했습니다. 문과 코너가 시야를 가리고, 양옆 우회로와 문 앞뒤 연결길은 유지합니다. 접수실 서쪽 창구의 **던지기** 표시에서 창을 향해 상자를 던지고 바깥 **받기** 표시의 동료가 E로 받으면 릴레이를 시도할 수 있습니다. 창구는 직원이 통과할 수 없습니다.

[0.7.6](docs/superpowers/plans/2026-09-08-enclosed-shrine.ko.md).

## 0.7.7 아트 방향 정리

배경을 낡은 배송시설의 크림색·녹회색·콘크리트색으로 정리했습니다. 가시 표지 104개를 38개로 줄이고 필요한 안내에 받침판을 달았습니다. 벽 보호판·이음새·천장 보강재와 은은한 재질을 추가했습니다. 직원은 작업복·모자·장갑·작업화·사번을 갖추고 팔과 다리를 번갈아 움직입니다. 화물 색과 먼 거리 문구도 정리했습니다. 조작과 배송 규칙은 그대로입니다.

[0.7.7](docs/superpowers/plans/2026-09-08-art-direction.ko.md).

## 0.7.8 접수실과 손맛 다듬기

접수대는 녹회색 패널과 나무 상판으로 새로 구성했습니다. 포장대에는 저울·테이프·송장, 기록 보관대에는 서류함·도장을 배치해 작업별로 구분했습니다. 큰 사장 장식은 작은 창업주 액자로 바꾸고 시계와 안내판을 벽에 붙였습니다. 바닥 진열 매트는 화물 적재선과 릴레이 위치 표시로 정리했습니다. 이 소품은 장식이며 새 조작 장치가 아닙니다.

가구·상자·직원 소품의 모서리를 깎고 손이 닿는 작업대 가장자리에 사용 흔적을 넣었습니다. 상자를 들고 돌아설 때 직원과 손이 상자 방향을 바로 따라가며, 들기·내려놓기 자세는 짧게 이어집니다. 평상시 상자 이름표를 줄이고 위험 예고는 유지했습니다. 배송 완료음은 짧은 도장·기계음으로 바꿨습니다.

모두 같은 0.7.8 ZIP으로 실행하세요. 기존 배송 규칙과 조작은 같습니다. 최종 출시 아트와 실제 친구 그룹의 재미·성능 검증은 아직 남아 있습니다.

[0.7.8 구현·검증 기록](docs/superpowers/plans/2026-09-08-authored-depot.ko.md).
