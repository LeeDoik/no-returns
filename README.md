# NO RETURNS — 반품 불가

[English](README.en.md)

살아 있는 택배를 배송하는 1~4인 3D 협동 게임. 현재 **개발 빌드 0.9.3**, Godot 4.7.2, Windows/Steam 출시 목표입니다. Steam 초대·상점/빌드 심사 완료본이 아닙니다.

## 실행

- [00_게임 실행.cmd](<00_게임 실행.cmd>): 마지막 배포본 실행
- [01_맵 편집.cmd](<01_맵 편집.cmd>): 맵 편집
- [03_물리 실험실.cmd](<03_물리 실험실.cmd>): 기존 운반 방식의 물리값 시험
- [PLAY.cmd](PLAY.cmd): 최신 소스 실행
- [BUILD.cmd](BUILD.cmd): 배포본 갱신
- [02_배포 파일 찾기.cmd](<02_배포 파일 찾기.cmd>): 배포 ZIP 위치

실행 파일과 PCK는 함께 보관하세요. `build/NO_RETURNS_0.7`은 기존 호환 경로이며 실제 버전은 0.9.3입니다. 협동 참여자는 같은 빌드·맵을 사용합니다. 프로토콜은 11입니다.

## 문서

**[문서 홈 — 여섯 가지 분류](docs/README.md)**에서 최신 기획·규칙·제작 방법·미완료·검증·과거 기록을 확인하세요. 기존 버전별 README는 [과거 기록](docs/archive/legacy-readme.ko.md)으로 옮겼습니다.

로컬 Git으로 관리하며 GitHub 원격 저장소는 연결하지 않습니다. `art/`는 제작 원본, `assets/`는 실행 아트, `scenes/`·`scripts/`는 맵과 코드, `tests/`·`tools/`는 개발 도구, `artifacts/`는 로컬 검증 기록입니다.
