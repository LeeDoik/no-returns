# 6. 과거 기록 보관함

[English](README.en.md)

기존 파일 경로는 링크·도구 호환성을 위해 보존했습니다. 아래 문서는 과거 기획·상세 가이드·검증 기록입니다. 현재 상태는 [문서 홈](../README.md)의 명세가 우선하며, 과거 수치를 현재 값으로 복사하지 마세요. 취소된 기능의 구현 기록은 현재 구현을 의미하지 않습니다.
