# 포장쥐 탐색·접근 수정 — 0.7.1

[English](2026-09-07-packrat-search.en.md)

## 원인

이전 포장쥐는 절도 거리 1.4m 안에서만 후보를 찾았고 상자로 접근하는 상태가 없었습니다. 실제 맵에 약 4m 떨어진 바닥 화물을 두면 지나치고 훔치지 않는 실패를 재현했습니다. 기존 검사는 상자를 쥐 바로 옆에 놓아 이 빈틈을 놓쳤습니다.

## 변경

오른쪽 활동 구역의 시야가 열린 6m 안에서 자유 접지 화물을 찾아 접근합니다. 1.4m 안에 도착한 뒤 0.9초 예고합니다. 소지·접착·공중·보호·벽 너머 화물 제외는 유지합니다. 추적 중 직원이 들면 취소합니다. 이동이 1.25초 막히면 목표를 3초 제외하고 돌아갑니다. 순찰 경유지는 (10,-3.2), (10,-8), (10,-14), (13,-17)로 둥지를 피합니다. 접근 상태와 `상자 발견!`을 한·영으로 표시하고 온라인으로 공유합니다.

계약 1과 짧은 연습에는 쥐가 없습니다. 계약 2~3에서 오른쪽 통로만 활동하며 왼쪽 운반 경로는 유지합니다. 기존 0.7 경로의 실행 파일·ZIP을 갱신하고 게임 내 버전을 0.7.1로 표시합니다. 앱 이름은 유지해 사용자 설정·기록 위치를 바꾸지 않습니다. Git `v0.7.0`은 보존하고 수정 기준점은 `v0.7.1`입니다.

## 검증

`tests/test_packrat.gd`에서 실제 물류센터의 약 4m 떨어진 상자를 순간이동 없이 접근·절도하는 검사를 추가했습니다. 수정 전 실패, 수정 후 통과했습니다. 추적 중 집기 취소와 기존 접지 운반·둥지·경적·벽·복구 검사도 포함합니다. `tests/test_campaign_network.gd`는 먼 상자로 조건을 바꾸고 방장과 손님 모두 접근 상태를 확인한 뒤 절도·경적 회수·완주를 검증합니다. 로그는 `artifacts/packrat-seek-red.log`, `packrat-seek-green.log`, `packrat-seek-network-run.log`입니다. 별도 PC와 실제 친구들의 플레이 검증을 대신하지 않습니다.
