## 점프대

원인은 Top만 이동·축소하고 스프링/안내봉을 움직이지 않던 표시 코드다. 실제 GLB는 네 스프링과 안내봉을 하나의 금속 메시로 합친 상태다. 발판 두께를 유지하면서 예고 0.18초에 최대 0.10m 내려가고, 발동 후 기존 0.48m 높이 곡선을 적용한다. 지지 메시의 아래 경계는 고정하고 위 경계는 실제 발판 메시의 아래 경계와 맞춘다. 초기·압축·튀어오름·복귀 전 구간을 검사한다. 발사 판정과 속도는 변경하지 않는다.

## 문서와 상자 더미

직원 이동 속도, 화물 충돌 속도와 질량, 재채기 거리에서 충격 세기를 정한다. 화물 세기는 속력×sqrt(질량/3), 재채기는 거리 감쇠한 최대 8이며 0.1~20으로 제한한다. 이는 반응 연출의 입력 척도이며 접촉 솔버가 측정한 실제 힘(N)이 아니다. 방향과 충격 위치는 월드 좌표다. 최초 유효 충격이 해당 발동을 결정한다.

문서는 이제 직원/화물의 빠른 접촉(1.8m/s 이상)에도 반응한다. 초기 속도·흩어짐·회전은 충격 방향·세기와 이벤트별 재현 가능한 난수로 정한다. 기존 뭉치 비행 후 펼쳐짐, 공기 저항·바닥/벽 검사·시간 후 복원은 유지한다.

상자 더미 3개는 정해진 목표 위치로 이동하지 않고 동적 강체로 낙하·회전한다. 충격점과의 거리로 속도를 줄이고 편심 충격으로 각속도를 부여한다. 바닥·벽·다른 장식 잔해와 충돌하지만 직원/배송 화물에는 물리 반작용을 주지 않는 장식 잔해다. 기존 장치의 직원/화물 반응 판정은 서버에서 유지한다. 모든 상자를 새 운반 화물로 바꾸는 변경은 아니다.

## 온라인과 검증

반응 상태에 충격 세기와 위치를 추가해 소품당 6→10개 수치를 전송한다. 프로토콜을 11→12로 올리며 같은 0.9.4 빌드로 접속해야 한다. 손님은 같은 입력으로 연출을 재생하지만 잔해의 프레임별 위치를 전송하지 않으므로 완전히 같은 최종 위치는 보장하지 않는다.

새 검사: 발판 두께·지지 하단 고정·상단 접촉, 강도별 문서 속도, 회전된 부모의 월드 방향, 상자 강체 이동과 초기화. 기존 온라인 검사는 충격 세기·위치 전송도 확인한다. 실제 렌더러에서 세 장치를 함께 녹화한다. 전체 결과와 남은 한계는 작업 기록과 현재 검증 문서에 남긴다.

전송 시 상태 배열을 DEFLATE로 압축하며, 수신 시 맵의 반응 소품 수×40바이트로 압축 해제 크기를 제한한다. 기존 2,048바이트 캠페인 메타데이터 회귀 검사를 유지한다. 스프링은 튀어 오른 뒤 약 0.63초 안에 기본 높이로 연속 복원된다.

행동 검사 41개, 2인 시나리오 10개, 4인 시나리오 1개의 통과 결과를 확보했다. 전체 실행의 마지막 던지기 애니메이션 통신 검사에서 1회 시간 초과가 발생했고 단독 재검사에서 통과했다. 반복 안정성은 추가 관찰이 필요하다.
