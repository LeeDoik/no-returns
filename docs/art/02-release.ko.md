## 9월 9일 직원 애니메이션 개정

직원은 새 41개 뼈·13개 동작 모델로 교체했습니다. 아래 24개 뼈·걷기 모델 설명과 성능 수치는 최초 0.9.0 기록이며 새 모델의 성능 측정치가 아닙니다. 최신 직원 편집 원본은 `art/tripo-01/worker-animation.blend`입니다. [동작 적용과 남은 검수](04-animation-integration.ko.md).

## 실행과 확인

Windows 빌드는 `NO_RETURNS.exe`를 실행한다. 개발 폴더에서는 `00_게임 실행.cmd`, 최신 소스는 `PLAY.cmd`, 에디터는 `EDIT.cmd`를 사용한다. 이전 실행 창을 닫고 새 빌드를 연다. 협동 참가자는 같은 0.9.1 빌드와 저장 맵을 사용한다. 통신 규칙은 프로토콜 11이며 맵 일치 검사도 유지된다. [운반·물리·팀 색상 개정](05-carry-physics.ko.md)이 아래 최초 아트 기록보다 우선한다.

혼자 연습에서 상자 네 종류와 직원을 확인한다. 재채기 상자는 예고 중 눈을 치켜뜨고, 재채기할 때 눈을 감으며 뚜껑이 열린다. 접착 상자의 흡착판과 점프 상자의 신발은 실루엣으로 구별된다. 공기 쿠션은 여섯 공기방이 납작해지고 스프링 발판은 상판이 튀어 오른다. 문서 18장의 비행과 복구 동작은 유지했다. 캠페인의 포장쥐는 새 모델의 발과 꼬리가 움직인다.

## 이번에 만든 것

- Higgsfield: 직원·포장쥐·시설 참고 이미지, 골판지·칠한 철·콘크리트 재질 원본, 직원과 쥐의 텍스처 포함 3D 모델.
- Blender 5.2.1 LTS: 모델의 크기·방향·불필요한 제어용 메시 정리, 직원의 24개 뼈와 걷기 애니메이션 유지, 쥐의 발·꼬리용 6개 뼈 추가.
- Blender 제작 키트: 일반·재채기·접착·점프 상자, 작업대, 선반, 컨베이어 모듈, 배송구, 스프링 발판, 공기 쿠션, 매달린 조명. 캐릭터를 합쳐 게임용 모델 13종이다.
- 맵: 작업대 7개, 선반 8개, 컨베이어 모듈 8개, 배송구 2곳과 기존 조명에 새 모델을 배치했다. 바닥 재질과 벽의 미세 요철을 적용했다. 충돌체 171개의 경로·변환·크기·활성 상태는 기존 버전과 같다.
- 화면: 거리별 텍스처 단계와 4배 다중 샘플 안티앨리어싱으로 재질 떨림과 가장자리 계단 현상을 줄였다. 아트는 기존 서버 판정과 동기화 상태를 따라 표시된다.

이미지 생성은 GPT Image 2의 `high / 4k` 요청을 사용했다. 실제 정사각 결과는 **2880×2880**, 시설 참고는 **3840×2160**이다. 정사각 이미지를 4096 해상도라고 표기하거나 확대하지 않았다. 재질 원본에서 반복 경계를 보정하고 노멀·거칠기·높이 지도를 만들었다. 현재 게임은 기본색과 약한 노멀을 사용하고, 나머지는 후속 재질 조정을 위해 보관한다. Nano Banana Pro는 계정 요금제 제한으로 생성되지 않았다. 구독은 변경하지 않았다.

## 직접 수정할 파일

`art/release-01/source/postal-kit.blend`는 시설과 상자 원본이다. `worker.blend`, `packrat.blend`는 캐릭터 원본이다. 원본 GLB와 생성 작업 번호는 같은 제작 폴더의 `source`, `reports`에 보관한다. 이전 `art/sneezer` 원본은 보존했다.

게임에서 읽는 파일은 `assets/art/release-01`에 있다. 새 GLB를 같은 이름으로 내보내면 Godot가 다시 가져온다. 작업대·선반·배송구 위치는 `scenes/maps/shipping_shrine.tscn`에서 `Art_` 노드를 이동해 조절한다. 충돌체를 바꾸려면 기존 편집용 블록을 함께 조절해야 한다. 아트만 옮기면 충돌 위치는 바뀌지 않는다.

반응 소품은 기존 `kind`, 반응 거리, 복구 시간 속성으로 편집한다. 표시용 모델은 미리보기이므로 자식에 복제하여 저장하지 않는다. `apply_postal_art.gd`, `refine_postal_art.gd`는 이미 적용한 일회성 도구이며 평소 실행이나 빌드에 사용하지 않는다. 자동으로 맵을 다시 만들지 않는다. 제작 폴더 전체는 배포에서 제외한다.

## 검증과 남은 출시 작업

아트 전용 검사는 표정 전환, 뚜껑, 쿠션 6개, 발판 상판, 캐릭터 뼈대, 정지 시 발 자세, 종료 후 남는 노드를 확인한다. 기존 협동·충돌·배송·문서·온라인 회귀 검사와 실제 렌더러 캡처를 함께 사용한다. 결과 기록은 `artifacts`에 남긴다.

같은 재질과 같은 관절을 사용하는 고정 부품을 묶고 얇은 인쇄면의 그림자를 제거했다. RTX 4070 Laptop, 1152×720, 직원 4명, 접수실 화면의 180프레임 표본에서 프레임 중앙값은 24.8ms에서 16.4ms, 95백분위는 27.8ms에서 17.6ms로 줄었다. 이는 이 PC의 짧은 표본이며 전체 맵의 최저 성능이나 저사양 PC 성능 보장은 아니다. 최적화 도구 `batch_postal_art.gd`와 조명 적용 도구 `light_postal_art.gd`도 이미 적용한 일회성 도구다.

이 버전은 **출시용 아트로 전환한 개발 빌드**다. 모든 배경 소품을 최종 자산으로 교체한 상용 완성판은 아니다. 일부 기존 벽·소품과 효과는 프로토타입 형상이 남아 있다. 직원의 손 접촉과 쥐의 발 미끄러짐은 다양한 플레이 상황에서 더 다듬을 여지가 있다. 외부 플레이 테스트, 저사양 PC의 성능 측정, Steam 친구 초대·스토어·계정 검수는 아직 출시 완료로 처리하지 않는다. 실제 게임 캡처와 참고 이미지를 구분하며, 참고 이미지를 게임 스크린샷으로 사용하지 않는다.
