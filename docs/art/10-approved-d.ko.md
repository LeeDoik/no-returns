# D안 대표 아트 3종 — 게임 적용

2026-09-10 · 개발 빌드 0.9.4의 D 아트 개정. 디자인 승인: 2026-09-09. 게임 전체의 출시 품질 인증이 아니다.

## 적용 결과

- 직원: 사용자가 제공한 Tripo GLB의 41개 관절·스킨을 유지하고 기존 18개 동작을 새 체형에 이식했다. 원본 파일에는 애니메이션이 없었다. 기존 동작의 초 단위 길이를 유지하며 60fps 선형 키로 저장한다. 골격 길이를 유지하고 운반 손 목표를 몸 기준 좌우 ±0.40m, 앞 0.44m, 높이 1.00m로 풀었다. 이 값은 손목 목표이며 상자의 전체 접촉 면 검증 수치가 아니다.
- 팀 식별: 새 모델의 COLOR_0 알파에 작업복 영역 마스크를 넣었다. 색상 셰이더가 얼굴·장갑·신발을 바꾸지 않도록 영역과 색상 조건을 함께 사용한다. 처음에는 장갑이 바뀌었고, 다음 검사에서는 잘못된 색상 채널 때문에 얼굴도 바뀌었다. 내보내기를 CrewMask 이름으로 고정한 뒤 네 팀 렌더에서 수정 결과를 확인했다.
- 재채기 상자: D안 골판지·코랄 테이프·앞니와 세 표정, 앞뒤 뚜껑을 적용했다. 기존 재채기 상태와 뚜껑 제어 이름을 유지한다. 20,624삼각형·23메시 표면, 내장 골판지 이미지 1개다.
- 컨베이어: D안 세이지 프레임·먹색 벨트·표지·받침대를 제작했다. 21,057삼각형·11메시 표면이다. 본편에는 길이 2m의 모듈 4개를 바닥 매립형으로 배치했다. 모듈 X 배율은 1.8, 바닥 상대 Y는 -0.874m다. 기존 운송 구역·레버·충돌 바닥·이동 규칙을 보존하며, 받침대는 바닥 아래에 들어간다. 기존 움직이는 줄무늬가 작동 표시를 담당한다. 표지와 버튼은 보이도록 0.25m 올렸다. 독립형 전체 모델은 제작 원본과 검토 장면에 보존했다.

## 원본·재제작

대표 제작 폴더 (`../../art/quality-trio-01/README.ko.md`; retired file), 적용 계획 (`../../art/quality-trio-01/integration-plan.ko.md`; retired file).

직원 입력은 `art/quality-trio-01/source/worker-tripo-rigged.glb`, 이전 동작 원본은 같은 폴더의 `worker-before-d.glb`이다. `retarget_worker.py`가 `worker-motion.blend`와 게임용 `models/worker.glb`를 만들고 `worker_team_mask.py`가 마스크를 제공한다. `build_props.py`는 상자·시설 원본과 GLB를 만든다. Blender는 `--factory-startup -b --python` 옵션으로 실행하여 사용자 추가 기능을 로드하지 않는다. 초기 검사에서 추가 기능 로그 경로 권한 오류가 발생하여 기본 시작 설정으로 재실행했다.

게임은 `assets/art/release-01/`의 worker/sneezer/conveyor_module.glb를 사용한다. `tools/apply_d_conveyor.gd`는 맵의 컨베이어 아트만 저장하는 일회성 제작 도구이며 게임 시작 때 실행하지 않는다. 이동 규칙 변경은 없다. 승인 이미지와 Tripo 입력·Blender 원본을 보존하며 비밀 키는 저장하지 않는다.

검토 후속: 새 화살표가 기본 운송 방향과 반대이며 반전되지 않는 결함을 수정했다. 화살표를 중심 기준으로 만들고 `scripts/conveyor.gd`가 실제 direction을 반영한다. 초기·반전 일치 검사를 추가했으며 D 아트·컨베이어·우편 아트 검사를 다시 통과했다.
