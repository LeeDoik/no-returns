## 확인한 원인

0.9.1을 16초 연속 시나리오로 재생하고 동작 전체의 골반과 발을 측정했다. 달리기의 골반 Z는 약 -0.913m, 대기·걷기는 약 -0.086m였다. Root가 제자리여도 Hip에 83cm의 기준점 차이가 남아 있었다. 신발 메시의 최저점은 대기·걷기·달리기에서 바닥 아래 약 3~10cm였다. 옆·뒤 이동도 전진 동작을 쓰고, 운반 손목의 회전은 기존 걷기 팔동작을 이어받고 있었다. 이전의 클립 존재·유한한 관절값·정지 화면 검사는 이 문제들을 검출하지 못했다.

## 재제작 범위

Tripo의 원본 동작을 참고 자료로 보존하고, 동일한 41개 뼈대에 18개 동작을 다시 굽는다. 매 프레임 골반의 수평 기준점을 충돌체 중심으로 맞추고 실제 변형된 신발 메시로 바닥 침범을 보정한다. 운반 상체는 대기 자세에서 별도로 만들고 손 목표점과 팔꿈치 굽힘을 고정한다. 운반은 전후좌우·대각선 8방향, 공중 운반, 대기로 나눈다. 공중에는 무릎을 굽히고, 착지는 발을 고정한 무릎 압축, 던지기는 팔을 내리는 회복까지 포함한다. 모든 출력은 60fps 선형 키로 굽는다.

빈손은 실제 이동 방향을 향해 움직이며, 운반 방향은 기존 상자 조준 방향을 유지한다. 다리의 실제 보폭에 맞춰 빈손 최고 속도는 3.2m/s, 운반 전진은 1.6m/s, 운반 옆·뒤는 1.2m/s로 조정한다. 장비·상태 배율은 기존 규칙을 따른다. 루프 간 변경은 진행 단계를 이어받으며, 공중 꼭대기를 착지로 오인하지 않게 한다. 팀 작업복 네 색과 물리·배송 규칙은 유지한다.

편집 원본은 `art/worker-motion-02/worker-motion.blend`, 재현 도구는 같은 폴더의 `rebuild_motion.py`다. 앞선 리깅 원본을 덮어쓰지 않는다.

## 검수 순서

- [x] 기존 동작의 16초 영상과 프레임 표본, 골반·발 측정치 확보.
- [x] 기존 달리기의 골반 위치와 누락된 방향별 동작을 새 검사에서 실패로 재현.
- [x] 재제작 모델을 Godot로 가져와 골반·손·발·방향 변경 검사.
- [x] 같은 연속 시나리오와 운반 8방향을 실제 렌더러로 녹화하고 프레임별 검수.
- [x] 회귀·온라인 검사, 배포본 실행과 한·영 안내 갱신.

정지 화면이나 자동 검사 통과만으로 동작의 자연스러움을 확정하지 않는다. 수정 전후 영상과 관절 측정을 함께 남기고, 수치로 확인한 내용과 사람의 판단이 필요한 부분을 구분한다.

## 0.9.2 검증 결과

행동 검사 37개, 2인 온라인 시나리오 10개, 4인 시나리오 1개를 통과했습니다. Godot에서 측정한 달리기 골반 수평 위치는 중심에서 0.001mm 이내였습니다. Blender 변형 메시 검사에서 대기·걷기·달리기·운반 걷기의 각 12개 표본은 최저점이 바닥 위 약 4mm였습니다. 이는 경사면이나 모든 중간 프레임의 발 고정을 보증하지 않습니다.

실제 렌더러에서 기본 동작과 운반 8방향을 각각 약 16초·60fps로 녹화하고 전환 프레임을 검토했습니다. 기록은 `artifacts/motion-before.avi`, `motion-after.mp4`, `motion-directions.mp4`, `motion-after.json`, `floor-after.log`, `motion-full.log`에 있습니다. 제어된 영상 검수이며 사람의 자유 플레이 평가는 별도로 필요합니다. 기존 Tripo 걸음의 스타일은 남아 있고 경사면 발 IK와 개별 상자 크기에 맞춘 손 IK는 구현하지 않았습니다.
