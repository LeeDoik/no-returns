# 애니메이션 전환 폴리싱

[English](08-animation-polish.en.md)

## 범위와 구현

0.9.3은 애니메이션만 다듬는다. 이동 속도, 중력, 질량, 충돌체, 잡기·던지기 규칙과 본편 맵은 변경하지 않는다. 현재 18개 동작을 재사용한다.

운반 방향을 22.5도 경계에서 즉시 변경하던 방식을 31도 이탈 경계로 완화한다. 제자리 운반 회전에는 기존 옆걸음을 사용해 발이 고정된 채 몸만 도는 현상을 줄인다. 걷기 재생 속도는 지수 보간하고 정지 전환은 0.24초, 일반 전환은 0.18초, 던지기·착지·피격은 0.09초, 공중 전환은 0.12초로 구분한다. 점프 꼭대기의 단일 수직 속도 0 표본을 착지로 오인하지 않도록 한다. 빈손에는 작은 호흡과 상체 기울기를 더하며 운반 팔 자세에는 적용하지 않는다.

## 검증 계획

전환 경계·제자리 발동작·점프 꼭대기를 회귀 검사하고, 기존 행동·온라인 검사와 연속 녹화를 수행한다. 실제 사람이 느끼는 자연스러움과 경사면 발 고정은 별도 판단이다. 제자리 회전은 전용 회전 클립이 아닌 기존 옆걸음의 재사용이며 발의 완전한 접지 고정은 보장하지 않는다.

## 검증 결과

행동 검사 39개, 2인 시나리오 10개, 4인 시나리오 1개를 통과했다. Windows 0.9.3 배포 및 실제 렌더러 실행도 확인했다. 프로토콜 11은 유지한다. `artifacts/motion-polish.mp4`는 동일한 16초 시나리오의 60fps 녹화이며 운반·회전·이동 표본을 검토했다. 전환 검사는 기존 코드에서 점프 꼭대기 오판으로 실패한 뒤 수정본에서 통과했다. 결과 로그는 `artifacts/animation-polish-suite.log`에 있다.
