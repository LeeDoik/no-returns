# 애니메이션 게임 적용 작업 계획

[English](04-animation-integration.en.md)

## 목표

[직원 재작업](03-tripo-animation.ko.md)을 이어서 사용자의 Tripo 업그레이드 이후 생성한 뼈대를 적용한다. 하나의 뼈대와 제자리 동작을 사용한다. 교체 모델의 불러오기와 시각 검증이 통과할 때까지 이전 플레이 가능 모델을 유지한다. 사용자 요청에 따라 Codex 계정의 남은 사용량이 1% 이하가 되면 작업을 멈추고 알린다. 사용량 초기화권은 사용하지 않는다.

- [x] 업그레이드된 계정 잔액 3,180크레딧 확인.
- [x] 검증된 로컬 T자 자세를 새 자산으로 업로드: `ba747b8c-0476-4108-9a87-6823869224c1`.
- [x] 사람형 v1.0 Auto Rig 요청. 표시 비용 20크레딧.
- [x] 후보 7개 생성과 Choose Animations 목록 확인. 뼈대 비용 20크레딧, 동작 생성 후 확인한 잔액 3,160.
- [x] 뼈대·동작 7개·Animation stay in Place를 포함한 GLB 내보내기 요청. Tripo 성공 알림 확인, 로컬 파일 수신은 아직 미확인.
- [ ] 대기·걷기·달리기를 우선 뼈대 포함 GLB로 내보내고 파일명·뼈대·프레임 범위·출처 자산을 `art/tripo-01`에 기록.

## 완료 판정

브라우저 미리보기 성공만으로 사용할 수 있는 뼈대 파일 확보나 게임 동작의 자연스러움을 입증하지 않는다. 요청한 사용량 중단 기준에 도달하면 완성한 자산을 보존하고 남은 순서를 이 문서에 기록한다. 교체 모델 검증이 끝나지 않았다면 플레이 가능한 기존 버전을 유지한다.

현재 막힌 부분: 다운로드 응답이 시간 초과됐고 로컬 GLB가 도착하지 않았다. 페이지 자산 저장 기능은 GLB를 지원하지 않는다. 로컬 파일 수신부터 재개하여 Blender에서 동작 7개를 확인하고 미완료 단계를 이어간다. 이번 수정에서는 게임 동작 파일을 바꾸지 않았다.
