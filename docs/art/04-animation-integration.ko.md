# 직원 애니메이션 적용 결과

[English](04-animation-integration.en.md)

현재 실행본은 [0.9.1 운반·물리·팀 색상 개정](05-carry-physics.ko.md), 프로토콜 11을 사용한다. 아래는 이전 0.9.0 리깅 적용 당시의 기록이다. 현재는 운반 중 carry_run을 선택하지 않는다.

2026년 9월 9일 · 0.9.0 아트 빌드의 직원 애니메이션 개정. 모든 참가자는 동일한 최신 ZIP을 사용한다. 프로토콜 번호는 10을 유지한다.

## 확보한 원본과 제작 결과

사용자가 제공한 `Downloads/worker-tripo-input.glb`를 검사해 41개 뼈와 idle, walk, run, jump, fall, lift_heavy, hit_to_body_01 동작 7개를 확인했다. 업로드용으로 만들었던 같은 이름의 뼈대 없는 원본과 혼동하지 않도록 다운로드 파일은 `art/tripo-01/worker-tripo-seven.glb`로 별도 보존했다. 파일 크기는 9,405,548바이트다. 유료 Tripo 자산은 `ba747b8c-0476-4108-9a87-6823869224c1`; 기존 리깅 기록의 20크레딧 외에 이번 로컬 적용 작업에서 추가 생성 요청은 하지 않았다.

Blender 5.2.1 LTS에서 기본 자세 높이를 1.65m로 맞추고 정면과 바닥 기준을 정리했다. 원본 7개 동작의 Root 이동 범위는 세 축 모두 0이다. 19.5초의 lift_heavy에는 지속 운반에 부적합한 몸 돌림이 있어 직접 연결하지 않았다. 같은 뼈대에 carry_idle, carry_walk, carry_run, air_rise, air_fall, throw를 제작해 총 13개 동작을 내보냈다. 공중 동작은 물리 도약에 겹쳐 다시 뛰지 않도록 자세 중심으로 제작했다.

편집 원본은 `art/tripo-01/worker-animation.blend`, 재현 도구는 같은 폴더의 `prepare_animation.py`, 게임 모델은 `assets/art/release-01/worker.glb`다. 이전 모델은 Git 이력에 남아 있다. 맵·상자·쥐 원본은 이번 수정에서 변경하지 않았다.

## 게임 연결

대기·걷기·달리기·운반·공중·피격·던지기를 상태에 따라 선택하고 혼합한다. 이동 속도로 걸음 재생 속도를 조절하고 걷기/달리기 전환에 서로 다른 진입·이탈 기준을 둔다. 정지할 때 다리를 기본 자세로 갑자기 돌리거나 팔 뼈를 매 프레임 강제로 겨냥하던 처리를 제거했다. 운반 손·팔꿈치 보정은 Blender 동작에 구워 넣었다.

던지기는 기존 놓기 판정 순간에 후속 동작을 시작하므로 조작 지연을 추가하지 않는다. 참가자별 던지기 순번은 기존 신뢰성 있는 메타데이터 채널로 전달한다. 위치 정보 패킷 크기는 늘리지 않으며 메타데이터 변경 확인 주기는 최대 0.2초다. 중복·오래된 수신 정보는 재생을 다시 시작하지 않으며 늦게 참가하면 과거 던지기를 재생하지 않는다. 던지기 정보가 없는 이전 메타데이터도 읽을 수 있다. 이동·충돌·배송 판정은 기존 호스트가 담당한다.

## 검증 기록

- [x] 필수 동작이 없는 기존 모델에서 새 애니메이션 검사가 실패하는 것을 먼저 확인.
- [x] 새 모델의 대기·이동·운반·던지기 복귀·공중 전환, 유한한 뼈 변환값, 시각 루트 고정 검사 통과.
- [x] 던지기 수신의 첫 동기화·중복·오래된 순번 처리 검사 통과.
- [x] Godot 실제 렌더러에서 대기·걷기·달리기·운반·던지기·공중 자세 정지 화면 확인. `tests/capture_worker_animation.gd`로 재현 가능.
- [x] 4인 위치 정보에 던지기 정보를 추가한 뒤에도 1,280바이트 제한 검사 통과.
- [x] 행동 검사 35개, 2인 네트워크 시나리오 10개, 4인 네트워크 시나리오 1개 통과. 상대 캐릭터의 던지기 동작 재생을 두 프로세스로 검증. Windows 내보내기와 패키지 실행 검사 통과.
- [ ] 서로 다른 PC에서 사람이 운반·급회전·착지와 원격 동작을 평가.

검사 기록과 화면은 `artifacts`에 저장한다. 정지 화면과 자동 검사는 모든 플레이 상황에서 동작이 자연스럽다는 보장이 아니다. 전용 집기와 착지 전신 동작, 방향별 옆걸음/뒷걸음, 다양한 상자의 정확한 손 접촉은 추가 검수 대상이다. 현재 집기는 운반 자세로 혼합하고 착지는 이동·대기로 복귀한다. Steam 출시 완료를 의미하지 않는다.

## 사용량 중단 규칙

사용자 요청에 따라 Codex 사용량이 1% 이하 남으면 작업을 멈추고 알린다. 이번 재개 시 사용량 초기화를 확인했으며 초기화권을 사용하지 않았다.
