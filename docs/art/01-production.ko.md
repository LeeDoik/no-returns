## 방향과 범위

사용자의 요청에 따라 비용 절약보다 형태·재질·동작의 완성도를 우선한다. 기존 협동 규칙, 맵 동선, 충돌 크기와 영문 원문·한국어 대응을 유지한다. 낡은 우편 시설을 과장된 만화풍 3D로 표현한다. 녹회색 시설은 배경, 황토·크림색 직원과 화물은 주인공, 연두·분홍은 상호작용 신호다. 모서리와 손잡이는 실제 입체 형상으로 만들며, 종이·고무·칠한 철·목재를 구별한다. 바닥과 벽에 같은 무늬를 무차별적으로 붙이지 않는다.

Higgsfield는 스타일 참고 이미지, 실제 재질, 캐릭터 메시 생성에 사용한다. Blender에서 크기·축·재질·메시·애니메이션을 정리하고 GLB로 내보낸다. 게임 화면에서 읽힘·충돌 일치·그림자·온라인 동작을 확인한다. 기존 `art/sneezer`는 원본으로 보존하고 새 작업은 `art/release-01`, 게임용 파일은 `assets/art/release-01`에 둔다.

## 제작 목록

- 직원: 머리·모자·작업복·장갑·신발의 개별 형태, 이동과 운반 동작.
- 살아 있는 상자 네 종류: 골판지·테이프·뚜껑·표정과 종류별 실루엣, 기존 재채기·점프·접착 반응.
- 포장쥐: 명확한 얼굴·귀·꼬리와 움직임, 둥지와 연결되는 외형.
- 시설: 접수대·작업대·컨베이어·출고 장치·선반·벽·바닥·조명.
- 반응 소품: 에어캡·스프링 발판·상자 탑·문서의 통일된 재질과 기계적 디테일.
- 전달물: Blender 원본, GLB·텍스처, 출처·작업 기록, 실제 게임 화면, 한영 안내와 Windows 빌드.

## 확인 기준

생성 결과가 나왔다고 출시 품질로 간주하지 않는다. 실제 게임에 적용하고 멀리서의 구별, 애니메이션 변형, 모델과 충돌의 일치, 재질 방향·이음새, 파일 누락, 실행과 온라인 회귀를 확인한다. 최종 출시 판정에는 외부 플레이·저사양 PC 성능·Steam 검수가 별도로 필요하다. 생성 작업 번호와 원본은 기록하되 계정 인증 정보는 저장하지 않는다. 구매·구독 변경은 이번 범위에 포함하지 않는다.
