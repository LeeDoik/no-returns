# 물리 실험실 구현 계획

[English](07-physics-lab.en.md)

본편과 분리된 단일 사용자 시험 맵에서 본편 직원·상자를 재사용한다. 낙하, 경사로, 6단 적재, 좁은 통로를 제공한다. 질량·마찰·반발·중력·회전 감쇠·던지기 속도를 실행 중 변경하고 전체 재설정으로 비교한다. 값은 user://physics-lab.json에만 저장하며 본편에 자동 반영하지 않는다. 물리 백엔드와 계산 주기는 표시만 한다. 중력 조절은 시험 상자에만 적용하고 직원 중력은 본편과 동일하게 유지한다.

구현 순서: 전용 씬·조작 → 조정 패널·저장/불러오기 → 낙하·재설정·값 적용 검사 → 렌더링 확인. 본편 코드는 수정하지 않는다. 이 맵은 운반 시스템 재설계 전 현재 동작을 측정하는 도구이며 온라인 물리 검증은 포함하지 않는다.

## 실행과 조작

프로젝트 최상단 `03_물리 실험실.cmd`를 실행한다. 에디터에서는 `scenes/physics_lab.tscn`을 열고 현재 씬을 실행한다. Tab 또는 Esc로 패널과 캐릭터 조작을 전환한다. WASD 이동, 마우스 시점, Space 점프, E 들기/내려놓기, 왼쪽 클릭 던지기, 1~4 구역 이동, R 전체 초기화다. 입력창에서 값을 수정한 뒤 Enter로 확정한다.

패널에서 질량(kg), 상자·바닥 마찰, 상자 반발, 상자 중력(m/s²), 회전 감쇠, 던지기 수평 속도(m/s)를 조정한다. 던지기 수직 속도와 캐릭터 중력은 본편 값을 유지한다. 한 번에 한 값만 바꾸고 시험 재시작을 눌러 비교한다. 저장값 불러오기도 초기 상태로 되돌린다. 본편에 적용하려면 별도 코드 변경과 회귀 검사가 필요하다.

현재 실행 화면에서 확인한 백엔드는 GodotPhysics3D, 계산 주기는 60Hz다. Jolt 비교 기능은 아직 제공하지 않는다. 본편과 동일하게 운반 중에는 상자의 자유 물리 계산을 멈추므로 질량을 바꿔도 손에 든 무게감이 자동으로 생기지 않는다. 질량 차이는 떨어지거나 부딪히거나 밀 때 비교한다. 같은 중력에서 자유낙하 속도는 질량에 따라 달라지지 않는다.

검증: 상자 10개 생성, 질량 7kg 적용, 45물리 프레임 동안 낙하, 초기 위치·속도 복원 검사 통과. 실제 렌더러에서 패널과 네 구역 표시를 확인했다. 저장 파일은 Godot 사용자 데이터 폴더에 생성되며 저장 실패 시 패널에 표시한다. 사용자 장치에서의 자유 조작·장기 적재 안정성·온라인 테스트는 별도 검토 대상이다.
