## 확정 방향

사용자가 직접 지정한 [초기 A](outer-threats-01.png)를 현행 외곽 생물 기준으로 선택했다. 갈색 사족형 THE STRIDER를 사용하며 하얀 THE ABSENCE와 내부에 매달린 몸은 폐기된 디자인이다. 과거 파일은 이력으로만 남기고 제작에 사용하지 않는다. 이번 결과물은 제작 참고 이미지와 문서이며 실제 모델은 아직 없다.

## 형태

앞쪽이 높은 무거운 몸통, 낮게 늘어진 쐐기형 머리, 굵은 앞다리 2개와 뒷다리 2개, 넓고 평평한 발을 유지한다. 꼬리·추가 팔·외부 눈·약점 발광은 추가하지 않는다. 갈색·먹색·황토색의 넓은 면으로 PSX 질감을 표현한다. 작은 돌조각을 별도 부품으로 만들지 않고 표면 표현으로 통합한다.

후면에서는 머리가 몸통 뒤에 가려져야 한다. 시트의 후면이 정면을 반복한 초기 오류를 수정했다. 생성 이미지의 시점별 세부 비율은 완전한 정합 도면이 아니므로 회색 모델에서 확인한다.

## 뼈대와 동작 제안

ROOT 아래 몸통·척추, 목·머리, 네 다리 사슬을 구성하는 일반 사족 리그를 검토한다. 이미지 관절 점은 개념일 뿐 최종 계층이나 개수를 지정하지 않는다. 발가락은 첫 버전에서 독립 관절 없이 통합한다. 목과 머리는 지면·앞다리와 충돌하지 않도록 가동 범위를 정한다.

| 동작 | 제작 기준 |
|---|---|
| IDLE | 네 발로 무게를 지지하고 작은 호흡 움직임 |
| WALK | 짧고 느린 교대 발걸음, 발 미끄러짐과 접지 확인 |
| TURN | 발을 디디며 회전, 고정된 발을 비틀지 않음 |
| WARN | 머리와 몸통을 들어 공격 예고 |
| ATTACK | 짧은 앞발 타격·체중 이동을 시험, 나머지 발로 지지 |

공격 모션은 제안이며 피해·범위·시간·탐지·추적 규칙은 별도로 정한다. 억제장치 정지 후 진입하는 죽일 수 없는 외곽 위협이라는 방향은 유지한다. 크기·폴리곤·텍스처·관절 수는 미정이다.

## 검증

내장 이미지 도구에 사용자가 지정한 초기 시트를 참고로 주고 A만 다방향·리그 개념·접지·자세로 정리했다. 후면은 한 차례 수정하고 시각 확인했다. 측면에서 다리 가림과 자세 간 변화가 있어 정밀 애니메이션 도면으로 사용하지 않는다.

- [ ] 새 제작 시트의 세부 외형 검토.
- [ ] 회색 모델에서 정면·측면·후면 비율과 네 다리 배치 확인.
- [ ] 리깅 후 접지·회전·목 간섭·앞발 타격 검증.
- [ ] 실제 게임의 시야·안개·경고·탈출 상황에서 평가.

모델·리그·애니메이션·게임 코드 제작 및 동작 검증은 하지 않았다.
