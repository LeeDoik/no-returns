## 결정과 범위

사용자는 외곽 생물 A안을 선택하고 단순화한 제작용 시트를 요청했다. A의 선택은 확정이며, 이번 단순화 외형과 리깅 방식은 검토용이다. 모델 제작은 아직 요청하거나 승인한 것으로 취급하지 않는다. 이전 B·C안은 비교 기록으로 남긴다.

## 형태와 부품

- 체중을 받는 다리 2개와 땅을 짚지 않는 짧은 보조 팔 2개.
- 하나의 아치형 몸통, 바깥 머리·독립 손가락·추가 팔다리 생략.
- 중앙의 검은 공간은 오목한 불투명 내부 면으로 표현하는 안. 실제 관통 구멍이나 포털 효과가 아니다.
- 안쪽 작은 몸은 짧은 연결부에 매달린 단순 형상. 바깥 몸과 따로 회전·흔들리되 외피 안에서 움직인다.
- 얇은 끈 다발과 실시간 천 시뮬레이션은 첫 제작에서 제외한다. 창백한 외피와 어두운 내부의 대비를 유지한다.

## 리깅 참고

이동 기준 ROOT 아래 몸통과 좌우 다리·팔을 두고, 몸통 안의 INNER PIVOT에 작은 몸을 연결하는 일반 리그를 검토한다. 자동 사람형 리깅 성공을 전제하지 않는다. 이미지의 점은 일부 관절만 표시한 개념이며 실제 계층·관절 수·바인드 포즈가 아니다. 외피의 다리 접합부와 팔꿈치에는 굽힘 여유를 둔다. 작은 몸의 진폭은 외피와 닿지 않는 범위로 제한한다.

## 기본 동작 초안

| 동작 | 의도 | 검토할 문제 |
|---|---|---|
| IDLE | 바깥 몸은 거의 정지, 안쪽 몸만 느리게 움직임 | 과한 흔들림·벽 관통 |
| WALK | 짧고 무거운 번갈아 딛기 | 발 미끄러짐·접지·몸통 하단 충돌 |
| TURN | 작은 발걸음으로 방향 전환 | 지지 발 회전·다리 교차 |
| WARN | 상체 전경과 팔 올리기 | 공격 전 자세 구분 |
| ATTACK | 한쪽 보조 팔의 단순 휘두르기 | 외피 관통·공격 판정과 시각 일치 |

내부 움직임은 독립 제어한다. 죽일 수 없는 외곽 위협이라는 방향은 유지하지만 공격·추적·숨기·생존 규칙은 별도 설계가 필요하다.

## 검증과 미완료

내장 이미지 도구에 이전 A 시트를 참고로 주고 형태 축소, 다방향 모습, 부품과 관절, 기본 자세를 요청했다. 시각적으로 두 다리·두 팔, 내부 몸, 방향별 모습과 동작을 확인했다. 일부 시점의 비율·관절 위치·표면은 정확히 일치하지 않으므로 이미지에서 정밀 치수를 추출하지 않는다. 크기·폴리곤·텍스처·관절 수·동작 시간은 미정이다.

- [ ] 단순화 외형 검토 및 모델 제작 승인.
- [ ] 회색 모델로 옆·뒤 시점과 관절 배치 확인.
- [ ] 리깅 후 걷기·회전·공격에서 접지와 관통 확인.
- [ ] 내부 어두운 면이 조명·시점 변화에서도 의도대로 보이는지 확인.
- [ ] 실제 게임 거리·안개·억제장치 정지 상황에서 실루엣과 공포 평가.

현재 코드·모델·리그·애니메이션 파일은 제작하지 않았다.
