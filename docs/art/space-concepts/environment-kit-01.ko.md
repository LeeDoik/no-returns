# CINDER DEPOT 환경 아트 01 — 이미지 승인용

2026-09-13 · PSX 스페이스 미스터리의 첫 구역 아트 제안. 기존 전체 컨셉, 우주선 내부와 1인칭 화면을 참고한다. 새 시트의 사용자 승인 전에는 3D 모델을 만들거나 실행본 외형을 교체하지 않는다.

## 이번 이미지의 범위

우주선 경사로에서 첫 배송 시설 입구를 바라보는 1인칭 환경 투시도와, 같은 장소를 구성하는 벽·모서리·문틀·바닥·램프·화물 선반의 6종 모듈 시트를 한 장으로 제안한다. 현재 검증 맵의 정확한 배치나 플레이 캡처가 아니다. 새 크리쳐 외형과 새 장비를 추가하지 않는다.

상아색 산업 패널, 산화된 주황·적갈색 띠, 어두운 철제 프레임과 삼각 배송 표식으로 기존 시설·우주선과 연결한다. 따뜻한 선내 조명은 귀환 지점, 문 주변 램프와 BAY 04 표식은 이동 방향을 강조한다. 청록은 동료 식별에 제한적으로 쓴다. 바닥은 출입구보다 대비를 낮추고, 굴곡진 통로에서도 운반 공간이 읽히도록 한다.

큰 각진 형태, 단순한 모서리, 평면 음영과 저해상도 점 필터 텍스처를 표현한다. 128/256픽셀 원본 질감은 생성 지시의 시각적 목표이며 실제 텍스처 파일 규격을 검증한 값이 아니다. 녹·손때·긁힘은 패널 하단과 접촉부에 집중하고, 면 전체에 균일한 노이즈를 덮지 않는다. 디더링은 그림자에 절제해 사용한다. 반사·블룸·피사계심도와 과도한 안개는 표현 기준에서 제외한다.

## 승인 후 제작 시 확인할 것

- 모듈을 이어도 패널 간격과 색 띠 높이가 맞는가.
- 문틀과 선반이 운반 동선·충돌체를 침범하지 않는가.
- 어두운 화면에서도 출입구·화물·동료가 구분되는가.
- 저해상도 표현이 지저분한 노이즈로 보이지 않는가.

제작 도구는 내장 이미지 생성이다. 실제 프롬프트는 대응 영문 문서의 링크로 보관한다. 이미지의 모듈 분해도는 외형 참고이며 치수, UV, 메시, 재질, 반복 연결과 성능을 검증한 제작 에셋이 아니다. 코드·장면·모델·빌드 변경은 없다. 생성 후 시각 검토 결과를 아래에 기록한다.
