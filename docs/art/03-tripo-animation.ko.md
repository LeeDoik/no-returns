# 직원 리깅·애니메이션 재작업

[English](03-tripo-animation.en.md)

## 최신 진행 — 업그레이드 이후

사용자가 계정을 업그레이드했다. 새 자산 `ba747b8c-0476-4108-9a87-6823869224c1`에서 업로드와 사람형 v1.0 리깅을 진행했고 잔액은 3,180에서 3,160크레딧으로 바뀌었다. 페이지 자산 목록에서 새 뼈대 리소스 번호는 `e2676d1f-3794-42c2-a4cd-3b8343ec7fa3`로 확인했다. idle, walk, run, jump, fall, lift_heavy, hit_to_body_01의 7개 동작을 생성했다. 새 걷기는 브라우저에서 재생된다.

이전 계정 제한은 해소됐다. Export Skeleton이 활성화되고 동작 7개를 모두 선택할 수 있다. `worker-tripo-seven`이라는 이름으로 GLB 내보내기를 요청했다. 현재 2k 텍스처와 Animation stay in Place를 켰다. Tripo에는 `worker-tripo-seven exported successfully`가 표시됐다. 그러나 브라우저 다운로드 응답이 시간 초과됐고 로컬 출력 파일을 찾지 못했으며, 페이지 자산 저장 기능도 GLB 형식을 지원하지 않았다. 내보내기 성공 알림만으로 파일 수신까지 완료됐다고 판단하지 않는다. 사용자에게 `art/tripo-01/worker-tripo-seven.glb`로 저장을 요청했다.

Godot 적용과 내보낸 뼈대의 Blender 검수는 아직이다. [실행 계획](04-animation-integration.ko.md)을 참고한다. 아래 무료 계정 부분은 이전 작업 기록이며 현재 계정 상태가 아니다.

## 대상과 확인한 문제

플레이어 캐릭터인 직원을 먼저 수정한다. 쥐와 상자 애니메이션은 이번 수정 범위 밖이다. 현재 직원은 `Casual_Walk` 동작 하나를 재생하고, 정지하면 다리를 기본 자세로 돌리며, 운반 중에는 팔 뼈를 상자 쪽으로 향하게 한다. 전용 대기·운반 동작이 없다. 뼈대만 교체해서는 갑작스러운 자세 전환, 이동 속도에 맞지 않는 보폭, 손 접촉 문제를 해결할 수 없다.

## 업로드 원본

`art/tripo-01/worker-tripo-input.glb`는 `art/release-01/source/worker.blend`에서 만든 텍스처 포함 T자 자세 모델이며 뼈대는 없다. Blender에서 같은 위치의 UV 경계 정점까지 기존 뼈의 영향을 부드럽게 정리한 뒤 팔을 올리고, 변형을 메시로 굳혀 이전 뼈대와 애니메이션을 제거했다. 기존 원본은 보존했다. 함께 있는 `.blend`는 편집용이고, 정면·사선 PNG는 업로드 자세를 확인하는 이미지다.

높이는 1.65m, 삼각형은 20,664개다. GLB에 이미지가 포함되고 뼈대·애니메이션이 없으며 업로드 제한 150MB 미만인지 검사한다. 정확한 파일 크기는 `art/tripo-01/upload-validation.json`에 기록한다. 정면 이미지에서 옷감 찢어짐과 길게 늘어난 겨드랑이 부분을 확인했다. 이는 앞으로 생성할 새 뼈대의 변형 검증을 대신하지 않는다.

Tripo 업로드 자산: `b22f0221-706e-4a90-afc8-433458e5b6eb`. 원본 UV 유지 기능을 켰다. 업로드 방향 창에서 Y = -90도로 설정하여 얼굴이 보이게 했다. `v1.0 - Good for Humanoid`로 사람형 뼈대가 생성됐다. 크레딧 잔액은 200에서 180으로 바뀌었다. 브라우저에서 `walk` 애니메이션이 재생되며 표시된 길이는 약 2.38초다. 한 장면의 미리보기만으로 전체 동작의 변형 품질을 합격 처리하지 않는다.

### 현재 내보내기 제한

계정은 Free다. GLB와 Blender FBX 모두 `Export Skeleton`이 비활성화돼 있다. 옆의 업그레이드 버튼을 누르면 요금제 창이 열린다. 새 뼈대나 애니메이션 파일은 아직 내려받지 않았다. 한국 시간 2026년 9월 9일 계정의 Pro 월간 제안은 첫 달 $8, 이후 매월 $20 자동 갱신으로 표시된다. 연간 결제는 별도 선택지다. 이 작업에서 구독 신청이나 결제를 진행하지 않았으며 새 정기결제는 사용자가 처리하도록 요청했다.

요금제 화면에는 Free가 비상업용, Pro가 상업적 사용 포함으로 표시된다. 이번 무료 계정 리깅은 평가용 결과로 취급한다. Steam 제작에 적용하기 전에 해당 출력의 사용 권한을 확인하거나, 조건에 맞는 유료 구독이 활성화된 상태에서 다시 리깅한다. 업그레이드가 이전 출력에 소급 적용된다고 가정하지 않는다. 메시 원본 자체는 기존 Blender 파일에서 로컬로 준비했다.

## 필요한 동작

아래는 게임 제작 요구사항이며 Tripo가 전부 제공한다는 뜻은 아니다. 확인한 라이브러리에는 `idle`, `standing_relax`, `walk`, `run`, `lift_heavy`, `jump`, `jump_down`, `fall`, `hit_to_body_01`이 있다. 각 후보가 이 캐릭터에 어울리는지 직접 확인해야 한다.

| 게임 동작 | 목표 | 제작 방법 |
|---|---|---|
| Idle | 발을 고정하고 편안하게 호흡하며 손은 조용히 유지 | idle과 standing_relax 비교 |
| Walk / Run | 느린 이동과 최대 속도에서 발 디딤이 또렷하게 보임 | walk와 run을 검토하고 보폭·재생 속도 조절 |
| CarryIdle / CarryWalk | 양손으로 0.8m 상자를 받치고 팔꿈치를 굽힌 상태 유지 | 적합한 동작이 없으면 Blender에서 운반용 상체 동작 제작 |
| Pickup / Throw | 기존 집기·놓기 순간에 맞춰 몸을 숙이고 팔에 후속 동작 부여 | 집기 후보로 lift_heavy 검토, 필요하면 양손 던지기 직접 제작 |
| Jump / Fall / Land | 실제 지면 접촉 상태에 맞춘 도약·공중 자세·착지 | jump, fall, jump_down 검토 후 단계 분리 또는 제작 |
| Stagger | 잠깐 중심을 잃었다가 회복하는 모습이 분명함 | hit_to_body_01 검토 후 강도 조절 |

채택한 뼈대 하나를 모든 동작에 사용한다. 어깨·팔꿈치·손목·골반·무릎·발목을 유지한다. 벙어리장갑 형태라 개별 손가락 애니메이션은 필요 없다. 필요한 동작을 포함한 리깅 GLB 또는 FBX를 내려받는다. Tripo 출력 원본은 `art/tripo-01`에 그대로 보관하고 출처 작업 번호와 확인한 내보내기 옵션을 기록한다.

## Godot 적용 조건

캐릭터 이동은 계속 게임이 제어한다. 제자리 동작을 우선 사용한다. 출력에 루트 이동이 들어 있다면 의도적으로 제거하거나 분리하여 게임 이동과 애니메이션 이동이 중복되지 않게 한다. 최종 기본 자세 높이는 1.65m, 정면 방향은 기존 캐릭터 규칙에 맞춘다. 변환이 검증될 때까지 원본 변환값을 보존한다.

동작 하나를 재생하는 제어기를 대기·이동·운반·공중·피격 상태로 나눈다. 다리 뼈를 초기화하는 대신 자세를 부드럽게 전환한다. 다른 참가자의 캐릭터까지 실제 수평 이동량에 맞춰 발 움직임을 조절한다. 운반용 동작에 제한적인 손 접촉 보정을 더하며, 매 프레임 팔꿈치를 완전히 펴지 않는다. 집기·던지기·충돌 판정 권한은 기존 게임 코드에 둔다.
