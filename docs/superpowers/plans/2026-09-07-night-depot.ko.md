# 야간 물류센터 구현 계획

[English](2026-09-07-night-depot.en.md)

2026년 9월 7일. 목표: 프로토타입 0.6. 제한된 맵 표현 작업과 최종 검토에 subagent-driven-development를 사용합니다. 사용자가 큰 야간 물류센터를 승인했으며 포장쥐는 둥지 표시까지만 포함하며 AI는 후속 기획으로 남깁니다.

## 제약과 배치

2~4인 방장 판정과 기존 화물 규칙을 유지합니다. 전체 한·영 문서를 함께 관리합니다. 유료 아트는 사용하지 않습니다. 지붕을 열어 둔 기본 도형 창고 하나에 읽기 쉬운 조명·벽 선반·분류대·안내 동선·배송 셔터·접근 가능한 둥지 자리를 구성합니다.

바닥: X/Z 중심 (0, -9), 32 × 36m. 벽은 X ±16, Z -27과 +9입니다. 입고 화물과 직원 시작점은 기존 Z 1~5.3 근처를 유지합니다. 배송구 중심은 A (-10, -22), B (+10, -22)이며 판정 반폭은 기존 1.5 × 1.3m, 검사 배치 Y는 .65입니다. 복구 여유 경계는 X ±17, Z -28~10, Y -4 아래입니다. Z -10에 폭 16m·높이 3.4m의 중앙 분류 칸막이를 두어 입고에서 바로 배송구로 던지지 못하게 합니다. 양쪽 X ±10 근처에 상시 통행 가능한 우회로를 둡니다. 점프 상자·던지기 조합용 낮은 칸막이는 (1, .5, -1.5)에 유지합니다. 입고 접근 동선을 막지 않습니다.

컨베이어: 바닥과 같은 높이, 중심 (0, -5), 폭 2.2m·길이 6m입니다. 정방향은 Z 음수 방향입니다. 속도 2m/s, 레버는 (2, 0, -4), 조작 거리는 2.4m입니다. F로 반전하며 공동 .5초 재사용 대기와 서버 거리·방향·시야 검사를 적용합니다. 상자를 내려놓을 필요는 없습니다. 직원은 벨트의 외부 이동 속도를 받고 바닥의 자유 화물은 벨트 속도로 수렴합니다. 들고 있거나 복구 중이거나 접착 중인 화물은 제외합니다. 손님은 전달받은 상태만 표시합니다. 근무마다 정방향으로 초기화하고 플레이 외에는 이동 효과를 중지합니다.

## 작업

- [x] `scripts/depot.gd`의 표현·지형을 교체합니다. 야간 산업 창고·열린 시야·우회로·높은 차단벽·선반/조명/셔터·입고와 둥지를 구성합니다. `box`, `label`, `overview`, `marker` 인터페이스를 유지합니다. 컨베이어 제어기가 사용하는 방향 표시를 추가합니다.
- [x] `scripts/conveyor.gd`, F 조작/문구, 방장 이동 판정과 간결한 방향 동기화를 추가합니다. 반전 검증·직원/화물 이동·비활성/운반 제외·두 프로세스 일치를 검사합니다.
- [x] 화물을 든 채 양쪽 배송구까지 실제 통행, 입고 직통 투척 방지, 넓어진 가장자리 복구, 전체 회귀, 최대 전송 크기 1280바이트 이하, 실제 한국어/영어 화면을 검증합니다.
- [x] 0.6 한·영 실행 안내와 진입점/빌드 경로를 갱신합니다. Windows 패키지 내보내기·별도 폴더 실행·검토 후 main에 커밋합니다. v0.5.0은 보존하고 검증 후에만 v0.6.0을 만듭니다.

## 검증 기록

동작 검사 17개, 실제 두 프로세스 연결 시나리오 4개, 네 프로세스 시나리오와 SteamPipe 생성 도구 검사를 통과했습니다. 양쪽 배송구 중심까지 직원·운반 화물 경로, 입고 투척의 첫 접촉, 넓어진 경계의 복구, 컨베이어 거리·방향·시야·재사용 대기와 게스트 역전을 확인했습니다. 최대 검사 스냅샷은 1,280바이트로 현재 제한과 같습니다. 한국어·영어 메뉴와 레버 안내, 맵 전체·3인칭·배송구/둥지 화면을 실제 렌더링해 확인했습니다. Windows 내보내기와 실행 검사, 게임 스크립트 17개의 팩 포함 여부, 실행 파일·게임 팩만 둔 별도 폴더의 연습 화면도 확인했습니다.

검토에서 발견한 보너스/퇴장 시 벨트 표시 상태와 F 안내 조건 불일치를 수정했습니다. 경로 검사는 배송구 중심 Z -22까지 연장했습니다. 최초 실패한 구 맵 경계/배송 검사, 새 분류대에 닿은 바닥 전용 검사 위치, 높이 조건 추가 중의 타입 오류를 수정한 뒤 전체 검사를 다시 통과했습니다. 인증서 저장소·캐시/사용자 디렉터리 환경 경고는 스크립트 실패와 구분했습니다. 180초와 기존 목표량은 실제 재미·난이도 검증 전까지 유지합니다. 포장쥐 AI는 구현하지 않았습니다. 로컬 Git 0.6 기록과 태그를 남기며 기존 v0.5.0과 빌드는 보존합니다.
