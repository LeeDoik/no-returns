2026년 9월 7일. 목표: 0.5. 사용자가 단계별 승인 없이 기존 확장 프로토타입 계획까지 연속 구현하도록 승인했습니다.

## 제약

창고 하나, 고정 화물 네 종류, 방장 권한 ENet 구조를 유지합니다. 영문 게임 문구에는 완전한 한국어 대응본을 제공합니다. 기본 도형을 사용합니다. 소유권·복구·접속 종료 처리를 유지하고 전송 상태 크기를 제한합니다. Steam 계정 등록·결제·제출에는 사용자의 실제 계정이 필요하며 샘플 App ID를 대신 쓰거나 외부망 검증을 완료했다고 표시하지 않습니다.

## 작업

- [x] 점프 상자: 바닥에 놓이면 4초 대기, 1초 예고 후 전방 2.8m/s·위쪽 6.5m/s로 점프합니다. 들거나 공중에 있으면 시계를 멈춥니다. 착지하면 다시 4초 대기합니다. 움츠림·방향·일시 정지 표시와 상태 동기화를 구현하고 장애물 통과·수명주기·접착 조합을 검증합니다.
- [x] 배송: 화물 상한을 4개로 유지합니다. 최초 목적지는 A이며 성공한 배송부터 방장이 시드 기반의 균형 잡힌 A/B 묶음에서 다음 목적지를 배정합니다. 오배송·유실 복구는 목적지를 유지합니다. 1/2/3/4인 목표는 180초 동안 5/6/8/10개입니다. 테스트용 재현 시드를 지원합니다.
- [x] 위치 알림: Q로 가까운 보이는 화물 또는 전방 지점을 표시합니다. 방장이 검증한 뒤 보낸 직원 번호와 함께 전달합니다. 공동 표지 하나, 4초 유지, 직원별 1초 재사용 대기로 상태 크기를 제한합니다.
- [x] 결과·추가 근무: 배송 수·목표·경과 시간을 표시합니다. 성공 후 현재 직원 전원이 동의하면 60초간 3/4/5/6개를 더 배송하는 보너스 근무를 한 번 진행합니다. 보너스 시간 초과로 기본 성공을 잃지 않습니다. 재시작하면 투표와 근무 상태를 모두 초기화합니다.
- [x] 설정: 언어·신호음 음소거·마우스 감도를 저장합니다. 카메라 흔들림은 사용하지 않습니다. 지원 화면 크기에서 일시 정지 메뉴를 사용할 수 있게 유지합니다.
- [x] 배포: 일치하는 내보내기 템플릿을 사용할 수 있으면 깨끗한 Windows 포터블 테스트 패키지를 준비합니다. 그렇지 않으면 검증된 개발용 패키지와 정확한 내보내기 장애 요인을 기록합니다. 계정 비밀정보나 가짜 ID 없이 매개변수형 SteamPipe 파일을 준비합니다.
- [x] 로컬 동작·두/네 프로세스 동기화·전송 크기·실제 한국어/영어 화면·패키지·문서 대응을 검증합니다. 현재 문서 진입점을 갱신하고 남은 계정·외부망 검증 항목을 기록합니다.

## 검증 기록

로컬 확장 프로토타입 0.5를 완료했습니다. 동작 검사 15개·두 프로세스 시나리오 4개·네 프로세스 시나리오 1개·SteamPipe 생성 도구 검사가 통과했습니다. 전송 크기 검사: 1,272 / 1,280바이트. 실제 한국어/영어 화면과 내보낸 연습 화면을 확인했고 Windows 실행 파일·게임 팩에는 컴파일된 게임 스크립트 15개가 포함됩니다. 코어/최종 검토에서 퇴장 후 위치 알림 잔류·보너스 연결 검사의 점수 구성·공중에서 잡은 호퍼의 정지 표시를 수정했습니다. 별도 폴더 실행에서 누락된 간접 참조 스크립트를 발견해 내보내기 선택을 수정했으며 이제 패키지를 만들기 전에 실행을 검사합니다. Steam 친구 참가에는 계정/ID와 연동 검증이 필요하여 인계만 준비했으며 완료로 표시하지 않습니다. 0.1~0.4 안내서는 각각의 빌드 기록으로 유지합니다. 이 프로토타입은 상용 출시 준비 완료나 재미 검증을 의미하지 않습니다.
