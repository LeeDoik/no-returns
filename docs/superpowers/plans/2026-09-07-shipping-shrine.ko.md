## 방향

0.7.2의 맵 테마를 평범한 야간 창고에서 **배송 신전 / THE SHIPPING SHRINE**으로 변경한다. 배송 회사가 택배 업무를 우스꽝스럽게 신성시한다. 종교 실존 인물이나 실제 상징을 사용하지 않고, 골판지 신상과 서류 도장으로 만든 독자적인 직장 풍자다. 사용자의 병맛 컨셉 변경 및 단계별 승인 없는 진행 요청에 따라 바로 구현한다.

거대 주방은 조리 시스템을 기대하게 하고 놀이공원은 추가 탈것 비용이 크다. 배송 신전은 기존 계약·상자·A/B 배송을 그대로 이해할 수 있어 선택했다.

## 화면에 보여야 할 것

- 중앙 분류벽 위의 거대한 골판지 사장상: 왕관, 넥타이, 멍한 눈, 서류 도장. 첫 진입에서 보인다.
- 북쪽 A/B 배송구: 거대한 배고픈 얼굴과 입, 혀 모양 배송 바닥. 두 얼굴의 색과 표정을 다르게 하되 A/B 표시는 크게 유지한다.
- 오른쪽 포장쥐 둥지: 치즈 왕관과 이달의 직원 패널. 도둑이 우수 직원인 모순이 농담이다.
- 입고는 제물 접수, 벨트는 승진의 길, 사내 표어는 진지한 어조의 헛소리. 영어 원문과 한국어 대응 문구를 모두 게임에 넣는다.
- 보라색 벽, 따뜻한 크림/금빛, 청록·분홍 제단으로 실루엣과 색을 바꾼다. 높은 조명을 유지하고 화면을 하얗게 날리는 효과·점멸은 쓰지 않는다.

## 범위와 규칙

32×36m, 기존 벽과 낮은 칸막이, 양쪽 운반 동선, 배송 판정 위치, 벨트·쥐 행동·계약 수치는 유지한다. 새 장식은 운반 길과 배송구 앞 공간을 비우며 장식의 입 움직임은 피해나 배송 판정에 관여하지 않는다. 이 변경은 새로운 장애물 시스템이나 완성된 상업 아트가 아니다. 모든 모양은 Godot 기본 도형으로 제작하며 새 외부 에셋 의존성은 없다.

## 구현·검증 순서

1. `scripts/shrine_decor.gd`에 얼굴·사장상·표어·작은 반복 움직임을 분리한다. `depot.gd`에서 생성하고 기존 배경의 재질과 이름을 테마에 맞춘다.
2. 제목 메뉴와 버전 표시를 갱신한다. 장식 문구는 영어/한국어 전환을 따른다.
3. 실제 렌더링으로 전체·입구 3인칭·제단·쥐 코너를 보고 가림과 밝기를 수정한다.
4. 기존 맵 경로/투척/배송 검사, 컨베이어, 포장쥐, 캠페인 검사를 실행한다. 내보낸 팩에 장식 스크립트 포함 여부와 실행을 확인한다.
5. 0.7 실행 파일/ZIP 경로를 갱신하고 로컬 Git에 v0.7.2를 저장한다. 앱 이름은 유지해 설정·기록을 보존한다.


## 적용 결과

0.7.2 구현 완료. 실제 OpenGL의 한·영 메뉴, 입구 3인칭, 전체 맵, A/B 제단, 직원상 코너를 `artifacts/shrine-*.png`로 확인했다. 첫 렌더의 과한 밝기는 조정해 주변광 0.34, 방향광 0.52, 높이 6.5m의 점광원 0.4~0.55로 낮췄다. `test_night_depot`, `test_conveyor`, `test_packrat`, `test_campaign` 통과. 로그는 `artifacts/shrine-*.log`다. Windows 내보내기·실행과 게임 모듈 23개 팩 포함을 확인했고 실행 파일/팩만 별도 폴더에 둔 `build/pack-probe-0.7/artifacts/world.png`에서 새 테마가 렌더링됐다. 기존 Steam·외부 네트워크·독립 재미 검증 조건은 미완료로 유지한다.
