## Tasks

- [x] Hopper: grounded unheld rest 4 seconds, windup 1 second, forward hop 2.8 m/s and lift 6.5 m/s; holding/airborne pauses the clock. Landing begins another 4-second rest. Visible squash, direction and pause cue; replicate state and verify obstacle crossing, lifecycle and attachment interaction.
- [x] Shipments: preserve a four-cargo cap. Start with A destinations, then host-seeded balanced A/B batches after successful deliveries; wrong-bay and lost recovery retain destination. Targets for 1/2/3/4 workers: 5/6/8/10 in 180 seconds. Support a reproducible seed for tests.
- [x] Ping: Q marks a nearby visible cargo or a point ahead, host validates and broadcasts a short-lived marker with the sender's slot. One shared marker, four-second lifetime and one-second sender cooldown keep state bounded.
- [x] Results/overtime: show deliveries, target and elapsed time. After success, every current worker must opt in before one 60-second bonus shift with 3/4/5/6 extra deliveries. Base success survives bonus timeout. Restart clears all votes and shift state.
- [x] Settings: persist language, cue mute and mouse sensitivity; no camera shake is used. Keep pause menu usable at supported viewport sizes.
- [x] Distribution: prepare a clean Windows portable playtest package if matching export templates are available; otherwise provide a verified development package and record the exact export blocker. Prepare parameterized SteamPipe files without account secrets or fake IDs.
- [x] Validate local mechanics, two-/four-process replication, payload size, actual Korean/English rendered screens, packaging and document parity. Update current entry points and record remaining account/external-network gates.
