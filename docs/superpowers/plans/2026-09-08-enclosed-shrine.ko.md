# 실내 구역 개편 계획 · 0.7.6

[English](2026-09-08-enclosed-shrine.en.md)

목표: 48×60m 배송 신전을 출입구, 가려진 시야, 지붕이 있는 구역으로 나눠 배송 중 마주치는 상황을 다양하게 만든다. 기존 굽은 주 동선과 양쪽 연결길은 유지한다. Godot 4.7.2의 저장된 맵 씬을 수정하며 실행 시 재생성하지 않는다.

## 공간과 상황

- 접수·포장실: 높은 벽과 양옆 출구로 시작 지점을 감싼다. 서쪽 벽의 낮은 화물 창구는 상자만 통과하는 3×1.15m 개구부다. 동료는 창구 반대편에서 받거나 출입구로 돌아간다.
- 분실물 서고: 기존 선반 옆을 긴 벽과 부분 지붕으로 둘러싼다. 진입 후 꺾어야 다음 공간이 보인다.
- 무급 문지기 대기실: 중앙 문과 발판을 벽·높은 지붕 아래에 배치한다. 문 앞뒤의 가로 연결길과 양쪽 우회로는 계속 열어 둔다.
- 특급 바람 통로: 벨트 이후 출입구를 거쳐 지붕 아래 가로 바람을 만난다. 노란 예고등을 보고 기다리거나 상자를 운반한다.
- A/B 배송실: 출입구가 한쪽으로 치우친 벽 뒤에 배송구를 둔다. 마지막 코너에서 목적지가 드러난다.

신규 벽은 기본 5.2m, 부분 지붕은 기본 5.7m 높이이며 문지기 지붕은 올라가는 문과 겹치지 않도록 8.2m에 둔다. 천장 아래 보조 조명을 둔다. 고정 가구와 선반은 보존한다. 새 문구는 영어·한국어 대응본을 제공한다. 새 네트워크 상태나 상호작용 키는 추가하지 않는다. 쥐의 기존 활동 구역은 막지 않는다.

## 배치 검토에서 조정한 사항

출입구 옆 3곳의 벽을 조정해 기존 3m 운반 경로 검사를 유지했습니다. 실제 릴레이 던지기에 맞춰 창구 개구부를 바닥 위 1.8~2.95m로 올리고 던지기/받기 위치를 표시했습니다. 벽과 겹치는 접수 책상·분실물 더미·화분·배송실 가구를 이동했습니다. 바람실 안에서 읽도록 선풍기 얼굴과 안내판 방향도 맞췄습니다.

## 검증 기록

- 새 실내 검사: 기존 맵에서 시야·창구·카메라 조건 실패를 확인한 뒤 개편 맵에서 통과. 실제 물리 상자가 창구를 지나 약 7m 비행 후 동료에게 공중 릴레이로 인계됨을 확인했습니다.
- 전체 검사: 동작 검사 25개, 2인 프로세스 시나리오 8개, 4인 프로세스 시나리오 1개 통과. 마지막 화분 이동 후 운반 동선 검사를 다시 통과했습니다.
- 실제 렌더링: 직원의 3인칭 카메라로 접수실·서고·바람실·배송실과 전체 배치를 촬영해 벽, 지붕, 시야와 안내판을 확인했습니다.
- 읽기 전용 코드 검토에서 발견한 가구/화분 4개 묶음의 벽 겹침을 수정했습니다.
- 결과 파일: `build/NO_RETURNS_0.7/NO_RETURNS.exe`, `build/NO_RETURNS_0.7_Windows.zip`. 영어·한국어 플레이 안내가 동봉됩니다.
