# 배송 신전 확장 기획·작업 계획

[English](2026-09-08-shrine-expansion.en.md)

> **과거 기록 · 2026-09-12 폐기/대체.** 현재 게임은 [PSX 우주 배송 기획](../../current/01-overview.ko.md)을 따른다. 아래 구현·실행·아트·수치는 과거 자료이며 현재 상태가 아니다. 삭제된 파일은 경로 기록으로만 남긴다.


> 문서 체계 개정: 이 파일의 버전·수치는 작성 당시 기준입니다. 현재 규칙·미완료 상태는 [문서 홈](../../README.md)을 먼저 확인하세요.

목표: 0.7.4에서 저장 맵을 32×36m에서 48×60m(면적 2.5배)로 확장하고 경로 선택·협동·타이밍 도전을 추가한다. 사용자의 기존 단계별 승인 생략 요청에 따라 이 세션에서 구현과 검증까지 진행한다.

단순 면적 확대는 빈 이동 시간이 늘고, 층을 추가하면 카메라·쥐 길찾기 비용이 커진다. 이번에는 수평 3경로 확장을 선택한다. 입고 위치와 기존 남쪽 구역을 유지하고 배송구를 X±15, Z-43으로 옮긴다. 바닥 범위 X±24, Z-48…12. 두 번째 분류벽 Z-28, 양 끝 X±21의 열린 우회로, 중앙 폭 4m 문으로 동선을 구분한다. Z-18에 화물을 잠시 내려놓는 릴레이 집결장을 만든다.

중앙 '무급 문지기': 양쪽 발판을 직원 또는 내려놓은 상자로 누르면 문이 열린다. 발판에서 떠난 후 6초 유지하여 솔로도 달려 통과한다. 문 안의 직원/상자를 감지하면 닫지 않는다. 상자를 든 채 발판 밖에 서는 것은 추가 작동 조건이 아니다. 왼쪽 우회로는 항상 열린다.

오른쪽 '특급 바람 배송': 5초 대기 → 1.5초 황색 예고 → 2.5초 송풍을 반복한다. 바닥 화살표 방향으로 직원과 자유 화물을 민다. 바람을 이용해 화물을 보내거나 안전한 옆길을 선택한다. 들고 있거나 쥐에게 잡힌/접착된 화물에는 독립적인 힘을 가하지 않는다. 게임 종료·로비에는 장치 시간이 진행하지 않으며 새 계약에서 초기화한다. 설정과 장치 배치는 에디터에서 수정한다.

기술: Godot 4.7.2. saved PackedScene을 한 번 수정하며 실행 시 재생성하지 않는다. `scripts/route_challenges.gd`가 발판·문·바람 상태와 효과를 관리한다. main이 방장/솔로에서만 step을 호출한다. 기존 별도 메타데이터에 장치 상태를 담고 손님은 받은 상태로 표시/문 충돌을 갱신한다. 이동 패킷 예산 1,280바이트는 유지한다. 프로토콜 9로 이전 동작과의 혼용을 차단한다. 쥐의 기존 영역·계약 240초·화물 유형은 유지하고 실제 플레이를 보고 수치를 후속 조정한다.

## 완료 및 검증 · 2026년 9월 8일

동작 검사 23개, 실제 두 프로세스 시나리오 8개, 네 프로세스 시나리오가 통과했다. 좌우 우회로를 직원/화물 모양으로 검사하고, 출발점의 한 번 던지기로 배송구까지 갈 수 없음을 확인했다. 새 장치 검사는 문 충돌 해제, 직원/화물 발판, 6초 유예, 통로 점유 중 닫힘 방지, 송풍 예고·방향·소유권 보호, 온라인 표시/충돌 일치와 재시작을 다룬다.

초기 전체 검사 중 손님 이동 관찰의 시간 조건이 한 차례 실패했다. 해당 시나리오를 별도로 다시 실행해 통과했고, 최종 전체 검사도 통과했다. 최종 로그는 `artifacts/expansion-final-tests.log`, 초기 결과는 `artifacts/expansion-full-tests.log`, 개별 재확인은 `artifacts/network-expansion-recheck.log`이다. 새 발판 검사에 물리 프레임을 추가한 뒤 고정 화물의 이전 낙하 속도가 남는 시험 배치를 발견해 정지 속도를 명시했다. 실제 놓인 상자 조건은 유지했다.

장치 표시에서 문/색이 바뀔 때만 충돌·재질을 갱신하도록 했다. 이동 스냅샷 최대 검사 상태는 1,280바이트를 유지하며 별도 캠페인/장치 메타데이터는 2,048바이트 한도를 통과했다. 실제 렌더 캡처의 전체 배치·닫힌 문·열린 문·송풍기 표시를 확인했다. Windows ZIP 생성·패키지 시작·파일 해시·컴파일 스크립트 28개/맵 지문 검사가 통과했다. 증거: `artifacts/routes-capture.log`, `artifacts/routes-pack-audit.log`, `build/NO_RETURNS_0.7/SHA256.json`.

기존 실행 경로를 0.7.4로 갱신했고 한국어/영어 안내를 함께 수정했다. 사람 플레이로 배송 거리·계약 난이도·지름길의 실제 효용을 검증하는 일은 남아 있다. 이번 작업은 Steam 출시 완료를 의미하지 않는다.

독립 코드 검토에서 장치의 호스트 권한, 복제, 초기화, 소유권 보호와 통로 배치를 확인했으며 중대한 문제는 발견하지 못했다.
