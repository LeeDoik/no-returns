# 배송 분류선 연결 · 0.8.0

[English](2026-09-08-sorting-line.en.md)

## 결정

분리된 장치를 한 배송 상황에 모은다. 접수실에서 중앙 분류대로 상자를 보내는 8m 컨베이어를 만들고, 접수실 북쪽 벽에 바닥 화물용 통로를 낸다. 직원과 들고 있는 화물은 기존 문을 이용한다. 레일 출구에는 높이 0.6m 분류 턱을 둔다. 일반 화물은 동료가 인계하거나 재채기로 넘기며, 점프 상자는 스스로 넘어갈 수 있다. 걷는 기존 우회로와 기존 서쪽 던지기 창구도 유지한다.

접착 상자는 기존 5초 접착으로 다른 화물과 함께 이송하거나 점프 상자에 붙어 턱을 넘는다. 접착된 두 화물은 쥐가 분리해 훔치지 못한다. 접착이 풀리면 다시 노출된다. 재채기는 기존 방향·거리·벽 가림 조건으로 쥐를 3초 도망치게 하고 빼앗긴 화물을 내려놓게 한다. 경적은 기존대로 작동한다.

쥐는 중앙 분류대 오른쪽의 종이 둥지에서 시작해 레일 출구 주변만 순찰한다. 계약 2부터 등장하며 계약 1에도 둥지가 보여 이후 출현을 예고한다. 재고 소품을 치워 순찰·회수 길을 확보한다. 새 잠금 퍼즐이나 특정 화물이 없으면 못 가는 필수 길은 만들지 않는다.

Windows 내보내기와 패키지 실행, 컴파일된 스크립트 34개·저장 맵 검사, ZIP 8개 파일의 SHA256 검사가 통과했다. `artifacts/sorting-pack-audit.log`와 `build/NO_RETURNS_0.7/SHA256.json`에 패키지 식별자를 남겼다.
