## 목표와 판단

현재 화면은 큰 기본 도형, 강한 색, 공중의 농담 문구, 반복된 소품이 동시에 주목을 요구한다. 추가한 수량보다 선택과 완성도가 드러나도록 수정한다. 방향은 **낡은 배송센터가 억지로 신전 행세를 하는 곳**이다. 현실적인 시설을 바탕으로 살아 있는 상자와 배송구가 이상하게 느껴지게 한다. 이 작업만으로 모든 사람이 AI 느낌을 받지 않는다고 보장하지 않는다.

## 적용 규칙

- 배경은 콘크리트 회색, 낡은 크림색 벽, 짙은 녹회색 금속으로 제한한다. A/B의 청록·황토색은 길과 배송구를 구별할 때 사용한다. 화물과 직원의 색이 배경보다 잘 읽혀야 한다.
- 바닥 격자와 반복 농담을 줄인다. 표지판은 실제 벽·받침에 붙이고, 목적지·조작·위험 정보를 우선한다. 농담은 대표 사장상과 배송 장치에 집중한다. 멀리 있는 작은 글은 숨긴다.
- 벽 하단 보호판, 기둥 마감, 천장 보강재, 금속과 콘크리트의 미세한 재질 차이를 추가한다. 통로를 막는 새 충돌체는 추가하지 않는다. 가구와 방은 저장된 씬에서 직접 편집할 수 있어야 한다.
- 직원은 둥근 작업복, 모자, 장갑, 작업화, 반사띠와 사번으로 정리한다. 걸을 때 팔과 다리가 번갈아 움직인다. 충돌체, 이동 속도, 손 위치와 네트워크 상태는 유지한다.
- 실제 배송 화물은 골판지색과 종류별 테이프로 구별한다. 재채기·접착·점프 상태의 경고 정보는 유지하되 먼 거리의 작은 문구는 제한한다.

## 작업과 검증

- [x] `tools/direct_shrine_art.gd`로 저장 맵의 색·재질·마감·표지·조명을 정리한다. 실행/빌드 시 자동 재생성하지 않는다.
- [x] `scripts/worker.gd`, `cargo.gd`와 화물 표시 코드를 정리한다. 새 동작 규칙은 추가하지 않는다.
- [x] 동일한 플레이어 카메라로 변경 전후 화면을 비교한다. 한국어·영어 표지, 실제 화물 경고, 지도 편집과 운반·릴레이·온라인 동작을 검사한다.
- [x] 한국어·영어 안내를 갱신하고 Windows 빌드와 패키지를 검증한 뒤 로컬 `v0.7.7` 기준점을 만든다.

검수에서는 문구가 없는 상태에서도 공간의 용도와 목적지가 보이는지, 직원이 배경에서 읽히는지, 마감이 벽·출입구와 어긋나지 않는지를 본다. 최종 재미와 화면 인상은 실제 사람의 플레이테스트를 통해 계속 다듬는다.

## 검증 기록

- 동작 검사 25개, 2인 프로세스 시나리오 8개, 4인 프로세스 시나리오 1개 통과.
- 읽기 검토에서 발견한 운반 장갑의 회전 방향을 수정했습니다. 마지막 수정 후 화물 방향 검사를 재실행하고, 실제 렌더링에서 장갑이 상자 쪽을 향하는지도 검사했습니다.
- 동일한 카메라의 접수실·서고·바람실·배송실 및 전체 화면을 비교했습니다. 추가로 운반 자세와 영문 바람 표지 화면을 확인했습니다.
- 맵의 가시 문구는 104개에서 38개로 줄었습니다. 이 수에는 바닥 화살표가 포함되며, 실제 화물의 상태 경고는 별도로 유지합니다.
- 벽·바닥 질감은 0.92~1.0 밝기의 낮은 대비로 줄였습니다. 외부 유료 에셋이나 서비스를 추가하지 않았습니다.

- Windows 빌드·패키지 실행·28개 컴파일 코드와 맵 식별 검사 통과. 기존 EXE/ZIP 경로를 0.7.7로 갱신했습니다.
