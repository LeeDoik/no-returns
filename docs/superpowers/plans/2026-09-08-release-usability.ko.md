## 목표와 방향

Steam Windows 출시를 목표로 첫 실행, 설정, 게임 중 메뉴, 종료, 온라인 연결, 저장을 점검한다. 외형만 추가하는 방법, 전체 게임을 재작성하는 방법과 비교해 현재 게임의 실제 이용 흐름과 결함을 먼저 고친다. 기존 협동 배송과 직접 편집하는 맵은 보존한다. 단계별 승인 없이 구현·검증·패키지까지 진행한다는 사용자 지시를 따른다.

## 작업

- [x] 화면 점검과 실패 재현: 메뉴·도움말·설정의 한영 배치, 혼자 일시정지, 연결 승인 제한 시간, 독립 코드 검토 결과를 확인한다.
- [x] 메뉴와 설정: 첫 화면 및 게임 중에 설정 접근, 스크롤 가능한 설정·도움말, 화면 크기 대응, 명확한 키보드 포커스, 나가기·종료 확인과 복귀를 구현한다. `interface.gd`, 새 `settings_panel.gd`, `release_copy.gd`를 사용한다.
- [x] 조작과 환경: 충돌 검사와 취소를 지원하는 키 변경, 실제 바인딩을 반영한 안내, 감도·음량·시야각 슬라이더, Y축 반전, 수직 동기화·프레임 제한을 저장한다. `input_bindings.gd`, `preferences.gd`, `worker.gd`, 문구를 수정한다.
- [x] 일시정지와 연결: 솔로에서 물리·시간을 멈추고 온라인에서는 로컬 입력만 차단한다. 초점 이탈 후 자동 재개하지 않는다. 연결 승인 전 무한 대기를 막고 검토에서 확인한 게임 흐름 결함을 재현해 수정한다.
- [x] 동작 회귀, 두·네 프로세스 온라인, 한영 실제 렌더, Windows 내보내기·패키지 실행·내용 검사를 수행한다. 기존 맵 편집 구조를 유지한다.
- [x] 한영 안내와 출시 점검표를 실제 증거로 갱신하고 로컬 main 및 v0.7.9에 기록한다.

## 출시 판정

이 작업으로 Steam 출시 완료를 선언하지 않는다. 실제 Steamworks 등록과 App/Depot ID, Steam 친구 초대·중계 구현 및 두 PC 검증, 대상 하드웨어 성능, 외부 플레이테스트, 최종 아트·권리·상점·심사는 별도 미완료 항목이다. 상점에 적은 기능은 실제 출시 빌드와 일치해야 하며 상점과 빌드는 Valve 심사를 거친다. [공식 심사 절차](https://partner.steamgames.com/doc/store/review_process), [오버레이와 일시정지](https://partner.steamgames.com/doc/features/overlay). 확인일: 2026-09-08.

## 검증 기록

- 기존 결함을 먼저 재현했다. 솔로 시간·물리, 설정 진입, 승인 대기 제한, 완주 기록 재시도는 수정 전 실패하고 수정 후 통과했다. 손상된 설정 파일의 자료형은 수정 전 스크립트 오류를 일으켰고 수정 후 기본값 복구를 통과했다.
- 호스트의 다음 계약·추가 근무 시작, 게스트의 근무 시작, 설정 위 종료 확인 취소, 키 지정 대기 중 창 닫기, 연결 화면에서 준비된 대기실로 전환하는 키보드 포커스 회귀를 검사했다.
- 최종 전체 검사: 동작 검사 30개, 2인 시나리오 8개, 4인 시나리오 1개 통과. SteamPipe 미리보기 설정 생성 검사 1개도 통과했다. 온라인 검사는 같은 PC의 별도 프로세스이며 실제 Steam/외부 네트워크 검증은 아니다.
- 실제 한영 메뉴·설정·도움말·결과·일시정지·종료 확인 화면, 조작 설정 스크롤 끝, 1024×768 및 1600×900 화면을 렌더해 확인했다. 한영 UI 배치와 모달 뒤 키보드 포커스 차단 검사도 통과했다.
- 독립 코드 검토에서 보고한 연결 승인 대기, 저장 재시도, 계약 전환·중첩 메뉴 문제를 수정했고 해당 수정 경로를 재검토했다.
