# 4인 프로토타입 0.4 계획

[English](2026-09-07-four-players.en.md)

핵심 화물 세 종류 다음으로 기존에 승인된 기획을 이어간다. 기존 실행 환경과 ENet을 사용한다. 이번 단계에는 Steam·새 화물·유료 에셋·최종 밸런스를 추가하지 않는다.

- 방 하나에서 직원 2~4명을 지원하고 기존 혼자 연습을 유지한다. 방장 혼자서는 근무를 시작할 수 없다. 비교 조건을 유지하기 위해 화물 세 자리·배송 5개·180초는 그대로 둔다.
- 빈 자리 1~4를 배정하고 고유 색상·번호·겹치지 않는 시작 위치를 사용한다. 재참가자는 빈 자리를 사용하며 남아 있는 직원의 번호는 바꾸지 않는다. 호스트가 배정한 자리를 전송한다.
- 손님이 나가면 현재 근무를 취소하고 모두 대기로 돌아간다. 방장은 남은 2~4명으로 재시작할 수 있다. 방장 이전·근무 중 참가는 없다. 정원이 찬 방은 ENet 접속 수 제한으로 추가 참가를 거부한다.
- 직원 위치 상태를 간결한 배열로 전송해 4명·화물 3개에서도 상태 크기 상한 1280바이트를 유지한다.
- 개발용 창 네 개를 여는 PLAY_FOUR.cmd를 추가한다. 기존 실행기와 2인 검사는 유지한다.

## 작업

- [x] 2·3·4인 시작 조건, 고유 자리·위치, 빈 자리 재사용과 패킷 상한의 실패 검사를 먼저 추가한 뒤 session/main/worker/UI를 구현한다.
- [x] 시간 제한이 있는 실제 네 프로세스 검사로 같은 참가자·자리, 소유권, 접착·재채기 결과, 배송과 퇴장·재시작을 검증한다. 독립 테스트 담당자는 subagent-driven-development를 사용하고 주 담당자가 코드를 통합할 수 있다. requesting-code-review로 검토한다.
- [x] 전체 회귀 검사와 에디터 가져오기를 실행하고 실제 한국어·영어 메뉴와 직원 네 명의 화면을 확인한다.
- [x] 0.4 전체 대응 안내서와 README·Steam 현재 상태를 갱신한다. 인터넷·Steam·사람의 재미·성능은 미검증으로 둔다.

완료: 전체 검사와 에디터 가져오기가 종료 코드 0으로 끝났다. 네 참가자의 같은 소유권·접착·두 직원 재채기 적중·배송과 3인 재시작을 확인했다. 최대 상태 크기는 1036바이트다. 한국어·영어 렌더러 캡처를 확인했다. 제한은 [0.4 안내](../../prototype/04-four-players.ko.md)에 기록했다.
