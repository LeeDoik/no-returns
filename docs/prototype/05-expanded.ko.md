# 반품 불가 — 확장 플레이테스트 0.5

[English](05-expanded.en.md)

> 문서 체계 개정: 이 파일의 버전·수치는 작성 당시 기준입니다. 현재 규칙·미완료 상태는 [문서 홈](../README.md)을 먼저 확인하세요.

2026년 9월 7일. Windows x64, Godot 4.7.2. 기본 도형을 사용하는 개발용 플레이테스트이며 Steam 출시 후보 빌드는 아닙니다. 게임 문구 원문은 영어이며 기본 UI는 한국어입니다.

## 시작하기

Windows 배포 폴더에서는 **NO_RETURNS.exe**를 두 번 클릭합니다. 개발 프로젝트에서는 **PLAY.cmd**를 사용하며 **PLAY_TWO.cmd**, **PLAY_FOUR.cmd**는 같은 PC에서 두 개 또는 네 개의 창을 엽니다. 기존 게임 창은 먼저 닫습니다. 혼자 연습하기를 선택하거나, 한 명이 방을 만들고 나머지가 방장 주소를 입력합니다. 직원 수가 표시되면 방장이 근무를 시작합니다. 2~4인을 지원하며 1인은 연습 모드입니다.

배포 패키지는 실행 파일, `.pck` 게임 데이터, 양쪽 언어 안내서, 제3자 고지, SHA256 목록으로 구성됩니다. 같은 폴더에 보관하세요. 내보낸 패키지는 에디터 설치가 필요 없습니다. 서명되지 않은 파일이므로 Windows에서 게시자·평판 경고가 표시될 수 있습니다. 신뢰하는 프로젝트 출처에서 받은 빌드만 사용하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 둘러보기 |
| Space | 점프 |
| E | 집기·가까운 화물 받기·내려놓기 |
| 왼쪽 클릭 | 들고 있는 화물을 접촉 예상 표지 쪽으로 던지기 |
| Q | 전방의 가까운 보이는 화물 또는 앞쪽 지점 알리기 |
| Esc | 메뉴 열기; 온라인 시뮬레이션은 계속 진행 |

첫 메뉴에서 언어를 변경할 수 있습니다. 첫 메뉴나 쉬어가기 메뉴에서 신호음을 끄고 켭니다. 쉬어가기 메뉴에서 마우스 감도를 0.50~2.00배 사이에서 0.25배씩 순환 변경합니다. 설정은 로컬에 저장됩니다. 카메라 흔들림은 사용하지 않습니다. 화살표와 A / B 라벨로 색상을 보완합니다.

## 배송과 목표

화물의 A 또는 B 라벨에 맞는 배송구로 보냅니다. 최초 화물의 목적지는 A입니다. 배송에 성공한 뒤 돌아오는 다음 화물에는 방장이 시드로 섞은 A 두 개·B 두 개 묶음에서 목적지를 배정합니다. 네 종류 화물은 계속 이용할 수 있으며, 종류 자체를 바꾸는 대신 목적지 순서를 변화시킵니다. 화물 개체는 최대 네 개입니다. 칸막이를 돌아가는 일반 운반 경로는 항상 존재합니다.

잘못 보낸 화물과 구역 밖으로 떨어진 화물은 1.2초 뒤 점수 없이 돌아오며 목적지가 바뀌지 않습니다. 배송 성공은 한 번만 계산합니다. 복구 시 접착을 해제하고 준비 중인 동작을 취소합니다. 제한 시간은 180초이며 **1 / 2 / 3 / 4인** 목표는 **5 / 6 / 8 / 10개**입니다. 초기 조정값이며 검증된 난이도가 아닙니다. 결과 화면의 배송 시드는 `-- --seed=숫자` 실행 인자로 재현할 수 있습니다. 목적지 순서만 재현하며 모든 물리 결과나 재채기 간격까지 같아지는 것은 아닙니다.

## 화물 네 종류

- **일반 상자(Standard):** 일반적인 운반·던지기 화물입니다.
- **재채기 상자(Sneezer):** 1.5초 예고 후 짧은 전방 재채기를 합니다. 직원과 화물을 밀고, 들고 있던 화물을 놓게 하며, 접착을 해제합니다. 재채기 상자를 든 직원은 자기 상자의 재채기에 밀리지 않습니다. 코와 방향 예고를 보세요. 이후 대기 간격은 6~9초입니다.
- **접착 상자(Clinger):** 0.95m 이내의 직원 또는 화물 하나에 최대 5초 붙습니다. 붙잡힌 직원은 70% 속도로 이동합니다. 재채기로 떼어낼 수 있으며 분리 후 재접착 대기는 2초입니다. 두 화물이 모두 해당 배송구와 목적지가 같을 때만 함께 배송됩니다. 목적지가 다른 짝은 점수 없이 돌아옵니다. 연쇄 접착은 없습니다.
- **점프 상자(Hopper):** 주황색 화물입니다. 바닥에서 4초 쉬고, 1초간 움츠려 예고한 뒤 전방 2.8m/s·위쪽 6.5m/s로 점프합니다. 들면 주기가 멈추며 공중에서는 추가 점프하지 않습니다. 착지하면 다시 대기합니다. 들고 방향을 맞춘 뒤 낮은 칸막이 앞에 내려놓아 넘겨보세요. 화살표는 방향을 표시하며 착지점을 보장하지 않습니다.

일반 던지기 표지는 첫 정적 접촉을 예상합니다. 그 뒤 화물의 동작 때문에 최종 착지 위치가 달라질 수 있습니다. 점프와 접착을 함께 활용할 수 있지만 붙은 화물이 장애물에 닿으면 접착이 풀릴 수 있습니다.

## 위치 알림과 추가 근무

Q를 누르면 보낸 직원 번호와 함께 4초간 공동 표지 하나가 나타납니다. 직원별로 1초에 한 번 갱신할 수 있습니다. 새로 승인된 표지가 기존 표지를 대체합니다. 화물 표지는 선택한 화물을 따라가며 위치 표지는 선택한 지점에 남습니다. 간단한 협업 도구이며 음성 채팅은 아닙니다.

목표 달성 시 배송 수·목표·경과 시간·배송 시드가 표시됩니다. 현재 직원 전원이 **추가 근무?**에 동의하면 60초 보너스 근무를 한 번 진행합니다. **1 / 2 / 3 / 4인** 추가 목표는 **3 / 4 / 5 / 6개**입니다. 보너스 시간이 끝나도 기본 근무 성공은 유지됩니다. 방장이 대신 다시 근무하기를 선택하면 점수·투표·목적지·시간을 초기화합니다. 보너스를 연속으로 반복할 수는 없습니다.

## 연결 제한

한 사람의 게임이 판정을 담당하는 서버이며 별도 호스팅 서비스는 구성하지 않았습니다. 개발용 통신은 ENet UDP **27842** 포트입니다. 같은 PC는 `127.0.0.1`, 같은 네트워크에서는 방장의 LAN 주소로 테스트합니다. 인터넷 직접 연결은 공유기 포트 전달과 방화벽 설정이 필요할 수 있습니다. Steam 초대·NAT 중계·방장 이전·근무 도중 참가는 구현하지 않았습니다. 로컬 테스트 결과만으로 간편한 인터넷 플레이를 보장하지 마세요.

손님이 나가면 들고 있던 화물을 놓고 남은 직원은 대기실로 돌아갑니다. 방장이 현재 인원으로 재시작합니다. 방장이 나가면 모두의 세션이 끝납니다. 연결 시도는 10초 후 시간 초과됩니다. 파티에서는 동일한 0.5 빌드를 사용하세요. 같은 PC의 여러 프로세스 검증은 실제 국가 간 지연이나 별도 네트워크 연결을 입증하지 않습니다.

## 검증과 남은 작업

자동 검사는 소유권·던지기와 접촉 표지·양쪽 배송구·복구·네 화물 동작·시드 목적지·인원별 목표·위치 알림·투표·보너스 시간 초과·재시작을 확인합니다. 두/네 프로세스 검사는 소유권·재채기/접착 조합·인원 변경·접속 종료의 동기화를 확인합니다. 동작 검사 15개·두 프로세스 시나리오 4개·네 프로세스 시나리오가 모두 통과했습니다. 확장 연결 검사는 호퍼를 든 동안 정지·도약, B 목적지·배송, 손님의 위치 알림, 호스트·손님 모두 점수 6 / 목표 10으로 전원 동의 후 보너스 시작을 확인했습니다. 의도적으로 상태를 채운 최대 검사 스냅샷은 1,272바이트(제한 1,280)입니다. 실제 한국어/영어 메뉴·결과, 설정, 호퍼 표시를 확인했습니다. 실행 파일과 게임 팩만 둔 별도 폴더에서 내보낸 실행 파일의 연습 화면을 렌더링했으며 팩 안의 컴파일된 게임 스크립트 15개를 검사했습니다. SteamPipe 생성 도구 검사도 통과했습니다. 샌드박스의 인증서 저장소·사용자 디렉터리/캐시 경고는 스크립트 실패와 구분하여 기록합니다. 실제 별도 PC와 Steam 검증은 남아 있습니다.

Steamworks 등록·실제 App ID·호환 Steam 통신 연동·실제 계정 두 개와 별도 PC/네트워크 검증·최종 아트·트레일러·상점 공개·Valve 심사는 남아 있습니다. 결제·업로드·출시는 진행하지 않았습니다. 테스트 참여자에게 사고의 원인을 설명할 수 있는지, 빠르게 수습할 수 있는지, 유용한 조합이 있는지 물어보세요. 자동 검사 성공으로 재미를 판단할 수는 없습니다.

## 0.5 수정 — 들고 있는 상자 방향

상자 몸체와 라벨이 운반자의 방향을 따라 회전하도록 수정했습니다. 재채기 얼굴은 몸체 회전을 한 번만 따르며 예고 방향과 일치합니다. 네 종류의 상자, 게스트 수신 상태, 던진 뒤 방향 유지와 복구 시 방향 초기화를 회귀 검사합니다. 같은 경로의 Windows 실행 파일과 ZIP도 갱신했습니다. 이전 게임 창을 닫고 다시 실행하세요.

## 0.5 수정 — 직원과 화물 충돌

직원과 화물이 서로 충돌합니다. 바닥 화물을 걸어서 통과할 수 없고, 날아오는 화물과 동료가 든 화물에도 닿습니다. 운반자는 자기 상자에만 충돌 예외를 적용하며 내려놓기·던지기·복구 시 해제합니다. 운반 위치 검사도 자기 몸을 제외하여 상자를 집고 이동할 수 있습니다. 붙어 있는 접착 상자는 기존 접착 추적 처리를 유지하며 분리되면 직원 충돌을 복구합니다. 충돌·운반·해제 회귀 검사와 기존 두/네 프로세스 검사를 통과했고 실행 파일과 ZIP을 갱신했습니다.
