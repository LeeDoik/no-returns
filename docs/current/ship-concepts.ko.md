# 우주선 외형 비교 — 4안

[English](ship-concepts.en.md)

2026-09-13 · A / FLATBED 외형 방향을 사용자가 선택했다. CINDER DEPOT 참고 이미지의 낡은 PSX 산업 시설과 같은 도장·질감·조명 계열을 사용한다. 1~4인과 화물 운반이 가능한 실내를 전제로 하지만 치수·실내 배치·충돌·리깅을 검증한 설계도는 아니다.

| 안 | 방향 | 비교할 점 |
|---|---|---|
| A / FLATBED | 낮고 넓은 화물선, 후방 램프 | 귀환 실루엣·넓은 화물실·낮은 진입 동선 |
| B / CONTAINER | 컨테이너형 선체, 측면 램프 | 시설 모듈 재사용·직선 실내·측면 출입 |
| C / TUG | 비대칭 조종실을 가진 산업 견인선, 전방 램프 | 개성 있는 외형·정면 화물 접근·후방 엔진 |
| D / HOPPER | 세로로 쌓인 착륙선, 낮은 하부 출입 | 수직 실루엣·착륙 다리·화물실 높이 |

상아색 도장·주황 띠·녹슨 금속·어두운 기계부·황색 작업등으로 통일한다. 출입구에 사람을 배치해 규모를 비교한다. 항로 선택 후 자동 이동·착륙 규칙은 그대로이며 비행 기능을 추가하지 않는다.

선택 후 해당 안의 전후좌우·내부 동선·램프와 장비 선반 제작용 시트를 만든다. 외형 승인 전 3D 모델 생성은 진행하지 않는다. 이번 작업은 이미지 비교용 시안과 문서만 만들며 게임 코드·모델·빌드는 변경하지 않는다.

![Ship comparison](../../art/ship-concepts-01/ship-comparison-01.png)

4안 비교 시트를 생성하고 실루엣·출입구·사람 크기 표시를 시각 검토했다. 사용자가 A를 선택했다. B/C/D는 비교 이력으로 보존한다. D의 하부 출입 높이와 모든 안의 4인 실내 동선은 후속 치수 설계가 필요하다. 그림만으로 운반 가능성을 검증하지 않는다.

## A 선택·4면 시트

사용자가 A안을 선택하고 전후좌우 이미지를 요청했다. 화물 개구부와 램프를 후면으로 정의한다. 정면은 그 반대의 닫힌 낮은 선체다. 좌측도는 기수가 왼쪽, 우측도는 기수가 오른쪽을 향한다. 보이지 않았던 정면과 측면 세부는 A의 실루엣을 바탕으로 확장한 제안이며 기계적으로 검증한 CAD 투영이 아니다. 3D 모델 제작·게임 적용은 이번 작업에 포함하지 않는다.

![A four views](../../art/ship-concepts-01/flatbed-four-views-01.png)

정면·후면·좌측·우측 시트 생성 완료. 후면 개방 램프와 측면 기수 방향을 확인했다. 생성 이미지의 상부 높이·착륙 지지대·세부 패널은 투영 간 정확히 일치하는 기술 도면으로 취급하지 않는다. 모델링 전 공통 치수와 지지대 배치를 하나의 구조로 정리해야 한다.
