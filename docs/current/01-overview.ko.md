# 1. 게임 개요

[English](01-overview.en.md)

검토일: 2026-09-09 · 게임 0.9.4 · 코드 기준: 이번 반응 장치 수정본.


## 확정된 방향

NO RETURNS(반품 불가)는 살아 있는 택배를 배송하는 3D 3인칭 협동 게임이다. 혼자 또는 최대 4명이 같은 목표를 완수한다. 시청자가 캐릭터의 사고와 동료의 대응을 함께 볼 수 있는 방송 친화적인 상황을 목표로 한다. 고의적인 배신을 중심으로 한 PvP가 아니다. 게임 문구는 영어 원문과 한국어 UI를 유지한다.

핵심 흐름은 화물 특성 확인 → 운반 경로 선택 → 들기·던지기·받기와 장치 활용 → A/B 배송 → 공동 보상 → 장비 선택 → 다음 계약이다. 재채기·접착·점프 화물, 포장쥐, 환경 장치가 동료와의 사고와 수습을 만든다. 이 흐름의 구현과 실제 재미 검증은 별개다.

## 제작 범위

현재 본편 맵은 배송 신전 1개이며 독립 물리 실험실이 있다. Windows/Steam 출시를 목표로 Godot 4.7.2에서 개발한다. 현재 실행본은 개발용 0.9.4으로 출시 후보가 아니다. 본편 물리는 기존 운반 방식이다. Human: Fall Flat 참고 힘 기반 잡기는 사용자 요청으로 되돌렸으며 현재 기능이 아니다.

우선순위는 핵심 조작·애니메이션, 맵의 선택과 상황, 실제 4인 재미 검증, 접속·출시 경험이다. 추가 맵, 전신 래그돌, Unity 이전은 확정 범위가 아니다. Steam 연동·상점 심사 완료를 약속하지 않는다.

## 확장 방향 탐색

2026-09-09 사용자 요청에 따라 배송지까지의 이동, 매번 달라지는 맵과 더 넓은 게임 구조를 기획 후보로 검토한다. 현재 맵·기능 수를 장기 규모의 상한으로 취급하지 않는다. [배송 원정·로드트립·도시 생활 비교](08-expansion-directions.ko.md)는 제안이며 현재 구현이나 출시 범위 확정과 구분한다.

## 품질 판단 기준

[MDA 분석](07-mda.ko.md)은 현재 구현의 핵심 재미를 동료와의 사고 수습(Fellowship), 운반 숙련(Challenge), 경로·장치 해법 발견(Discovery)으로 해석한다. 화물·계약·캠페인 루프를 구분한 분석 가설이며 실제 재미 검증 완료를 의미하지 않는다.

성공 기준은 처음 하는 사람이 목표를 이해하고, 동료와 의도적인 협동을 시도하며, 실패 이유를 납득하고 다시 플레이하려는가이다. 자동 검사 개수나 주관적 완성도 백분율은 출시 승인 기준이 아니다. [현재 명세](02-spec.ko.md), [미완료 목록](04-backlog.ko.md), [검증 기준](05-validation.ko.md)을 함께 본다.
