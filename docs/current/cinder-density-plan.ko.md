# CINDER 시설 밀도 확장 계획

[English](cinder-density-plan.en.md)

2026-09-21 · CINDER-DENSE-02 · 사용자 승인: 크기를 줄이지 않고 실제 시설처럼 채운다.

기존 108×86.4m 바닥과 우주선 크기를 유지한다. 별도 원본 블록아웃을 보존하고 배송 데모의 건물·동선만 재구성한다. 건물 내부를 기능별 방과 복도로 나누고, 여러 출입구·골목·연결 통로로 안팎을 순환하게 한다. 화물 통과 폭과 배송 목적지·단말기 좌표는 유지한다. 소품 수가 아닌 공간과 시야의 분절을 목표로 한다.

- [x] `CinderDenseBuild`에 창고·검문소·분류동·사무실·수령동·설비동·보관동과 외곽 설비, 방·복도·작업 마당을 제작한다. 검사: 원래 크기, 출입 연결, 화물 폭, 긴 시야 차단, 선내 왕복.
- [x] 기존 CarryThreat/CarryRoom을 확장해 리스너 A/B/C 3체를 호스트에서 계산하고 전원에게 복제한다. 다운·구조·충격봉 재사용 시간을 한 번만 계산하고 외곽 생물·기존 시험을 보존한다. Cinder 프로토콜은 12로 올린다.
- [x] Unity 플러그인 CLI로 생성·검사·렌더·Windows 빌드. 실제 프로세스에서 배송·영수증·귀환 및 복수 적 상태 일치·구조를 검사한다.
- [x] 한영 명세·가이드·백로그·검증·변경 이력을 갱신하고 작업 범위만 커밋·푸시한다.

검증은 자동 경로·상태 검사와 사람의 긴장·길 찾기·유인 협동을 구분한다. 억제 시간·경제는 이번에 변경하지 않는다. 최종 아트와 문 개폐·다층 AI는 별도 범위다. 기존 재질 변경 8개와 복구 장면은 보존한다.
