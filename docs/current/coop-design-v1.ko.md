# NO RETURNS — 협동 플레이 통합 기획 v1

[English](coop-design-v1.en.md)

2026-10-05 · 기획 기준 NR-COOP-01 · 구현 완료 아님

## 상태와 우선순위

사용자의 2026-10-04~05 질답과 “더 묻지 말고 끝까지 기획” 위임을 통합했다. **[선택]**은 사용자가 직접 고른 규칙, **[보완]**은 위임에 따라 작성한 초기 설계다. 보완은 별도 사용자 승인이나 재미 검증 완료를 뜻하지 않는다. 아래 수치는 모두 **[보완·초기 튜닝값]**이며 현재 코드에서 추출한 값이 아니다.

새 제작의 목표 규칙은 이 문서가 우선한다. 기존 개요·경제 초안·생물 실험과 충돌하면 이 문서를 적용하되, [현재 구현 명세](02-spec.ko.md)의 과거 검증 결과를 새 규칙의 구현 증거로 쓰지 않는다. 이번 변경은 문서뿐이며 게임 버전은 올리지 않는다. 반복 질답은 종료하고, 이후 구현과 실제 플레이에서 발견한 문제로 수정한다.

## 1. 게임의 약속

[선택] 1~4인 1인칭 우주 배송 협동 게임. 공포와 긴장이 먼저이고, 팀원의 실수와 대응에서 웃음이 나온다. 화물 조작은 단순하게, 위험은 환경·생물·팀의 행동에서 만든다. 직원과 생물을 희화화하지 않는다. 회피·유인·일부 전투 모두 허용하지만 강한 생물을 사격으로 정리하는 게임은 아니다.

[선택] 고정 직업 없이 장비로 역할을 나눈다. 대체로 같이 이동하며 운반·정찰·유인·시설 조작을 분담한다. 돈은 새로운 장비 선택지와 우주선 꾸미기에 쓰며 수치 강화 트리는 제외한다. 미스터리는 발견하는 배경 이야기이며 필수 추적 과제나 엔딩은 없다.

[보완] 성공의 단위는 모든 화물을 끝내는 것이 아니라 **위험을 판단해 일부 수익을 가져오는 한 번의 철수**다. 한 장소 목표 체류는 15~20분. 여러 장소 방문이 이어지지만 일일 할당량·부채·강제 캠페인 초기화는 두지 않는다. 낡고 더러운 PSX 산업 공간, 열린 하늘과 밀집 골목, 뚜렷한 외곽/내부 경계를 유지한다.

## 2. 한 번의 방문과 계약

[선택] 우주선 준비 → 후보 장소 선택 → 자동 이동/착륙 → 배송 선택/탐색 → 수령 확인/영수증 → 추가 배송 또는 철수 → 정산/구매. 직접 조종은 없다. 장소는 모두 처음부터 선택 가능하며 먼 곳은 이동 비용이 필요하다. 무료 장소는 항상 남는다. 출발 전에 환경·대략적 위험·기본 배송 건수와 각 보상을 공개한다. 생물 종류와 보너스는 공개하지 않는다.

[선택] 기본 화물은 우주선에 전부 실려 있다. 목적지의 구역만 안내하고 건물 번호와 표지판으로 수령대를 찾는다. 원하는 배송만 수행하며 미완료 위약금은 없다. 멀고 위험한 배송일수록 보상이 높다. 한 구역의 기본 배송이 마지막 한 건 남으면 우주선 단말기에 남은 건과 묶음 보너스를 공개한다. 글로벌 알림/회사 무전은 없다.

[보완] 구역 보너스는 해당 방문의 기본 배송 묶음만 계산한다. 숨겨진 추가 배송은 묶음 조건을 바꾸지 않는다. 누가 읽어도 단말기는 동일 상태를 보여준다. 우주선에는 구역 지도와 주소 목록을 제공하되 정확한 수령대/생물 위치를 HUD에 표시하지 않는다. 주소 표지·돌아오는 길·카트 우회로는 읽을 수 있어야 한다.

[선택] 큰 지형은 고정이고 배송·생물 배치 및 일부 길/출입구가 방문마다 변한다. 현장 장치와 절단기로 길을 열 수 있다. 일반 배송은 특정 장비 없이 가능하고 일부 보너스 구역만 특정 장비를 요구한다. 보너스 구역에서 추가 배송 화물, 이야기 단서, 꾸미기 수집품을 발견한다.

[보완] 모든 기본 목적지에 걸어서 갈 수 있는 경로를 생성 검증한다. 카트 경로는 전부 보장하지 않되 하역 지점을 둔다. 추가 배송은 현장에서 목적지/보상을 확인한 뒤 운반하며 위약금은 없다. 단서는 발견 즉시 팀 기록에 영구 저장하고 꾸미기 수집품은 소형 퀘스트 물품으로 챙겨 정상 철수해야 획득한다. 전멸 시 미반입 수집품은 잃고 이미 발견한 서사 기록은 남는다.

## 3. 화물·수령대·카트

[선택] 손에는 화물 하나. 운반 중 이동과 간단한 문/버튼 조작은 가능하지만 진압봉·특수 장비·구조는 내려놓은 뒤 사용한다. 화물은 충격/공격으로 파손되지 않는다. 수령대에 놓으면 자동 확인과 유인 소음이 시작된다. 팀이 떠나도 계속되며, 화물을 집으면 작업과 소음이 멈추고 같은 수령대에 다시 놓으면 이어진다. 완료는 현장 소리/표시등으로만 안내한다. 생물은 확인 결과나 영수증을 훼손하지 않는다. 버튼 한 번으로 영수증을 즉시 회수하면 팀 전체에 배송 완료가 등록되고 별도 실물 운반은 없다. 회수자가 쓰러져도 기록은 남지만 전멸하면 돈은 잃는다.

[보완] 화물 ID와 수령대가 일치해야 시작하며 잘못 놓으면 소음 없이 주소 오류를 표시한다. 확인 도중 생물이 와도 자동 중단하지 않는다. 완료 소리는 주변 생물에게도 들린다. 영수증은 한 번만 지급하고 중복 회수·재접속으로 보상을 복제할 수 없다. 진행도는 해당 화물/수령대 쌍과 방문에 귀속된다.

[선택] 카트는 팀 공동 구매이며 개인 슬롯과 별개. 소음이 크고 계단/좁은 길을 통과하지 못하며 미는 동안 무기/장비를 사용할 수 없다. 쓰러진 동료도 실을 수 있다. 현장에 남긴 카트는 전멸 여부와 관계없이 분실하고 우주선 적재 구역에 복귀시켜야 보존된다.

[보완] 초기 카트는 팀당 1대, 화물 3칸. 쓰러진 동료는 2칸을 쓰고 여러 동료는 동시 탑승 불가. 적재 버튼으로 고정해 물리 흔들림/자잘한 균형 잡기를 난이도로 쓰지 않는다. 영수증은 카트 없이 회수 가능하다. 낙하 구조물은 카트를 즉시 삭제하지 않고 이동을 막을 수 있어 짐을 내려 우회한다. 발판/잔해가 유일한 귀환로를 영구 차단하지 않게 설계한다.

## 4. 위험 단계와 출발

[선택] 시간에 따라 안개가 짙어지고 제어기 단계가 진행되어 외곽 생물이 배송 구역에 들어온다. 플레이어는 진행을 늦추거나 되돌릴 수 없다. 우주선 재정비 중에도 계속된다. 숫자 타이머/단계 HUD 대신 안개·장치 소리·생물 움직임으로 읽는다. 소음·전투·시설 조작은 추가 위험을 만든다.

[보완] 소음은 주변 AI를 자극하지만 제어기의 세계 시간을 가속하지 않는다. 환경 반응과 전역 시간압박을 분리해 원인을 학습할 수 있게 한다. 단계는 안정 → 감쇠 → 침입 → 최종 출발. 한 명만 남았다고 단계가 초기화되거나 느려지지 않는다. 생물은 지정 외곽 진입로를 이용하고 플레이어 바로 옆에 생성하지 않는다.

[선택] 마지막 단계에서는 방송·경적·엔진 시동으로 자동 출발을 예고하고 정확한 남은 초는 표시하지 않는다. 자동 출발은 취소 불가. 수동 출발은 우주선 안에서 누구나 시작/취소 가능하며 밖의 동료를 두고 떠날 수 있다. 생물이 따라와도 출발 가능하다.

[보완] 자동 출발이 수동 취소보다 우선한다. 수동 출발에도 방송/엔진과 탑승 현황을 표시하되 최종 출발 시간은 연장하지 않는다. 이륙 시각에 탑승 판정을 한 번 확정한다. 살아 있는 탑승자, 쓰러진 채 선내에 실린 동료, 진행 중인 유료 부활 대상은 유효 탑승자로 인정한다. 다운된 탑승자는 출발 후 구조 상태로 돌아와 낮은 체력을 유지한다. 밖에서 다운/탈락한 사람은 탑승자로 세지 않는다.

[선택] 살아 있는 사람이 전부 탈락해도 유료 부활이 진행 중이면 그 부활은 완료된다. 출발 시 진행 중인 부활만 있어도 정상 철수다. 탑승자와 진행 중 부활이 모두 없으면 현장 실패로 미정산 보상 전액을 잃는다. 유효 철수에서 남겨진 동료는 복귀 비용을 공제하고 합류하며 개인 소지 장비는 보존한다.

## 5. 체력·구조·부활·정산

[선택] 협동은 첫 다운에 구조 가능, 두 번째 다운에 즉시 탈락. 구조 제한 시간이 지나도 탈락한다. 동료를 끌거나 카트에 실어도 제한 시간은 계속된다. 끄는 동안 장비/진압봉 사용 불가. 구조 후 낮은 체력이지만 정상 행동 가능하며 짧은 무적 시간이 있다. 솔로는 착륙당 자가 소생 2회, 낮은 체력으로 일어나고 동일한 보호를 받는다. 자가 소생은 협동에 없다.

[선택] 생존자가 우주선 장치에서 한 명을 선택하면 부활이 자동 진행되고 자유롭게 움직일 수 있다. 한 번에 한 명만 처리한다. 미정산 보상이 비용보다 적으면 실행 불가하며 기존 자금은 사용하지 않는다. 완료 시 체력과 다운 횟수를 초기화한다. 치료품/미끼 소모는 복구하지 않는다. 체력은 자동 회복되지 않고 무료 선내 치료는 없다. 살아서 철수하면 부상은 유지된다. 치료품은 즉시 완전 회복하지만 다운 횟수는 초기화하지 않는다.

[보완] 부활 시작 시 미정산 금액에서 비용을 즉시 예약·공제하고 중복 선택을 차단한다. 임의 취소/환불은 없다. 이륙 시 진행 중 부활은 끝까지 완료하고 이중 비용을 받지 않는다. 현장 실패/철수 후 합류하는 탈락자는 완전한 체력으로 돌아오지만 미사용 소지품만 복귀한다. 무료 실패 복구는 돈을 생산하지 않는다. 다운 횟수는 다음 착륙에도 초기화되나 생존자의 체력은 유지된다. 솔로 자가 소생은 횟수만 소비하고 우주선 부활을 혼자 원격 실행할 수 없다.

[선택] 보상은 현장을 떠날 때만 확보한다. 재정비/부활을 위한 선내 복귀는 정산이 아니다. 전멸하면 현장의 모든 미정산 수익을 잃고 기존 자금/소지 장비는 유지한다. 별도 부채 없음, 정산액 최소 0원. 미완료 배송은 반납 처리하며 위약금 없음.

[보완] 정산 = max(0, 영수증 완료 기본·추가 보상 + 달성 구역 보너스 − 시작한 부활 비용 − 남겨진 인원 복귀 비용). 부활 가능 잔액에는 이미 달성한 보너스만 포함한다. 전멸은 이 계산 대신 0원이며 기존 구매/이동비를 환불하지 않는다. 실패 후 같은 방문을 재개하지 않고 새 방문으로 시작한다. 구조 대기자는 전멸 판정을 미루지 않지만 이미 시작된 부활은 미룬다. 반복 다운 직후 보호로 피해를 무시하며 행동해도 보호를 취소하지 않는다.

[보완] 다운 시 특수 장비는 소지 상태로 잠기고 화물만 바닥에 떨어진다. 구조하면 그대로 사용, 탈락하면 귀환 소지품으로 예약한다. 직접 버린 장비는 이 보호 대상이 아니다. 절벽 밖 화물은 가까운 접근 가능한 낙하지점으로 복구하고 보상은 자동 지급하지 않는다.

## 6. 장비와 손실

[선택] 협동 개인 특수 장비 1칸, 솔로 2칸. 기본 진압봉·무전기·화물은 별도. 현장 자유 교환 가능. 직접 내려놓은 특수 장비를 두고 철수하면 분실하지만 탈락 시 소지 장비는 보존된다. 구매는 현장 출발 후에만 가능. 착륙에는 장착한 수량만 가져가며 우주선 여분 보관/보충 없음. 접이식 차단막과 볼트 탄약 무기는 제외한다.

[보완] 같은 종류의 중복을 개인/팀 모두 허용한다. 솔로 치료품 2개도 가능하지만 탐지/절단을 포기한다. 역할을 강제하는 클래스나 중복 금지는 없다. 구매한 재사용 장비 여분은 착륙하지 않는 회사 보관함에 남는다. 출발 전 그 보관함에서 장착하고, 현장에 없는 물건은 이용할 수 없다. 재사용품은 복사본마다 구매해야 하며 남은 소모품 수량은 영속적이다. 전부 사용하면 슬롯이 비므로 현장 장비를 주울 수 있다. 솔로 두 칸도 동시 사용은 하나다.

| 장비 | 선택된 기능 | 보완한 운영 규칙 |
|---|---|---|
| 기본 진압봉 | 잠깐 기절/밀어내기, 처치 불가, 자동 회복 에너지; 일부 생물 면역 | 짧은 근접 범위, 빗맞혀도 에너지 소모. 반복 기절로 영구 봉쇄하지 않도록 생물에 재저지 저항 적용. 동료에게 체력 피해는 없고 공격 동작을 방해하지 않음 |
| 생체 탐지기 | 범위 안 모든 생물을 종류 없는 점으로 주기 갱신, 사용자만 확인; 신호/작동음이 위험, 화면과 잡음이 주의 분산; 끄면 배터리 회복 | 벽 너머도 탐지하나 높이는 불명확. 화면 가장자리를 가리되 중심 시야 강제 차단 없음. 모든 생물은 점으로 잡히지만 신호 반응은 종류별. 리스너는 신호 자체가 아닌 작동음에만 반응 |
| 소음 미끼 | 한 칸 3개, 착지 즉시 작동 후 소모; 추격 전환 여부는 생물별 | 사용 전 궤적 미리보기, 활성 미끼는 회수 불가. 가까운/큰 소리 중 생물별 우선순위; 리스너는 들리는 활성 미끼를 우선하며 여러 개면 가장 가까운 것 |
| 휴대 절단기 | 잠금/통로 전용, 무제한, 시간과 큰 소음 부담; 중단하면 처음부터; 열린 길은 방문 내내 유지 | 생물 공격 기능 없음. 이동·피격·손 떼면 중단. 일반 배송 경로에는 수동 전원/우회 대안 존재, 보너스 전용 입구는 예외 |
| 플라즈마 커터 | 자동 회복 에너지로 일정 간격 사격, 약한 생물도 여러 명중 필요; 동료 피해; 압력 배관/낙하 지지대 상호작용 | 발사 후 잠시 회복 지연, 연사로 완전 지속 불가. 배관·지지대는 구별 가능한 재질/형태로 표시. 휴대 절단기의 잠금 해제는 대체하지 않음 |
| 치료품 | 한 칸 1회분, 자신/동료에게 즉시 완전 회복; 다운 횟수 불변 | 살아 있고 부상한 대상만, 짧은 거리/시야 필요. 다운 대상은 먼저 구조. 오조작/동시 치료는 유효한 1개만 소모 |

[선택] 장비의 기본 사용법은 알려주지만 대부분의 부작용과 생물 상호작용은 플레이하며 배운다. 결과는 무작위 오작동이 아니라 일정한 규칙과 장소/생물 차이에서 나온다. 공략 정답 도감은 만들지 않는다.

[보완] 조작·가격·잔량·아군 피해 여부는 구매 전에 명시한다. 결과를 배울 수 있게 발광·작동음·생물 반응을 일관되게 연결한다. 장비 효과 수치를 숨겨 공포를 만들기보다 공간 판단과 위험한 사용에 긴장을 둔다.

## 7. 생물과 환경 함정

[선택] 공통 생물과 장소 고유 생물을 혼합한다. 리스너는 소리로만 탐지한다. 웅크린 발소리는 감지하지 않지만 대화·무전·장비는 들린다. 마지막 소리 위치로 가서 짧은 소리/자세 예고 후 해당 지점을 공격한다. 이미 피했으면 빗맞히고 곧바로 주변 수색, 추가 소리 없으면 떠난다. 몸에 닿으면 즉시 공격하지 않고 접촉 위치 수색. 추격은 플레이어 달리기보다 빠르다. 평소 간헐적 울음/딸깍 소리는 추격 시 더 자주 난다. 첫 공격은 버틸 수 있고 회복 전 두 번째 명중에 다운된다.

[선택] 리스너는 진압봉에 잠깐 기절, 플라즈마 직접 사격으로 처치 불가, 환경 함정으로 처치 가능. 추격 중에도 소음 미끼를 우선해 방향을 바꾼다. 탐지기 신호 자체에는 반응하지 않는다(이전 신호 반응 선택은 사용자 정정으로 취소). 열린 우주선 문으로 진입하지만 닫힌 문은 못 통과한다. 닫힌 문 너머 평소 대화/무전은 못 듣고 큰 소음만 듣는다.

[보완] 리스너가 피격되면 공격자 좌표를 마법처럼 알지 않고 피격 지점/발사 소리만 조사한다. 수색 종료 뒤 기존 순찰로 돌아간다. 미끼가 끝나면 그 위치를 수색하며 새 소리를 추적한다. 공격 준비 시작 시 목표점을 고정해 예고를 보고 옆으로 피할 수 있다.

[선택] 압력 배관 분출과 지지대 파괴에 의한 낙하는 일부 강한 생물을 처치하며 동료에게도 피해. 외곽 생물은 시간 경과 후 배송 구역에 진입한다. 일부 생물은 플레이어를 추격해 우주선에 도달한 경우 닫힌 문도 안전을 보장하지 않는다.

[보완] 초기 생물 구성은 아래 3종으로 제한한다. 이름/외형은 신규 확정 아트가 아니다.

| 생물 | 역할·탐지 | 대응·선내 규칙 |
|---|---|---|
| LISTENER / 리스너 | 위에서 선택한 공통 소리 추적자 | 미끼·조용한 이동·봉; 환경 처치, 닫힌 문 방어 |
| SCAVENGER / 수거충(작업명) | 공통 약한 시각 생물, 화물 경로 순찰, 소음 조사 후 시야 확인 | 봉/플라즈마 처치 가능, 엄폐로 추적 해제. 미끼는 플레이어를 놓친 뒤 반응, 탐지 신호에는 무반응. 닫힌 문 통과 불가 |
| STRIDER / 외곽 생물 | Cinder 고유 강한 위협, 침입 단계에 외곽에서 접근; 시야·큰 소음·탐지 신호 감지 | 봉/직접 사격 면역, 함정은 일시 저지만 가능. 추격해 도착한 선박의 닫힌 문을 예고 후 파괴. 미끼는 추격 전/시야를 잃은 뒤 유효. 출발로 회피 가능 |

[보완] STRIDER는 벽 너머 플레이어 위치를 상시 알지 않는다. 선박 공격은 위치를 실제로 추적한 경우만 가능하며 단순 시간 경과로 선박에 자동 배치하지 않는다. 문 파괴 전 소리/흔들림 예고, 다음 착륙에 기능 복구. 선박 체력/영구 수리 비용은 도입하지 않는다. 배관은 단발 분출 후 정지하고 낙하물은 재설치 불가, 방문 변경 시 복원한다. 피해로 화물/영수증은 파괴되지 않는다.

## 8. 음성·관전·입력

[선택] 근거리 음성과 기본 무전. 목소리와 수신음 모두 생물이 감지한다. 수신은 항상 켜짐. 설정에서 자동 송신을 켜거나 끄며 끄면 누르는 동안 송신한다. 탈락자는 탈락자끼리만 대화하고 생존자 1/3인칭 관전을 자유 전환한다.

[보완] 무전 기본값은 버튼 송신, 근거리 음성은 음성 감지/버튼 중 선택. 무전 송신은 송신자 주변 목소리와 각 수신기 위치의 소음을 발생시킨다. 같은 음성을 근거리/무전으로 이중 재생하지 않는다. 수신 장치의 게임 세계 음량은 고정하되 사용자 청취 음량/자막/청각 접근성 설정은 제공한다. 설정 음소거는 AI 소음을 제거하지 않는다. 관전자 음성/수신기는 세계 소음을 만들지 않는다. Discord 등 외부 대화까지 통제하려 하지 않는다.

[보완] 생물 소음 입력은 마이크 음량과 발화 여부만 사용하고 음성 내용을 분석/저장하지 않는다. 배경 잡음 보정, 입력 미터/송신 표시를 제공한다. 서버가 유효 상태/거리/빈도를 판정한다. 마이크가 없는 사람을 위해 근거리/무전 텍스트와 짧은 호출을 제공하고 동일한 위치·소음 규칙을 적용한다. 적 위치 자동 공유 핑은 없다. 공포 단서 자막은 소리 존재/방향을 접근 가능하게 하되 미탐지 생물 위치를 새로 공개하지 않는다.

[보완] 이동·시점·달리기·웅크리기, 사용, 손에 든 것 내려놓기, 장비 전환, 주 사용, 무전만 핵심 입력으로 둔다. 화물 운반 중 장비 사용은 화물을 자동으로 버리지 않고 내려놓으라는 안내를 준다. 위험한 출발/구매는 명시된 버튼으로 하되 추가 승인 투표 없음. 모든 키 재설정, 토글/유지 선택, 마우스 감도/FOV, 흔들림·플래시 감소 제공. 치료는 유효 대상을 조준해 사용, 빈 방향은 자신 치료로 명확히 표시한다.

## 9. 경제·세이브·인원 변경

[선택] 자금·구매품·꾸미기는 팀 공동 소유이고 누구나 구매한다. 방장 세이브에 저장하며 멤버 변경 가능. 모든 장소를 즉시 선택할 수 있지만 이동비가 필요하고 무료 장소가 항상 있다. 수치 강화·개인 자금·부채는 없다.

[보완] 구매는 서버에서 잔액 확인과 지급을 원자적으로 처리하고 최근 구매 내역을 공유한다. 미정산 장부/지급 완료 ID/아이템 ID를 보관해 중복 지급을 방지한다. 선내 출발 준비에서는 저장 후 안전 종료, 현장에서는 같은 방문의 자동 체크포인트를 복원한다. 방장 종료는 세션을 중지하고 다음 실행 시 해당 방문·위험 시간·부상·소모·부활 진행 상태를 이어간다. 앱 강제 종료로 장비/시간을 복구하지 못하도록 소비/정산 사건을 기록한다. 클라우드 공유·호스트 이전은 초기 범위 제외.

[보완] 착륙 시 인원으로 해당 방문의 계약/생물 수를 고정한다. 중간 입장은 관전하고 다음 착륙부터 장비를 골라 참여한다. 끊긴 사람은 기존 캐릭터에 재접속 가능하며 60초 동안 몸이 남고 이후 현장 탈락으로 처리한다. 다운/연결 끊김을 이용해 인원/난이도/장비를 재생성하지 않는다. 방장 중단과 일반 참가자 연결 끊김을 구분한다.

[보완] 솔로 난이도는 계약 수·생물 동시 수·배치를 조절하며 생물 감지 규칙과 피해는 같게 둔다. 스폰 한 마리가 유일한 통로를 영구 점유하지 않게 한다. 2인도 한 명은 운반, 한 명은 대응할 수 있는 경로를 검증한다. 전멸 복구를 악용한 무료 치료는 미정산 보상/이동비/시간 손실로 비용을 지니며 추가 부채나 장비 몰수로 막지 않는다.

## 10. 초기 수치 — 모두 보완, 플레이 검증 전

이 표는 구현 작업을 시작할 수 있게 정한 **초기 기준**이다. 현재 실행본 수치나 밸런스 검증 결과가 아니다. 사용자 선택인 15~20분 체류 목표, 장비 칸, 미끼 3개, 치료 1개, 솔로 소생 2회는 유지한다.

[보완] 시작 시 기본 진압봉/무전기만 무료. 기존 세이브를 바꾸는 이행/보상은 구현 전 별도 마이그레이션으로 처리하고 기존 자금/구매품을 임의 초기화하지 않는다. 현금 고갈·부상 상태에도 무료 장소의 가까운 배송과 기본 도구로 회복 자금을 벌 수 있어야 한다. 보상이 더 높은 곳에 적 체력만 늘리는 방식은 쓰지 않는다.

## 11. 제작 범위와 순서

[보완] 출시 수량 약속 대신 첫 완결된 제작 범위를 **Cinder 1곳, 공통 생물 2종+외곽 1종, 특수 장비 5종, 카트 1종, 수령대 3구역, 기본 배송 최대 6건, 보너스 구역 1곳, 단서 3개, 꾸미기 3개**로 제한한다. 기존 모델/맵을 우선 재사용하고 새 생물/장비 외형은 별도 제작한다. 후속 장소는 위 흐름이 재미있다는 근거가 생긴 뒤 만든다.

1. **규칙 토대:** 방문 장부, 상태 전이, 소지품/체력/다운/이륙 판정, 기존 저장 마이그레이션. UI에서 비용과 실패 이유를 설명한다.
2. **한 번의 배송:** 기본 화물·주소 탐색·자동 확인/중단 재개·영수증·선내 보너스 안내·철수 정산을 연결한다.
3. **협동 생존:** 리스너/소음, 진압봉, 구조·끌기·자가 소생·부활을 먼저 완성한다. 현재 코드와 목표 규칙의 차이를 작업별로 대조한다.
4. **선택과 위험:** 탐지기/미끼/절단기/플라즈마/치료, 카트, 함정, 수거충과 외곽 단계/자동 출발, 음성 소음과 관전.
5. **연속 세션:** 구매/보관함/목적지/꾸미기/단서 저장, 재접속/방장 중단 복원, 음성 접근성, 1~4인 튜닝.

각 단계의 자동 검사가 통과해도 사람의 재미/품질 승인이 아니다. 수동 게임 창은 사용자가 직접 시험을 요청할 때만 연다. 그전에는 변경에 맞춘 Editor/화면 없는 검사만 한다. 기획 전용 작업이므로 이번에는 실행본·씬·에셋 변경, Unity 빌드, 클라이언트 시험, 도구 갱신을 하지 않았다.

## 12. 수용 기준과 남은 검증

- [ ] 두 명이 화물 운반/대응 역할을 번갈아 맡아 한 건 배송과 자발적 철수를 완주한다.
- [ ] 네 명의 동일 장비 선택도 가능하지만 역할을 섞을 실용적 이유가 있다. 솔로 두 칸으로 일반 배송이 가능하다.
- [ ] 소리 발생 위치·문 차폐·미끼/신호 우선순위가 서버와 모든 클라이언트에서 일치한다. 관전자 소리는 생물에 전달되지 않는다.
- [ ] 확인 중 회수/재배치·중복 영수증·동시 치료·동시 구매·중복 부활·출발 직전 탈락을 결정적으로 처리한다.
- [ ] 부활 중 마지막 생존자 탈락, 부활 중 이륙, 전원 미탑승, 자동/수동 출발 경쟁, 선내 다운자를 포함한 정산 표를 통과한다.
- [ ] 부활 미정산 잔액 부족, 0원 바닥, 기존 자금 보존, 이동비 미환불, 소모품 미복구, 버린 장비/카트 손실을 검증한다.
- [ ] 생물 신호로 대응을 배울 수 있으며 안개 속에서 주소/출발 징후를 읽을 수 있다. 소리가 없는 접근성 설정도 플레이 가능하다.
- [ ] 지형 변형/낙하물/카트가 필수 배송 또는 유일한 귀환 경로를 막지 않는다. 무료 장소에서 파산/부상 교착이 없다.
- [ ] 연결 끊김/재접속/방장 종료/저장 중단에 보상 복제·소모 복구·진행 손실이 없다.
- [ ] 사람이 15~20분 방문에서 “한 건 더”와 “지금 철수”를 실제로 고민한다. 한 장비/경로가 모든 선택을 지배하면 수치를 조절한다.

문서 검사만 이번 작업의 검증이다. 위 항목은 모두 미실시이고 출시 완료 조건이 아니다. 플랫폼/Steam 연결·네트워크 지연·성능·최종 아트/음향·음성 전달 서비스 선택은 구현 단계의 기술 검토가 남는다. 게임 규칙은 본 문서로 작업 가능한 v1을 닫고, 수치는 플레이 근거로 수정한다.
