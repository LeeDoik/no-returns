## 구현·검증 결과

게임 HUD는 uGUI Canvas로 분리했고 1280×720 기준 Expand 배율을 사용한다. 직원 번호 01~04와 색상을 함께 써 색상만으로 상태를 구분하지 않는다. 자신의 직원에는 ‘나’를 표시한다. 오른쪽 상태는 방장이 전송한 접속·다운·운반·우주선 판정에서 읽으며 위치 표식이나 거리 추적을 새로 제공하지 않는다. 목표와 잔액은 왼쪽 위, 조작·구조 진행률과 억제 신호는 아래, 조준점은 중앙이다. 생물 AI 상태의 디버그 문구와 화면의 충격봉 쿨타임 숫자를 제거했다. 충격봉 내장 디스플레이는 유지한다. 저장 안내는 기존 Esc 메뉴에서 확인한다.

Unity MCP에서 상태·언어·입력 가림·숨김·배율 10개 조건과 두 언어 × 근무 5단계 × 텍스트 10개의 높이 검사를 통과했다. 영어 목표 문구가 넘치는 문제를 발견해 목표 글자를 20으로 조정했다. 실제 Canvas를 카메라 모드로 임시 렌더한 1280×720 및 1024×768 시안을 검토했다. 이는 격리된 HUD 배치 근거이며 실제 게임 전체 화면이나 사람 가독성 평가가 아니다.

Windows 0.9.1 빌드, 실제 로컬 4개 프로세스 장비·접속·배송·영수증·정산 31개 검사를 통과했다. 31개 검사는 마지막 글자 크기 조정 전이며, 조정 후 Unity 전체 문구 검사와 Windows 빌드를 다시 통과했다. 네트워크·보상·구조 규칙은 변경하지 않았다. 실제 사람의 가독성·현장 배경 대비, 소형 화면과 긴 상태 오류 문구는 후속 평가 대상이다.
