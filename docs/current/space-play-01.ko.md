# SPACE-PLAY-01 — 2인 운반 실험 구현 계획

[English](space-play-01.en.md)

2026-09-12. 승인 범위: 1인칭 이동·화물 들기/내려놓기·충돌·2인 직접 접속 Windows 빌드. 완성 배송 데모 전의 조작 실험이다. 기존 Bootstrap과 아트 시안은 보존한다.

- [x] CarryRoom 장면과 임시 지형·직원·화물 제작. 최종 아트 제작 아님.
- [x] 방장 권한 이동·화물 소유·충돌, 참가자 입력과 상태 복제 구현.
- [x] 두 프로세스 접속·이동·잡기 경쟁·회전·내려놓기·벽·이탈 검증.
- [x] Windows 빌드·실행 안내·한영 현재 문서와 근거 갱신.

Runtime/CarryLab 폴더에서 전송, 입력/시뮬레이션, 시각 표현을 분리한다. Editor/CarryBuild.cs는 장면 생성과 빌드를 담당한다. tools/test_carry_build.py는 실제 실행본을 시작해 테스트 전용 입력 파일로 일반 입력 경로를 조작하고 상태 결과를 대조한다. TCP 직접 접속은 실험용이며 Steam 초대·NAT 중계·지연 보정·호스트 이전은 포함하지 않는다. 테스트는 자동 조작과 사람 조작감 평가를 구분한다. 장비·생물·정산·구조는 이 단계 밖이다.
