# Steam 비공개 테스트 등록

[English](steam-testing.en.md)

2026-09-13 · 사용자 결정으로 Steam 등록을 보류한다. 로그인 후 Steam Direct 수수료 단계에 도달한 것을 확인했다. Continue로 결제 안내 이동을 시도했지만 후속 화면 확인은 중단됐다. 에이전트는 결제를 실행하지 않았으며 결제 완료도 확인되지 않았다. 파트너 승인, NO RETURNS 자체 AppID, 빌드 배포 및 테스트 키는 미확인이다. 재개 요청 전 가입·결제를 진행하지 않는다.

## 목표와 첫 단계

친구에게 최초 이용 권한을 제공한 뒤 같은 앱의 테스트 빌드를 반복 업데이트한다. 먼저 [Steamworks](https://partner.steamgames.com/newpartner)에 게임을 관리할 계정으로 로그인한다. 이후 기존 파트너와 앱 보유 여부를 확인해 중복 가입·구매를 피한다.

신규 가입에는 법적 명의, 은행·세금 정보, 신원 확인과 계약 절차가 있다. 개인도 가입할 수 있으며 등록 명의와 예금주가 일치해야 한다. 개인정보 입력과 계약 검토는 계정 소유자가 공식 사이트에서 진행한다. 계좌·세금 식별자·비밀번호·인증 코드는 문서와 Git에 저장하지 않는다. [가입 안내](https://partner.steamgames.com/doc/gettingstarted/onboarding)

앱 등록 수수료는 USD 100 또는 현지 통화 상당액이며 적용 세금과 실제 결제 금액은 결제 화면에서 확인한다. 이번 작업에서 결제하지 않았다. [수수료 안내](https://partner.steamgames.com/doc/gettingstarted/appfee)

## 진행 체크리스트

- [x] 기존 세션과 공식 등록·테스트 안내 확인.
- [x] 가입용 로그인 화면 열기.
- [x] 계정 로그인 확인.
- [ ] 기존 파트너 승인·앱 보유 상태 확인.
- [ ] 필요한 가입·계약·결제·신원·은행·세금 절차 완료 확인.
- [ ] NO RETURNS 자체 AppID 확보 및 기록.
- [ ] Windows depot와 실행 항목 구성, 테스트 계정 패키지에 앱과 depot 포함 확인.
- [ ] 테스트 빌드 업로드 및 제한된 테스트 브랜치 적용.
- [ ] 개발자 계정에서 Steam 설치·실행 확인.
- [ ] 소규모 외부 테스터용 Release State Override 키 요청·승인·이용 권한 확인.
- [ ] 다른 계정·PC에서 설치·실행·새 빌드 업데이트 확인.
- [ ] Steam 초대·합류 연동 구현 후 서로 다른 계정·네트워크에서 확인.

첫 외부 테스트 방식은 본편 AppID와 출시 전 테스트 키를 후보로 삼는다. 키 발급은 승인 전 보장하지 않는다. 브랜치 암호나 로비 초대만으로 앱 이용 권한이 생기지는 않는다. 대규모 모집은 별도 Playtest 앱을 후속 검토한다. [공식 테스트 안내](https://partner.steamgames.com/doc/store/testing)

## 완료 기준과 별도 개발 범위

배포 검증은 Steam 설치, 실행, 업데이트와 접근 권한을 다룬다. 협동 검증은 초대, 합류, 배송, 귀환 저장, 전원 종료 후 재개를 다룬다. 등록만으로 협동 네트워크나 운영자 서버가 구현되지는 않는다. 현재 서버 구조 권고와 미결정 항목은 [백로그](04-backlog.ko.md)를 따른다. 게임 코드 변경과 실제 Steam 배포·초대 테스트는 아직 없다.
