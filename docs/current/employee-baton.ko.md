# 직원 진압봉 직선 찌르기·회수 — 0.9.10

[English](employee-baton.en.md)

2026-10-03. 사용자가 직접 시험 뒤 “휘적거리는” 공격 대신 정확하게 “팍 찌르는” 동작을 요청했다. 현재 게임 **0.9.10**, 프로토콜 **13**, TCP **27842**. [버전 설정](../../NoReturns/ProjectSettings/ProjectSettings.asset)이 근거다. 아래 내용이 0.9.9의 측면 휘두르기·가슴 비틀기·0.55초 복귀를 대체한다. 수정본의 사용자 타격감 승인은 아직 받지 않았다.

## 현재 동작

- 빈손 준비 자세부터 봉 끝을 직원 전방으로 향하게 한다. 손목 방향과 가슴 비틀기를 고정하고 기존 대기·걷기의 하체 이동을 유지한다. 준비 자세 진입은 약 **0.1초**다.
- 좌클릭 후 **0–0.06초**에 손을 곧게 **0.30m** 전진시킨다. 초반이 빠른 곡선으로 밀고 **0.06–0.10초** 잠시 유지한 뒤 **0.10–0.30초** 같은 경로로 회수한다. 전체 표현은 **0.30초**다. 기존 타격 판정은 클릭 시 **즉시**, 재사용 대기는 **6초**로 유지한다. 외형이 최대 전진에 도달하는 시점과 판정 시점은 다르며 피해 판정을 늦추지 않는다.
- 실제 손 기준점·방향에 무기를 붙이고 별도 측면 무기 회전이나 가슴 좌우 회전을 넣지 않는다. 도달 범위 밖에서는 팔을 늘리지 않고 제한한다. 이때 실제 손 경로에 작은 오차가 생길 수 있으나 봉의 전방 방향은 유지한다.
- 1인칭 무기도 봉 끝을 조준 전방으로 고정한다. 전진 표현은 **0.27m**이며 벽 앞에서는 봉 끝의 현재 도달 거리 **0.92–1.19m**(여유 **0.04m** 포함)를 검사해 깊이만 당긴다. 좌우·상하 잡는 위치는 고정한다. 기존 최소 배율 **0.35** 제한을 유지하므로 극단적인 벽 근접/모서리의 모든 관통 해결로 간주하지 않는다. 1인칭 전신 팔은 아직 없다.
- 상자·신호기 운반, 다운, 유효한 구조, 비활성/미접속 직원에서 무기·공격 자세를 차단한다. 중단된 공격은 다시 재생하지 않고 준비 자세로 돌아간다. 유효한 구조/공격 동시 입력은 구조 우선이다. 공격 범위·방향·시야·리스너 기절·이동/화물 충돌은 바꾸지 않았다.
