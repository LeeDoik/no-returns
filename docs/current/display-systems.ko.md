## 제작 기준

단순 수치·막대·깜빡임은 셰이더. 고정된 픽셀 문구·일러스트는 텍스처. 동적 문장·계약 목록·메뉴가 들어가는 실제 기기 화면은 UI를 RenderTexture에 그리는 방식을 검토한다. 공간에 부착한 조작 UI에는 World Space Canvas도 후보지만 메시 표면에 붙어야 하는 화면은 재질 방식으로 유지한다. 현재 RenderTexture를 새로 생성하는 제품 화면은 없다. 테스트 캡처용 RenderTexture는 제품 화면 구현과 구분한다.

방장은 게임 상태를 결정하고 참가자는 같은 값으로 표시한다. 표시 방식 변경으로 공격·배송·정산 판정은 바꾸지 않았다. 두 셰이더의 깊이 검사·깊이 기록을 유지했다. 단말기 CRT 마스크는 기존 배치 좌표에 의존하므로 배치 변경 시 재조정이 필요한 기존 제약이다.

## 검증과 한계

Windows 빌드 성공. 단말기 진행률 25%와 75% 렌더 비교에서 정면 212픽셀 변경, 뒷면 0픽셀, 차폐 벽 뒤 0픽셀. 진행률이 화면 내부에만 보이는 것을 확인했다. 성능 수치 개선이나 출시 UI 완성을 주장하지 않는다. 사람의 실제 가독성·멀미·조작감은 별도 평가다.
