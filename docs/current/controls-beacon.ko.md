# 조작 통일과 운반 신호기

[English](controls-beacon.en.md)

2026-09-13 · 0.8.8 · 구현 완료 · 아래 검증 범위 참고

E: 바라보는 화물·신호기 줍기, 영수증 회수, 단서 조사, 선내 항로·귀환. 쓰러진 동료 곁에서 E 유지 구조. Q: 들고 있는 물건 내려놓기. E로 들고 있는 물건을 내려놓지 않는다. 소리 내기는 Q에서 C로 이동한다. G 밀치기·Tab 기록·Esc 메뉴는 유지한다. 보급 메뉴는 위/아래 키로 구매·계약 변경을 고르고 E로 확인하거나 마우스를 사용한다. F/I/B/T/V 별도 단축키는 제거했다. 구조·대상 사용·줍기·선내 행동을 한 입력에서 중복 실행하지 않는다.

신호기 사용권 120 CR을 구매하면 선내 (-2,0.22,-7)에 공용 장비 1개가 생성된다. E로 가져가며 화물과 동시에 들 수 없다. Q로 선내에 내려놓으면 횟수를 쓰지 않는다. 현장에서 바닥에 내려놓으면 8초 작동하고 1회를 소모한다. 근무당 2회이며 작동 중에는 회수할 수 없다. 작동 후 E로 다시 운반할 수 있다. 다음 근무에 선내 장비와 2회를 재보급하며 출발만으로 장비 위치를 초기화하지 않는다. 원격 생성·원격 설치는 제거한다. 방장이 소유·위치·사용 횟수를 결정하며 프로토콜 9로 공유한다. 내려놓을 공간이 막혀 있으면 손에 유지한다.

신호기 외형 시안 03 / DECOY BEACON은 사용자가 제작 승인했다. 조작 수정과 물리 운반을 먼저 처리하라는 요청에 따라 이번 실행본은 기존 임시 외형을 사용한다. 승인된 최종 3D 제작·적용은 후속 아트 작업으로 남긴다. 아트 제작 완료로 표시하지 않는다.

검증: 2개 실제 프로세스에서 E/Q 운반·영수증·귀환, 시험 잔액을 가진 별도 세션에서 구매·선내 생성·참가자 운반·현장 작동·회수를 검사한다. 사람의 조작감과 새 아트 품질은 별도 검증한다.


검증 결과: Windows 0.8.8 빌드, 실제 2개 프로세스 배송·E/Q 회귀 30항목, 시험 잔액을 사용한 신호기 구매·운반 14항목 통과. 신호기 재회수의 최종 검사는 우주선 출구 쪽에서 수행했다. 생물 순찰 지점에서 대기한 이전 시도는 다운되어 실패했으며 전투·위험 지역 재회수 난이도는 사람 검증 대상으로 남긴다. 문서 검사 210개 통과.
