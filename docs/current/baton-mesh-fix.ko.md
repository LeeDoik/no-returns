# 충격봉 외장 복원 — 0.8.15

[English](baton-mesh-fix.en.md)

사용자가 표면에 구멍이 나거나 조각이 튀어나온다고 보고했다. Unity 프리팹 렌더에서 디스플레이 위 외장에 길게 열린 틈을 재현했다. 이전 제작 스크립트는 면의 중심점이 화면 좌표 범위에 들어오면 면 전체를 삭제했다. 경계를 넘어 이어지는 외장 면도 삭제된 것이 확인된 원인이다. 기존 메시의 면 방향 검사에서도 재정렬 대상이 나왔으나, 모든 사용자 증상이 그 때문이라고 단정하지 않는다.

## 변경

[제작 스크립트](../../art/psx-baton-02/prepare.py)에서 357개 면을 삭제하는 처리를 제거했다. 원본 외장 전체를 유지하고 0.00001m 범위의 중복 정점을 병합한 뒤 면 방향과 삼각형 분할을 정리한다. 디스플레이는 외장을 잘라내지 않고 기존 프레임 안의 별도 면에 표시한다. 화면 면의 Blender Y 위치는 -0.048m다. 원본과 최종 외장의 삼각형 수가 같아야 내보내도록 검사한다.

수정 모델은 원본 외장 9694개 삼각형과 별도 화면을 유지한다. 길이 0.68m, 몸체 텍스처와 승인된 외형은 유지한다. 선택 FBX·Blender 파일과 Unity FBX를 갱신했다. 공격 판정·6초 충전·전기선·벽 근처 배치 규칙은 변경하지 않았다. 이전 0.8.13의 화면 면 삭제 방식 설명은 이 문서로 대체한다.
