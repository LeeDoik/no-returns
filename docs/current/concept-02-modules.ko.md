## 반복 건축 모듈과 분리할 자산

- 직원 전신: 한 몸체에 주황·청록 등 팀 색상 변형. 1인칭 팔은 사진에는 없지만 현재 게임 시점에 필요한 별도 항목이다.
- 거대 외곽 생물: 배경에서 실루엣은 확인되지만 상세 구조를 추정해 확정하지 않는다. 기존 승인된 갈색 A 디자인을 우선한다.
- 우주선: 각진 외피, 후방 출입 프레임, 착륙 다리, 개폐 문/램프, 외장 설비를 별도 조립체로 분리한다. 사진의 램프는 관찰 사항이며 현재 선내/외장 보류 결정을 뒤집거나 램프 재도입을 승인하는 근거가 아니다.
- 원경: 공장 매스, 굴뚝/탑, 작은 경고등. 접근 가능한 건물과 원경용 간소화 모델을 구분한다.
- 배경 행성과 하늘: 배경 재질/스카이로 검토하며 반드시 거대한 3D 모델을 만들 필요는 없다.

## 모델 대신 재질·표면·연출로 처리

공용 낡은 도장 금속, 어두운 보강재, 주황/적색 띠, 금속 바닥, 외부 지면을 준비한다. 로고·바코드·번호·오염·벗겨짐은 재질/데칼 변형으로 다룬다. 화면 UI와 발광 면은 별도 재질 영역으로 분리한다. 보라색 안개, 따뜻한 작업등, 녹색 화면, 적색 경보는 Unity 조명·효과 작업이다. 사진 속 외부 바닥은 별도 지면 메시/재질이 필요하지만 반복 실내 타일과 동일하게 취급하지 않는다.

## 먼저 만들 묶음 제안

A01~A08, B01~B06, C01~C03, C06~C07, D02~D03과 필요한 E 연결 부품으로 입구·작업실·배송 장치를 조립해 본다. 기존 모델은 재사용 후보이며 새로 만들기 전에 결함을 확인한다. 문짝, 화면, 조명 발광 면, 매달린 고리는 작동/재질 교체를 위해 분리한다. 바닥 레일은 우선 시각 요소이며 사진만으로 컨베이어나 자동 운송 기능을 추가하지 않는다.

치수는 사진에서 확정하지 않는다. 현행 맵의 3.2m 폭·3.3m 높이 개구부와 천장 하단 4m를 초기 호환 기준으로 삼고 화물·직원 통과를 확인한다. 실내 선행과 이미지 승인 후 3D 제작 원칙을 유지한다.
