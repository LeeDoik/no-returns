# Cinder 리스너·진압봉·구조 — 0.9.3

[English](cinder-listener.en.md)

2026-10-02 · 구현. 기본 Cinder 배송 실행에 기존 위험 규칙을 연결했다. 이 문서가 아래 과거 단계의 Cinder 리스너/진압봉/구조 미연결 상태보다 우선한다. 사람 조작·재미·공포 품질 승인은 아니다.

## 실행과 조작

[07_Play_Cinder_4P.command](../../07_Play_Cinder_4P.command)는 방장 1명+참가자 3명을 실행한다. 우주선에 모여 E 단말의 버튼으로 항로 선택·출발한다. 현장 단계에서 리스너가 움직인다. Editor에서는 `Assets/_NoReturns/Scenes/CinderFourPlayerTest.unity` → Play → HOST/JOIN. 기본 빌드 **0.9.3**, 공통 네트워크 프로토콜 **12**, Cinder TCP **27842**다. 같은 버전끼리 연결한다.

- **Shift**: 조용히 걷기. 빈손 1.5m/s, 화물 운반 1m/s; 발걸음 소음 없음. 일반 이동 빈손 4m/s, 화물 2.5m/s.
- **C**: 12m 안에서 소리 내기로 마지막 위치에 유인. 일반 발걸음 6m, Q 화물 해제 10m. 안전한 선내 소음은 무시한다.
- **좌클릭**: 빈손 진압봉. 2.5m·전방 65°·정적 장애물 없는 가시선 조건, 3초 저지·6초 재사용 대기. 화물/신호기 운반 중에는 놓기로 동작한다. 저지 종료 후 2초 재저지 저항이 있다.
- **E 유지**: 쓰러진 동료 2m 이내·가시선·빈손에서 2.5초 구조. 손을 떼거나 멀어짐·벽·대상 변경·구조자 다운 시 취소. 구조 후 4초 공격 보호.

현장 빈손 안내는 현재 설정한 Shift/C/좌클릭 키와 진압봉 대기 시간을 표시한다. 구조 대상과 진행은 E 화물/선내 UI보다 우선한다. 다운 시 이동·집기·진압봉·출항을 차단하고 화물/신호기를 놓는다. 메뉴는 세계를 멈추지 않는다.

## 현재 맵 연결

[CarryThreat](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryThreat.cs)는 기존 1m 정적 격자와 BFS를 재사용한다. 검사 범위 x=-27~25, z=-34~30m, 지상 높이차 0.32m 이하; 바닥 지지·0.84×1.6×0.84m 공간·격자 사이 swept box를 검사한다. 계단/동적 지형/직원·이동 화물의 경로 회피는 범위 밖이다. 현재 지도에는 지상 경로만 사용한다.

순찰 순서는 **(-23,2) → (-23,-10) → (-5,-10) → (-5,14) → (-23,14)**m의 x/z다. 1.4m/s 순찰, 2.5m/s 마지막 소음 조사, 관심 5초. 1.3m 이내 가시선이면 1.2초 경고 뒤 1.5m 안에 남은 직원을 다운시키고 4초 공격 회복한다. 벽 반대편을 직접 공격하지 않는다. 경고 몸 색/임시 음향과 기존 진압봉 모델/내장 표시를 재사용한다. 리스너 최종 모델·애니메이션은 만들지 않았다.

선내 안전 판정은 [CarryMission.Aboard](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryMission.cs)의 Cinder 좌표를 공통 사용한다. 경사로와 갑판은 순찰 격자에서 제외한다. 현장에는 리스너 1개만 존재하며 옛 억제기·외곽 생물·단말/저장 좌표를 함께 생성하지 않는다. 억제기 약화/외곽 생물/단서와 Cinder 진행 저장은 다음 단계다. 기존 옛 위험 모드 기능은 유지한다.

전원 다운 3초 후 해당 근무를 무보수 정산으로 중단하고, 네 직원을 실제 선내 **x=-21.65/-19.75, y=1.035, z=-25.5/-26.9m**에 회수한다. 이미 가진 지갑은 유지하고 새 배송 보수는 지급하지 않는다. 선내 버튼으로 다음 근무를 준비하면 직원·화물·다운/재사용 상태를 초기화한다. 정상 영수증 귀환 300+120=420 CR은 유지한다. 참가자 이탈 시 근무 중단·다운 직원 복구의 기존 규칙도 유지한다.

기존 신호기 신호는 리스너 `Hear`에도 전달되므로 12m 안에서 조사 대상으로 사용할 수 있다. 120 CR 사용권·2회/8초 규칙은 [조작·구매 안내](controls-ui.ko.md)를 따른다. 외곽 생물 유인은 아직 연결되지 않았다. 지갑/사용권은 세션 전용이며 종료 후 복원하지 않는다.

## 제작·검사

원본 아트 씬을 보존하고 기존 파생 씬/빌드 도구를 사용한다. 신규 모델·텍스처·패키지 없음. `--map-only`는 이동/운반만, `--delivery-only`는 위험 없는 배송 UI 회귀다. 기본 실행은 배송+리스너다. 자동 입력/근거 파일은 기존 시험 빌드에서만 지원한다.

```sh
source ~/.unity/env
python3 tools/cinder_four_player.py build
python3 tools/test_cinder_threat.py
python3 tools/test_cinder_delivery.py
python3 tools/cinder_four_player.py check
python3 tools/cinder_four_player.py start --delivery-only
python3 tools/cinder_four_player.py stop
```

[격자·순찰·선내 안전·벽 구조 검사](../../tools/unity_checks/CinderThreatCheck.cs)는 현재 파생 씬의 native 물리를 사용한다. 별도 규칙 검사의 명시적 상태 설정과 실제 네 실행본 검사를 구분한다. [실제 네 실행본 검사](../../tools/test_cinder_threat.py)는 이동·사용·소리·진압봉·구조 입력만 보내며 순간이동/다운 주입을 사용하지 않는다. 배송 회귀는 위험을 끄고 UI/장부만 검사한다.

최종 검증 결과는 [0.9.3 검증 기록](../validation/cinder-listener-0.9.3.json)을 따른다. 실제 사람 네 명의 운반/회피/구조 재미, 경고음 전달력, 리스너 외형·HUD 가독성, 다른 PC/LAN·최신 Windows 실행·성능/장시간 안정성은 미검증이다.

맥 빌드 오류 0개·기존 경고 7개, 현재 맵 경로 끝점 92곳·순찰 충돌 검사 2,400회·구조 조건 5개·기존 네 직원 구조 7개·조작/UI 17개·장부 35개·HUD 상태 13개/텍스트 높이 100개 통과. 실제 네 실행본 위험 검사 **31개**를 통과하고 800×500 한영 화면을 검토했다. [한글 진압봉·다운 동료](../../art/cinder-kit-01/listener-baton-ko.png) · [영문 다운 안내](../../art/cinder-kit-01/listener-down-en.png). 활성 리스너 아래 영수증/정상 귀환과 구매한 신호기 유인은 이번 작업에서 별도로 실행 검증하지 않았다.

위험을 끈 실제 네 실행본 배송/UI 회귀 **48개**, 이전 테스트 맵 순찰 끝점 **4곳**도 통과했다. 구조 완료 후 구조자는 공격 보호를 받지 않으므로 계속 피해야 한다. 임시 크리처 몸에는 직원/화물용 물리 콜라이더가 없고, 거리·가시선으로 공격을 판정한다.

최종 실제 네 실행본 이동·접속·5번째 거절·이탈/재참가 회귀 **13개** 통과. 자동 세션은 검사 후 모두 종료했다. 전체 문서 검사는 기존 누락 링크 142개로 실패(새 오류 0개)하고, native 씬 후행 공백 4개로 raw diff 검사가 실패한다. 코드/문서/근거 및 blank-at-eol 제외 공백 검사는 통과한다.

최종 재빌드로 시험 입력 폴더 없는 수동 네 창을 실행하고 방장 TCP 연결 3개를 확인했다. 사용자 검토용으로 열어 두었으며 사람 입력/품질 검증은 아니다. [08_Stop_Cinder_4P.command](../../08_Stop_Cinder_4P.command)로 종료한다.
