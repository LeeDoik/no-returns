# 우주선 외부·내부 정합성 재검토

[English](ship-review.en.md)

2026-09-13 · 대상: 창문 외부 02, 내부 02, 내부 치수 제안. 결론: 미술 방향은 유지할 수 있지만 제작용 구조 승인은 보류해야 한다. 외부 승인까지 취소하는 의미는 아니다. 이번에는 이미지를 재생성하거나 모델·게임 코드를 변경하지 않는다.

## 근거와 판정

## 유지할 부분

A의 낮고 넓은 외형, 후방 화물 진입, 전방 창문과 콘솔, 단층 중앙 통로, 좌우 장비 배치는 좋은 방향이다. 후방을 보는 투시도에서 신호기·충격봉 좌우가 반전되는 표현도 맞다. 전부 버리고 새 우주선을 만드는 대신 동일한 기본 형태의 정합성을 맞춘다.

## 권장 다음 작업

생성 이미지 추가보다 외부 셸·실내 바닥·기수·유리·문·램프·가구를 단순 블록으로 먼저 조립한다. 미술 디테일 없이 하나의 모델에서 모든 뷰를 출력한다. 길이·높이 배분과 기구 방식을 확정한 뒤에 이 블록을 참고해 이미지를 보완한다. 이 단계는 본 검토에서 실행하지 않았다.

- [ ] S01~S04: 외부/내부 단면과 램프 닫힘 상태 검증.
- [ ] S05~S07: 4인 인체·좌석·화물·접근 공간 검증.
- [ ] S08: 밝기와 오염 밀도의 역할 구분.

기존 47.04㎡는 제안한 사다리꼴 포함 평면의 가구 배치 전 산술값일 뿐 실제 선체 안에 들어간다는 증거가 아니다. 2.0m 통로와 두 직원 충돌 폭 차이 0.64m도 회전·화물·손·장비 공간까지 보장하지 않는다. 이전 ‘외부에 맞췄다’는 표현은 시각 방향을 맞춘 것으로 한정한다.
