# CINDER DEPOT — 한 사이클 데모와 3D 에셋 목록

[English](demo-art-list.en.md)

2026-09-13 · 0.9.1 기준 조사·제작 제안. 이미지 경로의 앞 슬래시를 제거해 원본을 열어 확인했다. 사용자 목표는 이미지 수준의 공간과 완결된 데모 한 사이클이다. 아래는 제작 계획이며 개별 외형 승인·제작 완료·출시 품질 판정이 아니다.

## 데모 범위

우주선 준비 → 항로 선택·자동 도착 → 밀봉 화물 1개 운반 → 안전 우회로/위험 지름길 선택 → 리스너 대응·선택적 단서 조사 → 수령소 배송 → 영수증 회수 → 우주선 귀환·정산 → 신호기 구매·직접 집기 → 다음 계약 준비. 구매한 도구가 실제 선내에 나타나 다음 출발에 쓸 수 있는 상태까지가 끝이다. 두 번째 배송 완료는 필수가 아니다.

첫 성공 12~18분, 현장 7~10분을 검증 목표로 제안한다. 현재 억제 단계 90/135/180초·침입 188초와 맞지 않으므로 동선 실측 후 조정해야 한다. 이번에는 값을 바꾸지 않는다. 직접 카운트다운 대신 조명·작동음·중계 기둥의 단계 신호를 유지한다.

배송지 1곳, 밀봉 화물 1종, 리스너 1종, 외곽 생물 1종, 기본 충격봉·구매 신호기, 핵심 단서 1개에 집중한다. 기존 단서 2개는 보존하되 1개를 첫 궁금증의 중심으로 연출한다. 자유 비행·행성 전체 탐험·절차 생성·신규 무기·대규모 상점은 범위 밖이다.

## 제작 수량

44개 제작 단위 중 기존 모델 10개는 재사용·보완 검토, 신규 34개는 제작 제안이다. 반복 배치·색상 변형 수가 아니다. 배관 키트처럼 여러 연결 조각을 포함하는 단위도 있으므로 FBX 파일 수나 개별 메시 수와 다르다. Review 복제본·시설 생성 후보는 완성 자산으로 중복 계산하지 않았다. 기존 Selected FBX와 적용 문서를 확인했으며 이번에 모든 메시·UV를 재검사하지 않았다. 직원·생물은 현행 코드에서 임시 도형이다.

P0: 핵심 공간·기능 통합. P1: 동선·시설 밀도 마감. P2: 작은 분위기 소품. 모두 데모 후보에 포함하지만 P0부터 검증한다. R은 기존 모델 재사용·보완 검토, N은 신규 제작 제안이다.

## 이미지의 7개 구역과 연결

| 이미지 | 조립할 에셋 | 플레이 목적 |
|---|---|---|
| 01 착륙·귀환 | SHP01~05, ENV04/07, FAC01 | 준비·구매·반납 동선을 알아보기 쉽게 연결 |
| 02 보관 우회로 | ENV01~07, FAC01/02, PRP04/06 | 길지만 시야가 끊기고 화물 운반은 안정적인 경로 |

| 04 수령소 | FAC03, ENV08/09, PRP01 | 바닥 배송 표시 → CRT 반응 → 슬롯 영수증 회수 |
| 05 측면 사무실 | PRP07~10, FAC08, SHP05 재질 변형 | 무인 시설의 최근 사용 흔적; 콘솔 외형 재사용 가능 |

이미지의 청록·황색 동선 화살표와 번호는 설명용 그래픽이며 게임 내 3D 에셋이 아니다. 게임에서는 건축 형태·표식·빛으로 경로를 읽게 한다. 머리 위에서만 보이는 보기 좋은 배치보다 1인칭 문 너머·코너·천장·후면을 먼저 검토한다.

## 모델 밖에 필요한 제작물

- 재질: 도장 금속, 벗겨진 모서리, 바닥, 암석의 공용 재질군. 따뜻한 작업등·차가운 CRT·적색 경보의 역할을 통일한다. 모듈별 생성 텍스처를 그대로 섞지 않는다.
- 2D/표면: 바닥 수령 표시, Bay 04 표지, 화물 라벨, 오염·흔적 데칼, 영수증 면, 항로·구매·정산 화면, 직원 얼굴 표시. 매 상태마다 모델을 복제하지 않는다.
- 애니메이션: 직원 대기·이동·운반·다운·구조, 1인칭 집기·놓기·충격봉 사용·구조, 리스너 이동·소음 조사·공격 예고·공격·저지, 외곽 생물 진입·추적·공격. 필요한 클립과 손 접점은 모델 제작 전에 정하고 정확한 개수는 리그 검증 후 확정한다.
- VFX·오디오: 충격봉 전기, 억제장치 단계 변화·꺼짐, 경고등, 수령 스캔·프린터, 엔진·발소리·생물 예고·환경음. 분위기를 만드는 안개·색보정·저해상도 표현·조명도 별도 작업이다.
- 충돌·기술: 바닥 중심 피벗, 실제 단위, 문·팔레트의 단순 충돌, 손·화물 소켓, 발광 면과 CRT의 별도 재질 영역. 직원 4색과 부품 작동은 재질·애니메이션 변형으로 처리한다.

이 항목들은 44개 모델 제작 단위에 포함되지 않는다. 이미지의 완성도를 내는 데는 이 작업들과 일관된 배치가 함께 필요하다.

## 현재 코드 재사용과 남은 구현

| 항목 | 현재 근거 | 데모에 남은 일 |
|---|---|---|
| 4인 운반·구조·배송 | 0.9.0~0.9.1 실제 프로세스 검사 | 아트 적용 후 동일 검사와 사람 4인 플레이 |
| 계약·귀환·구매·저장 | CarryMission, CarryRoom, CarrySave | 선내 콘솔에 연결한 자연스러운 안내·첫 구매 마무리 |
| 보수 | 일반 300+120=420, 신호기 120 | 첫 구매 후 300 잔액·재실행 복원·다음 출발 사용 검증 |
| 고난도 | 첫 성공 뒤 기존 위험 계약 선택 가능 | 새 지역을 추가하지 않고 선택 이유·위험 정보 전달 |
| 생물·억제장치 | CarryThreat, CarrySuppression | 실제 리그·사운드, 경로 실측에 맞는 단계 시간, 공격 사전 신호 |
| 맵 | 현재 32×44m 실험과 시설 키트 | 참고 이미지 구역 연결을 1인칭 운반 기준으로 재조립 |
| 실패 | 미배송 중단·전원 다운 회수·동료 이탈 규칙 | 실패 안내·재도전·동료 이탈 악용 가능성 검토 |

위 보수와 시간은 현재 코드 값이며 새 경제안이 아니다. 첫 구매를 장비 사용권 확장으로 보여주고 별도 능력치 업그레이드 트리는 추가하지 않는다. 사용자의 실제 저장을 초기화하지 않고 첫 체험 검사는 별도 테스트 저장으로 수행한다. 미스터리 정체·결말은 확정하지 않는다.

## 제작 순서와 완료 조건

1. 우주선 → 짧은 복도 → 수령소를 기존 10종과 핵심 구조 P0로 이어 먼저 한 배송을 완주한다. 새 직원·크리처는 제작을 준비하되 에셋을 기다리느라 경로 검증을 멈추지 않는다.
2. 천장·벽 마감·바닥·조명·암석의 작은 기준 구간을 완성한다. 이 구간의 재질 밀도와 색을 나머지 시설의 기준으로 삼는다.
3. 우회로·마당·억제 설비·외곽 입구를 연결하고 직원·팔·리스너·갈색 A를 실제 조작에 붙인다.
4. 사무실 흔적·선반 적재·데칼·음향을 채운다. 통로에 소품을 무작정 늘려 운반을 막지 않는다.
5. 새 저장에서 배송 → 영수증 → 귀환 → 구매 → 다음 준비까지 검증하고, 실패 후 재시도·재접속·종료 후 진행 복원을 확인한다.

신규 디자인은 제작용 이미지 → 사용자 외형 승인 → 3D 제작 순서를 지킨다. 이 목록 승인은 34개 신규 외형을 일괄 승인한다는 뜻이 아니다. 기존 모델은 결함을 확인한 것만 재제작하고 치수·UV·재질·피벗 문제는 먼저 로컬에서 수정한다.

- [ ] 각 모델: 전후좌우·하부 검토, 정상 법선·UV·텍스처 경로, 단위·피벗·단순 충돌 확인.
- [ ] 기준 구간: 1인칭 화물/무기 시야, 4인 교차, 문·경사·선반에 걸리지 않음.
- [ ] 플레이: 설명 없이 배송·영수증·귀환·첫 구매까지 이어지고 안전·위험 경로 선택이 생김.
- [ ] 실패: 다운·구조·전원 회수·동료 이탈·다음 근무에서 진행 불능 없음.
- [ ] 자동 검사: 상태·중복 보상·소유권·저장·빌드 회귀 통과. 외부 4인/Steam 검증과 구분.
- [ ] 사람 검사: 조작감·가독성·긴장·반복 의향을 별도로 기록. 목표 PC를 정해 프레임·메모리·동시 표시 부하 측정.
