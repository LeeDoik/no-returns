# 2. 현재 게임 명세

[English](02-spec.en.md)

검토일: 2026-09-09 · 게임 0.9.4 · 코드 기준: 이번 반응 장치 수정본.


이 문서는 현재 동작의 기준이다. 과거 기획과 충돌하면 이 문서와 연결된 코드를 확인한다. 새 코드와 다르면 문서를 갱신하며 과거 수치로 코드를 되돌리지 않는다. 아래 수치는 별도 표시가 없으면 기본값이다.

## 모드·진행·보상

- 솔로 또는 2~4인. 3계약 캠페인과 180초 연습이 있다.
- 캠페인 계약 시간은 240초 + 시간 장비 단계당 20초. 목표량은 인원 1/2/3/4명에 대해 5/6/8/10개에 계약 단계(0/1/2)×2를 더한다.
- 배송당 10크레딧, 릴레이면 5 추가. 계약 성공 시 획득액과 성공 보너스 20을 공동 잔액에 합한다. 실패 시 같은 방식으로 지급하지 않는다.
- 성공 후 마지막 계약 이전에 방장만 구매한다. 신발 20(최대 2단계, 이동 배율 단계당 +8%), 시간 25(최대 2단계), 경적 20(최대 1단계, 재사용 8→6초). 모두 준비하면 다음 계약으로 진행한다.
- 연습 기본 목표는 5/6/8/10개. 연장 보너스는 60초이며 현재 점수에 3/4/5/6개를 더한 목표다.

근거: [contracts.gd](../../scripts/contracts.gd), [round_rules.gd](../../scripts/round_rules.gd), [main.gd](../../scripts/main.gd).

## 입력과 일시정지

WASD 이동, 마우스 시점, Space 점프, E 집기/받기/내려놓기, 왼쪽 클릭 던지기, Q 표시, F 벨트 레버, R 경적, H 도움말, Esc 메뉴다. 본편 키 설정을 변경할 수 있다. 솔로 메뉴에서는 일시정지하고 온라인에서는 근무가 계속된다. 실험실은 별도 조작이며 [제작 가이드](03-guides.ko.md)를 따른다.

| 항목 | 현재 값 |
|---|---|

| 운반 가속도 / 점프 초기 속도 | 12m/s² / 4.8m/s |

| 질량: 일반 / 재채기 / 접착 / 점프 | 3 / 4 / 5 / 2.5kg |
| 상자 마찰 / 반발 / 회전 감쇠 | 0.65 / 0.06 / 0.6 |
| 집기 거리 | 2.4m 이내, 가림·소유·상태 검사 추가 |
| 던지기 | 전방 9.5m/s + 위 5.4m/s + 직원 속도 |
| 내려놓기 | 직원 속도 계승 |
| 직원이 미는 힘 상한 | 80N |

운반 중 상자는 물리 계산을 정지하고 이동 경로·회전 충돌을 검사하며 손 위치로 이동한다. 직원과 들고 있는 상자의 충돌은 예외 처리하고 직원에 운반용 충돌체를 켠다. 막힌 상자의 정면 간격이 0.9m 미만이면 운반을 해제한다. 현재 구조는 무게에 따라 손이 끌리는 물리 잡기가 아니다. 배송은 목적지 일치, 비운반, 미배송 상태를 만족해야 한다.

## 애니메이션·온라인·저장

직원은 41개 뼈·18개 동작을 사용한다. 운반 8방향, 공중·착지·던지기가 있으며 0.9.3은 전환·호흡을 조정했다. [전환 상세](../art/08-animation-polish.ko.md). 손/발의 완전한 접지 IK와 전신 래그돌은 없다.

ENet 방장 판정, 최대 4명, 기본 UDP 포트 27842, 프로토콜 12이다. 서로 다른 프로토콜·맵은 접속 검사를 받는다. 60Hz 실행 기준 일반 상태는 3틱마다(20Hz), 쥐는 6틱마다(10Hz), 메타데이터는 12틱마다(5Hz) 전송한다. Steam 친구 초대는 미연결이다. [통신 코드](../../scripts/session.gd).

로컬 설정과 완주 기록을 저장한다. 완주 기록은 `user://run_profile.cfg`이며 진행 중 캠페인 저장·Steam Cloud·온라인 순위표는 없다. 실험실 값은 `user://physics-lab.json`에만 저장하고 본편에 자동 반영하지 않는다.

## 0.9.4 반응 장치 개정

점프대 발판은 두께를 유지하며 스프링·안내봉의 높이가 발판 하단을 따른다. 문서는 재채기뿐 아니라 빠른 직원/화물 접촉에도 반응하고, 상자 더미는 충격 방향·세기·위치에 따른 장식 강체로 무너진다. 충격 정보를 온라인으로 공유한다. [수치·연출과 게임 판정의 경계](../art/09-reactive-impact.ko.md).
