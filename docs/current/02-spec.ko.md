## 실제 구현

현재 프로젝트는 [NoReturns](../../NoReturns)이며 새로 생성했다. Unity 6000.6.0f1, 3D URP 템플릿, URP 17.6.0, Input System 1.20.0, Pipeline MCP 0.7.0-exp.1을 사용한다. 설치 근거는 [버전](../../NoReturns/ProjectSettings/ProjectVersion.txt)과 [패키지](../../NoReturns/Packages/manifest.json)다.

[ProjectBootstrap](../../NoReturns/Assets/_NoReturns/Editor/ProjectBootstrap.cs)은 제품명 NO RETURNS, 버전 0.1.0, 기본 창 1280×720과 빈 Bootstrap 장면을 설정한다. 폴더는 Scenes·Runtime·Editor·Art·Audio·Data·Prefabs·Tests로 나눴다. 시작 장면에는 기본 카메라와 조명만 있다. 게임플레이는 아래 별도 CarryRoom 실험에 구현했으며 제품용 PSX 렌더러는 미구현이다.

## 확정된 제품 규칙과 구현 경계

[최상위 기획](01-overview.ko.md)에 따라 항로 선택 후 자동 이동·착륙, 위험한 지역의 배송, 보수로 장비 개선·고난도 계약에 도전하는 방향을 사용한다. 운반과 2인 직접 접속은 아래 실험에 구현했다. 실제 우주선·다양한 배송지·미스터리 전체 구조는 아직 없다. 단서 2개와 공용 현장 기록은 별도 실험에 구현했다. 크리처·신호기·위험도 선택 실험은 아래에 명시한다. 별도 배송 모드에 임시 항로와 보수 일부를 구현했다. 이전 게임의 지급 검사나 물리 수치는 새 게임의 검증 근거로 사용하지 않는다.

## 제거한 구현

기존 Godot 소스와 캐시, Unity 임시 프로젝트, CarryLab·SIDE EFFECTS·NR-LOOP-01, 이전 아트·빌드·실행 항목·게임 전용 도구를 삭제했다. 다운로드 폴더나 시스템에 설치한 Unity·Blender 같은 프로그램은 제거하지 않았다. Git 이력은 보존하지만 삭제 당시 미커밋·미추적 파일이 모두 Git에 저장됐다는 뜻은 아니다. [삭제 목록](../archive/space-reset-deletion-manifest.json)은 경로와 용량 기록이며 파일 백업이 아니다.
