[English](review-fixes.en.md)

## 제작·온라인 제약

[CarryRoom](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryRoom.cs)이 이탈 복구, F 단계 전환과 단서 활성 순서를 결정한다. [CarryThreat](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryThreat.cs)의 발밑 박스 검사와 인접 칸 높이 차는 현재 평지·낮은 단을 위한 것이다. 복층·임의 경사·이동 발판을 지원하는 일반 내비게이션 시스템으로 확장한 것은 아니다. 높은 장애물과 벽은 계속 우회한다.

선반 배치는 [CarryWorld](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryWorld.cs), 거절 메시지는 [CarryWire](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryWire.cs)의 선택적 rejection 필드와 [CarryLanguage](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryLanguage.cs)에 있다. 프로토콜은 6을 유지한다. 같은 0.8.2 실행본끼리 검사했으며 이전 버전과 혼합 접속은 미검증이다. 저장 형식과 경제 수치는 바꾸지 않았다.

## 추가 회귀 결과 — 0.8.2

전역 추적 Unity 검사 12개, 보수·권한·초기화 Unity 검사 17개를 통과했다. 실제 실행본에서는 [전역 추적 23개](../../artifacts/global-hunt/run-20260913-133956/report.json), [구조·밀치기 21개](../../artifacts/review-fixes/rescue-0.8.2.json), [위험 지역 배송 6개](../../artifacts/review-fixes/delivery-0.8.2.json)를 통과했다. 신규 검사를 합하면 실제 실행본 검사 67개, Unity 규칙·물리 검사 40개다. 두 실행본 결과를 비교했으며 개인의 실제 저장 파일은 사용하지 않았다.

규칙 실험은 편집 모드에서 게임 객체를 직접 구성한다. 런타임 Visual의 Destroy 호출로 발생한 편집 모드 경고성 오류 로그는 실험 도구의 제한으로 남는다. 이것을 게임 실행 오류로 분류하지 않으며, 대상 물리 검사에서는 직원 하위 충돌체를 제외한다. 실제 플레이어 로그에서는 해당 오류가 없었고 컴파일 실패도 없었다. 이번 검증은 렌더링 품질·성능 측정이 아니다.
