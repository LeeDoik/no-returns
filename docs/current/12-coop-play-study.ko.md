## 직접 비교 방법

처음에는 같은 친구 2~4명과 같은 입력 장치를 사용하고 인원·언어·버전·키 설정·음성 방식·호스트 여부를 기록한다. 기본 게임을 기준으로 하며 모드를 쓴 경우 명시한다. 인게임 음성이 있는 게임은 그 방식으로 먼저 경험한다. 처음 20분은 공략 없이 배우고, 다음 40~60분은 같은 행동을 반복하며 관찰하는 방식을 제안한다. 이는 분석 시간 제안이며 클리어 시간이나 충분한 숙련 시간은 아니다.

1. 조작: 잡기·놓기·점프 등을 반복했을 때 예상대로 되는가? 실패는 입력, 카메라, 충돌, 네트워크 중 무엇 때문이라고 느꼈는가? 느낌과 확인한 원인을 구분한다.
2. UI: 다음 목표, 내 위험, 동료 상태를 어디서 알았는가? 안내를 못 본 장면을 캡처하고 정보를 찾는 데 걸린 시간을 기록한다.
3. 협동: 동료가 꼭 필요했던 순간과 혼자 처리해도 같았던 순간을 나눈다. 가장 숙련된 한 명이 나머지를 지시만 하게 되는지도 본다.
4. 랜덤: 맵·아이템·적의 변화, 정해진 이벤트, 플레이어 실수·물리 상호작용을 구분한다. 같은 조건의 재도전에서 다른 선택이 가능한지 본다.
5. 방송: 웃긴 장면 전후를 짧게 녹화한다. 소리를 끈 영상에서도 누가 무엇을 해서 사고가 났는지 이해되는가? 사망 후 다시 행동할 때까지 얼마나 기다리는가?

기록 형식: 시간 / 목표 / 입력·선택 / 기대 / 실제 결과 / 화면·소리 피드백 / 감정 / 원인 가설 / 재현 여부 / 가져올 설계 원칙.

한 게임마다 좋았던 점 3개, 불편했던 점 3개, 가져올 원칙 1개를 남긴다. 공식 설명 확인은 완료했지만 실제 설치·접속·조작·UI·재미·방송 테스트는 미수행이다. 기존 게임의 물리 방식이나 확정 방향을 변경하는 결정은 없다.
