## 범위와 방향

현재 우주선 내부 시험 05를 사용한다는 사용자 결정을 유지한다. 외장은 제작하지 않는다. [독립 HTML](../../prototypes/cinder-depot/index.html)은 맵 구조 검토용이며 Unity 장면·모델·온라인 게임은 변경하지 않았다.

[Lethal Company 공식 소개](https://store.steampowered.com/app/1966720/Lethal_Company/)의 버려진 산업 시설 탐색을 참고했다. 아래 방 배치와 연결은 NO RETURNS용 수작업 제안이며 원작 지도 복제나 원작 생성 알고리즘 구현이 아니다.

## 구조와 선택

착륙장 포함 18개 이름 있는 공간을 좁은 회랑과 분기로 연결한다. 서쪽 현관, 하역실, 분류실, 보관실, 분전실, 관제실, 검사실, 수령소가 주 접근축이다. 기록실·보안실·펌프실·터빈실·억제 코어·작업실·냉각실·폐기물 저장소는 중앙과 동쪽 순환을 형성한다. 휴게실은 막다른 선택 탐색 공간이다.

서쪽 하역 마당과 남서쪽 착륙장, 동쪽 정비 마당, 남쪽 외부 우회로를 추가했다. 청회색은 시설 내부, 황토색은 외부다. 우주선부터 서쪽 주 출입구로 진입하고, 수령소 오른쪽 비상문으로 바로 외부에 나갈 수 있다. 동쪽 문은 안쪽에서 E로 열며 바깥에서는 열 수 없다. 닫혀 있어도 서쪽 출입구로 모든 구역과 배송지에 접근할 수 있다. 컨테이너·설비 장애물이 외부 우회로의 직선 시야와 이동을 꺾는다. 외곽 추적은 기존 억제 4단계 실험을 유지하며 외부 전용 생물·시야·엄폐 판정은 아직 없다.

추천 경로는 현재 위치부터 목적지까지 최단 연결을 보여주며 끄고 자유롭게 탐색할 수 있다. 내부 방을 전체 지도에 맞춰 재배치했으므로 이전 방별 치수를 유지하는 확대도가 아니다. 통로는 모두 화물 운반 가능하다. 직원 전용 길, 추가 잠금 퍼즐, 층간 이동, 시야 안개, 절차적 생성은 아직 없다.

## 실행과 규칙

루트의 Play_Map_Overview.cmd 또는 HTML을 브라우저로 연다. 외부 다운로드와 서버가 필요 없다. 한국어가 기본이며 English 버튼으로 전환한다.

- WASD/방향키 또는 바닥 클릭: 이동. Space: 시작·일시정지.
- E: 화물 들기 → 수령소 배송 → 영수증 회수 → 우주선 귀환 완료. 기록실 단서 조사와 안쪽 비상문 개방도 E.
- Q: 화물 내려놓기. F: 위험 모드에서 8초 유인 신호기. 이 실험의 신호기는 무제한이다.
- 위험은 기본 꺼짐. 켜면 45초 간격 4단계 억제 신호와 순찰·추적을 실험한다. 숫자 시간 대신 색과 상태 설명을 표시한다. 공격 예고 0.9초 후 우주선으로 회수하고 화물은 현장에 남긴다. 우주선 내부는 안전하다.
- 120×112m 범위는 10픽셀/m로 표현한 검토용 제안이다. 이동은 빈손 88픽셀/s, 화물 62픽셀/s로 가속되어 있다. Unity 실제 치수·물리·최종 난이도 검증으로 해석하지 않는다.

## 검증과 다음 통과 조건

[자동 검사](../../prototypes/cinder-depot/check.cjs): 닫힌 비상문을 제외한 모든 이동 셀의 연결, 화물 운반·배송·영수증·귀환 한 사이클, 비상문 바깥 개방 거절/안쪽 허용, 내려놓기·재회수, 동쪽 비상문 개방 후 정비 마당·남쪽 외부 우회로·우주선까지 이동 통과. Node 문법 검사 통과. 브라우저에서 지도 렌더와 읽기 전용 연결 진단을 확인했다(수령소·단서·순찰점 연결).

자동 검사는 모의 DOM에서 이동 로직을 실행한 결과이며 사람 조작감이나 온라인 검증이 아니다. 실제 브라우저에서 전체 귀환 사이클 수동 완주, 위험 모드 균형, 사람의 길 찾기·재미, 1인칭 시야·높낮이·4인 교행은 미검증이다. 추천 경로를 끄고 갈림길에서 목적지를 추론할 수 있는지, 재탐색이 지루하지 않은지 확인한 뒤 Unity 블록아웃으로 옮긴다.


## MAP-STUDY-04

외부 확장 04: 전체 범위를 120×112m 제안으로 넓혔다. 시설 내부 좌표는 유지하고 서쪽 안테나 구역, 동쪽 정비 마당, 남쪽 야적장·연료 설비 구역을 넓게 연결했다. 바깥 장애물 사이로 여러 방향의 이동이 가능하다. 안테나·연료 설비는 현재 위치 표식과 충돌 장애물이며 새 상호작용은 없다. 추가 외부 목적지 5곳까지 이동 및 기존 배송·비상문·귀환 자동 검사 통과. 브라우저 지도 표시와 오류 0건 확인. 1인칭 조작감·위험 균형·Unity 적용은 미검증.


## MAP-STUDY-05

시설 북쪽 외부 정비 지대를 추가해 동서남북으로 한 바퀴 도는 외부 순환을 구현했다. 전체 제안 범위 120×112m. 내부와 외부 사이 간격을 유지하고 기존 서쪽 출입구·동쪽 비상문으로만 연결한다. 외부 전체 순환·기존 배송·문 규칙 자동 검사 통과, 브라우저 표시와 콘솔 오류 0건 확인. Unity 적용·사람 조작감은 미검증.
