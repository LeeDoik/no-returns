# Cinder 억제기·외곽 생물 — 0.9.4

[English](cinder-suppression.en.md)

2026-10-02 · 구현·실제 네 실행본 60개 검사 통과. [현재 검증 기록](../validation/cinder-suppression-0.9.4.json). 이전 0.9.3의 Cinder 억제/외곽 미연결 설명을 이 범위에서 대체한다. 배송·리스너·진압봉·구조 조작은 [리스너 안내](cinder-listener.ko.md)와 [조작 안내](controls-ui.ko.md)를 유지한다. 최종 외곽 모델·사람 품질 승인·진행 저장은 포함하지 않는다.

## 플레이 규칙

기본 Cinder 실행에 리스너 1개와 외곽 생물 1개를 함께 연결했다. 방장이 현장 단계(배송 중/수령 완료) 시간을 진행한다. 선내 대기·메뉴 열기로 시간을 멈추지 않는다. 정산/준비 중에는 멈추며 다음 도착에서 초기화한다. 기존 검증값 **90/135/180초**를 유지해 정상 → 불안정 → 붕괴 임박 → 정지로 진행한다. 정지 뒤 **8초**, 도착 후 **188초**부터 외곽 생물이 움직인다. 출시 난도 확정값이 아니다.

억제기 4개의 기존 신호부와 경계선을 초록 → 주황 점멸 → 빨강 점멸 → 어두운 정지 상태로 표시한다. 기존 공간의 작업등 40개는 원래 밝기에 대한 비율 **1 / 1.15÷1.5 / 0.8÷1.5 / 0.45÷1.5**로 약해진다. 정지 시 기존 환경광을 0.65배로 낮추고 정산 화면에서는 원래 밝기를 복원한다. 저장된 하늘·안개·태양 밝기/방향은 바꾸지 않는다. 상태 문구와 기존 임시 신호음을 사용하며 HUD에 숫자 남은 시간은 표시하지 않는다.

외곽 생물은 붕괴 임박 단계부터 **(29,0,18)m** 동쪽 경계 밖에서 먼저 보이고, 유예가 끝나면 기존 동쪽 진입구를 통해 직원을 추적한다. 기본 리스너는 계속 움직인다. 외곽 생물은 벽 뒤·먼 직원도 찾지만 벽을 우회하고 거리·가시선·**0.9초 경고** 후 공격한다. 다운/선내 직원은 추적에서 제외한다. 기존 **2.2m/s 순찰·3.3m/s 추적·0.8초 대상 갱신**을 유지하며 진압봉으로 저지하지 못한다.

구매한 신호기는 기존 **120 CR 사용권·근무 2회·각 8초·12m 유인**을 유지한다. 일반 리스너는 소음 조사로, 외곽 생물은 마지막 유효 신호부터 **1.2초** 직원 추적을 대신해 신호 위치로 움직인다. 신호가 끝나면 직원 추적을 재개한다. 공격 예고/회복 동작을 신호기로 취소하지 않는다. 선내 놓기는 횟수를 쓰지 않는다.

두 생물은 같은 네 직원의 다운 상태와 구조 후 보호를 사용한다. 외곽 공격으로도 화물을 놓고 기존 E 구조/전원 다운 긴급 회수로 이어진다. 정상 영수증 귀환 **300+120=420 CR**, 신호기 구매 후 **300 CR**, 실패 시 기존 지갑 보존·새 배송 보수 없음 규칙을 유지한다. 다음 근무에서 화물·직원·생물·신호기 횟수를 초기화한다. Cinder 지갑/사용권은 아직 세션 전용이다.

## 실행·제작 기준

[07_Play_Cinder_4P.command](../../07_Play_Cinder_4P.command) 또는 `python3 tools/cinder_four_player.py start`. 맥 버전 **0.9.4**, 공통 프로토콜 **13**, Cinder TCP **27842**. 같은 실행본끼리 연결한다. `--map-only` 이동 시험과 `--delivery-only` 위험 없는 배송 회귀는 유지한다. [종료 도구](../../08_Stop_Cinder_4P.command).

원본 아트 씬·모델·텍스처·충돌·동선을 보존하고 기존 파생 씬/빌드 경로를 사용한다. [CarrySuppression](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarrySuppression.cs)은 현재 신호부의 런타임 재질 복사본과 원래 작업등 밝기를 사용한다. 저장된 공용 재질은 덮어쓰지 않는다. 옛 단서·진행 저장은 Cinder에서 생성하지 않는다.

[CarryThreat](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryThreat.cs)의 Cinder 리스너 격자는 기존 **x=-27~25, z=-34~30m**다. 외곽 생물은 현재 108×86.4m 지면/추락 방지 경계 안의 **x=-53~53, z=-42~42m**로 넓혀 외곽으로 달아난 직원도 찾는다. 1m 정적 바닥/장애물 격자, 높이차 0.32m, 선내 경사로/갑판 제외를 재사용한다. 배경 암석은 기존 장식이고 새 충돌을 추가하지 않았다. 동적 지형·이동 화물/직원 경로 회피·최종 외곽 모델/애니메이션은 범위 밖이다.

## 검증과 남은 일

[native 단계/조명/경로 검사](../../tools/unity_checks/CinderSuppressionCheck.cs)는 시간 경계 9개, 신호부/경계선 5개, 작업등 40개, 외곽 경로 7개·충돌 1,600회, 격자 8,056개와 하늘/안개/태양 보존을 확인했다. 명시적 시간/위치 설정을 사용하는 규칙 검사이며 사람 플레이나 실제 시간 검사는 아니다.

[실제 네 실행본 검사](../../tools/test_cinder_suppression.py)는 일반 이동·화물 조작·구매·신호기 놓기 입력과 실제 시간을 사용한다. 위험 속 배송/정산, 리스너 유인, 단계 일치·사전 징후·진입 유예, 외곽 유인/재추적·공용 다운·선내 보호·긴급 회수·다음 근무를 검증한다. 순간이동/다운/잔액/시간 주입을 사용하지 않는다. 실제 60개 검사 통과·맥 빌드 오류 0개/기존 경고 7개. [붕괴 임박 한글 화면](../../art/cinder-kit-01/suppression-failing-ko.png) · [정지 영문 화면](../../art/cinder-kit-01/suppression-off-en.png). 800×500 경고 표시를 확인하고 LFS PNG 2개를 보관한다. 기존 리스너/구조 31개·위험 없는 배송/UI 48개·이동/접속 13개 회귀도 통과했다. 실제 네 실행본 검사 합계 152개, 문서 274개 링크/언어·체크 상태 검사 통과. 기존 재질 편집을 제외한 이번 변경 공백 검사 통과. 사람 품질·다른 환경 검증과 구분한다.

사람 네 명의 경고 판독·운반/회피/구조·재미·외형/음향/어두워진 바닥 가독성, 다른 PC/LAN·Windows·성능/장시간 안정성은 별도 검토다. 자동 통과를 해당 품질 승인으로 취급하지 않는다.

최종 실행본으로 시험 입력 폴더 없는 수동 네 창을 열고 방장 TCP 연결 3개를 확인했다. 사용자 검토용으로 실행 상태를 유지한다. 자동 시험 종료 직후 첫 실행은 포트 사용 중 판정으로 거절됐고 짧게 기다린 재시작이 통과했다. 사람 입력/품질 검증은 아니다.
