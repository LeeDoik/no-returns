# NO RETURNS — 다른 PC 실행 안내

[English](cinder-portable.en.md)

2026-09-18 · CINDER-DEMO-01 · Windows 64비트용 내부 테스트 배포

1. 패키지 폴더 전체를 다른 Windows PC로 복사한다. 압축해서 전달했다면 전체를 먼저 푼다.
2. `PLAY.cmd` 또는 `NoReturns-CinderDemo.exe`를 실행한다. Unity 설치는 필요 없다.
3. 혼자 플레이하려면 방 만들기를 누른다. 협동은 모두 같은 버전을 실행하고 출발 전에 참가한다.
4. 같은 공유기/내부 네트워크에서 방장은 방 만들기, 참가자는 방장 PC의 IPv4 주소를 입력하고 참가하기를 누른다. 방장 주소는 방장 PC에서 `ipconfig`로 사용하는 네트워크 어댑터의 IPv4 주소를 확인한다.
5. Windows 방화벽에서 네트워크 허용을 묻는다면 사용하는 신뢰된 개인 네트워크에 허용한다. 연결 포트는 TCP 27841이다. 방화벽 전체를 끌 필요는 없다.

`127.0.0.1`은 같은 PC에서만 사용한다. 다른 집이나 외부 인터넷을 통한 자동 접속·Steam 초대는 현재 지원하지 않는다. LAN도 실제 다른 PC에서의 최종 확인은 남아 있다.

`NoReturns-CinderDemo_Data`, `MonoBleedingEdge`, `D3D12`, DLL 등 동봉 파일은 실행 파일과 함께 유지한다. EXE만 보내면 실행되지 않는다. `runtime-manifest.json`은 원본과 복사본을 SHA-256으로 대조한 목록이다. 개발용 백업·프로젝트·사용자의 진행 저장은 포함하지 않는다. 진행은 플레이하는 PC의 방장 계정에 따로 저장된다.

WASD 이동, 마우스 시야, E 상호작용/동료 구조 길게 누르기, Q 내려놓기, Shift 조용히 걷기, Space 빈손 점프, C 소리 내기, 왼쪽 클릭 충격봉, Esc 메뉴. 언어 전환은 메뉴에서 한다.

우주선에서 E로 계약·출발 → 화물을 E로 들고 BAY 04로 운반 → 표시된 바닥에 Q로 내려놓기 → 인쇄된 영수증을 단말기에서 E로 회수 → 전원 우주선으로 돌아와 E로 귀환·정산. 첫 일반 계약 보상은 420CR다.

이 빌드는 기본 도형 데모다. 실제 사람의 재미·모든 PC 호환성·Steam 출시는 검증 완료가 아니다.


**버전 주의:** 기존 9월 18일 휴대용 패키지는 프로토콜 11이다. 이번 밀집 시설 빌드는 프로토콜 12이므로 서로 접속할 수 없다. 다른 PC 검사 시 양쪽 모두 새 빌드 전체를 복사해야 한다.
