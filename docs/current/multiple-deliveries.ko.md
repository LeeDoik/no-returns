## 구현된 규칙

[NR-COOP-01](coop-design-v1.ko.md)의 다음 구현 단계이며 [방문 정산](visit-settlement.ko.md)에 연결한다. 일반 Cinder 세션은 기존 단일 420 CR 배송 대신 여러 실물 상자를 사용한다. 안전 동료 연습과 기존 빠른 검사 준비 상태는 연습용 상자 하나를 유지한다.

1/2/3/4명에 맞춰 3/4/5/6개 화물을 배에 싣는다. 준비 중에는 인원에 따라 목록을 갱신하고 착륙하면 고정한다. 한 사람은 상자 하나만 운반하며 여러 사람이 서로 다른 상자를 동시에 운반할 수 있다. 기존 집기·회전·거리·놓기·떨구기 조작을 사용한다. 상자 주소 라벨이나 배 단말기의 DELIVERY MANIFEST(배송 목록)를 보고 가져갈 화물과 순서를 자유롭게 선택한다. 정확한 수령 지점을 가리키는 HUD 표시는 추가하지 않는다. 미완료 화물에는 별도 포기 벌금이 없으며 동료 귀환 비용은 유지한다.

| 화물 | 주소 | 기본 보상 |
| --- | --- | ---: |
| NR-01 | WEST / BAY 02 | 100 CR |
| NR-02 | WEST / BAY 02 | 120 CR |
| NR-03 | EAST / BAY 04 | 180 CR |
| NR-04 | NORTH / BAY 07 | 160 CR |
| NR-05 | EAST / BAY 04 | 200 CR |
| NR-06 | NORTH / BAY 07 | 180 CR |

인원에 맞는 개수만큼 위에서부터 사용한다. 경제 밸런스가 검증된 값이 아닌 최초 구현 수치다. WEST 묶음 보너스는 55 CR, 두 계약이 있을 때 EAST는 95 CR, NORTH는 85 CR이다. 계약이 하나뿐인 구역에는 보너스가 없다. 구역 기본 보상 합계의 25%를 내림하여 마지막 영수증과 함께 한 번만 지급한다. 계약이 1 또는 0개 남았을 때만 배 단말기에 보너스를 공개하며 전역 안내는 하지 않는다.

상자를 해당 주소의 표시된 바닥에 내려놓고 움직임이 멈추면 검수한다. 검수 시간은 25초이며 수령 지점 하나에서 상자 하나씩 처리한다. 서로 다른 수령 지점은 동시에 작동할 수 있다. 사람이 떠나도 계속 검수한다. 상자를 들거나 범위 밖으로 옮기면 검수 진행과 소음은 멈추지만 진행도는 유지한다. 되돌려놓으면 이어서 검수하며 중단된 상자는 기계를 독점하지 않는다. 검수 중에는 현장 반복음과 주기적인 리스너 유인이 발생한다. 완료되면 현장 녹색등·영수증·확인음을 표시한다. 검수 완료 상자는 영수증을 받을 때까지 고정하고, 영수증을 받으면 팀 기록에 즉시 반영하며 실물 상자를 제거한다. 중복 수령으로 다시 돈을 받을 수 없다.

기본 보상과 묶음 보상은 모두 미정산 수익이다. 유료 부활에 사용할 수 있고 출발할 때만 지갑에 입금한다. 기존 실패·동료 귀환 비용·자동 출발 규칙은 유지한다. WEST 두 건은 부활·귀환 비용 차감 전 275 CR이다. 다음 착륙에서는 화물을 초기화하고 정산된 지갑 잔액을 유지한다.

## 검증과 남은 작업

[검증 기록](../validation/multiple-deliveries-0.9.24.json)을 참고한다. 자동 검증과 사용자 품질 승인은 구분한다. 수동 플레이 창은 열지 않았다. 실제 운반 검사는 적 AI를 끄고 배송을 독립 검증하며 검수 중 전투·구역 난이도·소리 식별성을 검증하지 않는다. 전용 접근 표지, 무작위 계약, 추가 배송, 모든 수령 지점 경로, 여섯 화물의 모든 동시 운반 배치, 저장·재접속과 1–4인 밸런스는 미구현 또는 미검증이다. 기존 위험 단계 90/135/180/188초를 17/18분 출발 일정에 맞추는 작업은 아직 하지 않았다. 이번 변경에는 새 장비 구현이 없다.

이번 작업 세션의 공식 확인에서 Unity 6000.6.4f1, CLI 1.0.0-beta.12, Pipeline 0.8.0-exp.1은 최신이었다. 기존의 관련 없는 머티리얼·Blender 변경을 보존한다.


검사 결과: Editor 규칙 27개, 실제 2인 비콘·구조·진압봉 23개, 실제 4인 배송 24개 통과. 기존 유료 부활·출발의 실제 2인 검사 17개도 통과했다. 최종 Mac 빌드는 오류 0개·기존 경고 7개다. 최초 검사에서 서쪽 단말기가 외곽 벽과 겹쳐 접근할 수 없었고 통로 안쪽으로 옮겨 실제 이동을 재검증했다. 출발 검사에서는 배송 목록에서 단말기로 돌아오는 화면을 기다리지 않은 자동화 문제를 고쳤다. 기존 전체 위험 검사 두 개는 과거 규칙에 의존하므로 클라이언트 실행 전에 중단하도록 표시했다. 새 규칙 이행 전까지 전체 위험 회귀 통과로 간주하지 않는다.
