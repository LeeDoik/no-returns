## 목적과 범위

배송을 하면 다음 도구를 선택할 수 있고, 실패해도 기본 장비로 다시 출발할 수 있게 한다. 이는 사용자가 요청한 경제 설계 초안이며 최종 수치가 아니다. 첫 검증은 근무당 계약 1개·화물 1개·배송지 1곳으로 제한한다. CR은 팀 공용 게임 재화이며 인원마다 복제하거나 나누어 지급하지 않는다. 시작 잔액은 0 CR이다. 이미지의 기존 잔액 180 CR은 진행 중 예시다.

## 보수

| 단계 | 기본 배송 B | 상태 보너스 최대 Q | 귀환 보너스 최대 R | 최대 합계 |
|---|---:|---:|---:|---:|
| 기본 | 240 | 60 | 120 | 420 |
| 위험 | 360 | 90 | 180 | 630 |
| 심층 | 480 | 120 | 240 | 840 |

화물 상태 배율 q는 정상 1, 손상 0.5, 심한 손상 0이다. 첫 버전은 심한 손상도 수령할 수 있고 운반 중 완전 소멸은 제외한다. 낙하·충격 임계값은 별도 물리 검증으로 정한다. 접수 전 라벨·단말기에서 상태 등급을 확인할 수 있다.

- 수령 확정 즉시 B + Q × q를 공용 계좌에 한 번 기록한다. 누군가 죽거나 전멸해도 회수하지 않는다.
- 귀환 추가 지급은 배송 완료 시에만 floor(R × r / n)이다. n은 착륙 시 고정한 참가 직원 수, r은 귀환한 직원 수다.
- 미배송이면 모든 보수는 0이다. 빈 출발·즉시 귀환으로 보너스를 받지 않는다.
- 기본·상태 보수는 정산 화면에서 다시 더하지 않는다. 정산은 기존 지급 내역을 보여주고 귀환 보너스만 추가한다.
- 억제장치 가동 종료는 보수 삭감 조건이 아니다. 배송·귀환 위험이 증가하며 직접 시간 보너스나 정확한 카운트다운은 두지 않는다.

## 사고·실패와 회복

다운은 동료 구조 가능 상태, 사망은 해당 근무에서 조작 불가 상태로 제안한다. 다운된 직원을 생존 상태로 선내에 운반하면 귀환 인원에 포함한다. 구체적인 구조 조작과 사망 전이 조건은 미정이다. 전원 행동 불능이면 근무 종료·기지 정산으로 넘어간다. 새 근무에서 전원 복귀하며 영구 캐릭터 손실·부채·강제 사망 비용은 없다.

이미 수령한 화물 보수와 장비 해금·개조는 보존한다. 미배송 화물은 무보수로 계약 종료, 현장에 버린 선택 소모품은 손실이다. 우주선에 안전하게 보관하거나 직원이 반입한 미사용 소모품만 창고에 반환한다. 전멸 시 선내에 보관된 물품은 회수된 것으로 처리하는 안이다. 기본 장비와 해금 장비의 본체는 다음 근무에 다시 지급한다. 실패의 주된 손실은 귀환 보너스·소모품·진행에 쓴 시간이다.

한 명이라도 살아 있을 때는 자동 종료하지 않는다. 출발은 탑승한 생존자의 준비 확인으로 진행하는 안이며, 남겨질 직원 목록을 명확히 보여준다. 선외 생존자의 존재 때문에 귀환이 영구 차단되지는 않게 한다. 의도적 유기·방장 권한·재접속 처리의 공정성은 플레이 검증 대상이다.

## 구매·개조와 장비 공간

| 항목 | 가격 CR | 구매 결과 |
|---|---:|---|
| 기본 손전등·충격봉 | 0 | 모든 직원에게 지급, 재충전·재지급 무료 |
| 유인 신호기 라이선스 | 120 | 해당 캠페인 영구 해금 |
| 압축가스 발사기 라이선스 | 300 | 해당 캠페인 영구 해금 |
| 충격봉 절연 손잡이 | 180 | 자신의 사용 후 경직을 줄이는 개조 후보 |
| 발사기 효율 밸브 | 240 | 동일한 밀침에 드는 가스 감소 후보 |
| 신호기 지향성 혼 | 180 | 멀리 전달하는 좁은 방향 모드 후보 |
| 화물 고정 랙 | 300 | 선내 운송 중 화물 흔들림 완화 후보 |
| 추가 보급 팩 | 40 | 출발 전 선택 구매, 배치당 1회 사용 |

위 개조는 각각 한 번만 구매하며 원 장비 해금이 선행 조건이다. 개선량은 아직 정하지 않는다. STRIDER를 죽이거나 억제장치 시간을 늘리는 개조는 이 초안에 없다.

라이선스는 팀에 속한다. 해당 장비를 중복 선택할 수 있으며 공용 출동 랙 4칸에 슬롯당 본체 1개를 준비한다. 기본 손전등·충격봉은 랙 밖 개인 지급품이다. 각 직원은 추가 장비 1개만 휴대한다. 실사용 중 즉석 본체 무한 재생성은 금지한다. 1~4인 모두 같은 공용 잔액·가격·보상표를 쓰며 소수 인원용 화물·경로 난도는 별도로 조정한다.

기본 충전은 근무 시작 시 선택된 본체에 1회 무료 제공하며, 근무 중 선내 재충전은 제공하지 않는다. 무료 충전을 소비한 뒤 다음 근무의 정상 지급은 가능하다. 잔량을 판매하거나 다른 장비로 옮길 수 없다. 추가 팩은 선택적으로 총 2개까지 싣고 각 1칸을 사용한다. 즉 장비와 추가 보급이 같은 4칸을 경쟁한다. 팩은 장비별 저장 용량 이내로만 채우며 충전량은 도구 검증에서 정한다. 미사용 팩은 귀환 시 재보관하고 무료 지급하지 않는다. 판매·분해 환급은 첫 버전에서 제외한다.

필수 연료비·수리비·재출동비는 없다. 잔액이 0이어도 기본 계약을 시작할 수 있다. 기본 도구만으로 모든 필수 배송을 수행할 수 있도록 경로를 제공한다.

## 성장과 지속성

위험 업무는 기본 업무 2회 배송·귀환 성공 후, 심층은 위험 업무 2회 배송·귀환 성공 후 공개하는 안이다. 여기서 성공은 수령 후 최소 1명이 귀환한 근무다. 금액을 입장료로 지불하지 않는다. 고난도는 선택이며 기본 업무는 계속 남는다. 높은 보수는 더 큰 운반·경로·정보 부담의 대가이며 크리쳐 체력만 증가시키지 않는다.

첫 정상 배송은 420 CR로 발사기 300 + 신호기 120을 함께 살 수 있다. 이후 소모품과 개조의 순서를 선택한다. 필수 유지비로 재화를 계속 빼기보다, 이 유한 장비 목록을 모두 산 뒤 돈의 쓰임이 줄어드는 것을 첫 검증의 범위 한계로 인정한다. 장기 경제는 장비 사용 데이터 이후 추가한다.

공용 자금·라이선스·개조·계약 기록은 방장의 캠페인 저장에 귀속한다. 참가자는 이 캠페인 장비를 함께 사용하지만 다른 방으로 재화나 아이템을 복제해 가져가지 않는다. 참가자의 개인 진척은 첫 범위에서 제외하며 입장 시 이를 안내한다. 구매는 기지에서 방장이 확정하고 다른 직원은 선택 요청을 보내는 안이다.

## 중복 지급·이탈 방지 요구사항

방장이 runId/contractId/receiptId로 지급과 수령을 한 번만 처리하고 영수증 기록과 지갑을 함께 저장해야 한다. 재접속·영수증 재수령·상호작용 반복으로 추가 보수는 없다. 이미 완료된 근무 ID를 재정산하지 않는다. 상점은 잔액 확인·차감·해금을 한 거래로 처리하며 중복 구매는 실패한다. 임무 중 구매는 불가하다.

착륙 시 n을 고정하고 신규 참가자는 다음 근무부터 참여한다. 연결 종료는 즉시 귀환으로 취급하지 않으며 같은 직원으로 재접속한다. 기지로 회수되지 않은 직원은 귀환 보너스에 포함하지 않는다. 방장 이탈은 캠페인을 일시 중단하며 저장 상태로 재개한다. 자동 이전과 오프라인 저장 조작 방지는 첫 범위 밖이다.

## 계산 예시와 검증

| 기본 계약 결과 | 총 보수 CR |
|---|---:|
| 정상 화물·전원 귀환 | 420 |
| 정상 화물·4명 중 2명 귀환 | 360 |
| 정상 화물·배송 후 전멸 | 300 |
| 손상 화물·전원 귀환 | 390 |
| 심한 손상·전원 귀환 | 360 |
| 미배송·전원 귀환 | 0 |
| 미배송·전멸 | 0 |

[귀환 정산 화면](../art/space-concepts/shift-report-01.png)은 기존 180 + 이번 360 = 540 CR이다. [상점 화면](../art/space-concepts/equipment-shop-01.png)은 그 뒤 540 - 300 = 240 CR을 표시한다. 상점에는 본체 구매와 잠긴 후속 개조를 함께 보여주며 둘을 동시 결제하지 않는다.

자동 계산 검사는 문서 수식과 표의 산술, 인원별 단조 증가, 빈 귀환 무보수, 첫 구매 접근성만 확인한다. 실제 Unity 지급·저장·온라인 테스트가 아니다. 이미지의 금액·선택 이름은 시각 확인했다. 균형이 잘 맞는다는 결론은 아직 내리지 않는다.

- [ ] 첫 구매까지 걸리는 근무 수와 소모품 구매 부담을 실제 플레이에서 기록.
- [ ] 죽어서 빠르게 정산하는 전략이 정상 귀환보다 유리한지 CR/분과 재미로 비교.
- [ ] 일부 직원 유기로 얻는 시간과 잃는 보너스, 구조 의향 평가.
- [ ] 솔로와 다인 수익·운반 부담·장비 선택 비교.
- [ ] 추가 보급을 항상 사거나 항상 무시하는지 확인.
- [ ] 중복 지급·구매·재접속·방장 재개를 실제 프로세스에서 검증.

배송 후 전멸 보수 300을 유지하는 만큼 자살 정산이 빠르면 반복 악용 동기가 생길 수 있다. 실제 측정 후 귀환 보너스·귀환 거리·재출발 소요를 함께 조정하되 확보 보수 몰수나 긴 강제 대기로 임시 봉합하지 않는다. 기준은 정상 귀환이 유리하면서 실패한 팀도 다음 시도를 하고 싶은가이다.
