# FLATBED 내부 02 — 정면 창문에 맞춘 배치

[English](ship-interior.en.md)

2026-09-13 · 외부 A와 정면 창문 수정본에 맞춘 내부 제안. 아래 치수는 이미지에서 실측한 값이 아니라 모델링 전 검증할 설계 가정이다. 코드·모델·게임 빌드 변경 없음.

![내부 02](../../art/ship-concepts-01/interior-glazing-aligned-02.png)

## 배치

후방 램프 → 입구 → 화물 → 장비 준비 → 정면 조종 구역의 단층 구조다. 3분할 정면 유리가 실제 조종 구역의 외벽이며 낮은 항로·보급 콘솔을 창문 아래에 둔다. 이전 초안의 전방 비거주 구획은 없앤다. 기계 공간은 바닥 아래와 외부 엔진 포드로 제안한다. 자동 이동·착륙 규칙은 유지한다.

정면을 바라볼 때 왼쪽에 신호기, 오른쪽에 충격봉 보관대를 둔다. 좌석은 양옆 2개씩 총 4개이며 접은 상태를 기준으로 통로를 확보한다. 화물은 양옆에 고정하고 중앙은 비운다. 침실·주방·추가 층은 없다.

## 치수 계산

| 항목 | 제안값·계산 |
|---|---|
| 닫힌 선체 | 길이 11.2m × 최대 폭 10.8m; 열린 램프 제외 |
| 폭 구성 | 중앙 외장 7.2 + 양측 엔진 포드 1.8씩 = 10.8m |
| 실내 기본 폭 | 중앙 외장 7.2 - 양측 구조 여유 0.4씩 = 6.4m |
| 실내 길이 | 입구 1.4 + 화물 3.0 + 준비 1.2 + 조종 2.0 = 7.6m |
| 기수 테이퍼 | 앞쪽 2.0m 구간에서 폭 6.4 → 4.8m |
| 가구 배치 전 면적 | 6.4×5.6 + (6.4+4.8)/2×2.0 = 47.04㎡ |
| 화물 구간 폭 | 랙 0.8 + 접근 1.4 + 통로 2.0 + 접근 1.4 + 랙 0.8 = 6.4m |
| 높이 | 유효 높이 목표 2.5m; 기수 경사 아래 머리 간섭 검증 필요 |
| 후방 출입구 | 폭 3.0m × 높이 2.4m |
| 램프 | 길이 3.0m, 상승 0.6m 가정; 약 11.54도, 수평 돌출 약 2.94m |
| 두 직원 충돌 폭 | 0.68×2=1.36m; 2.0m 통로와 차이 0.64m |

47.04㎡는 가구와 경사 벽의 침범을 빼기 전 평면 면적이다. 구조 여유 0.4m는 배관·외장 확보 가정이다. 실내와 외부 길이 차이만으로 부품이 들어감을 증명하지 않으며, 창 높이·기수 경사·문짝 힌지는 같은 3D 블록에서 확인해야 한다. 그림은 배치·분위기 시안으로, 정확한 CAD 투영이나 충돌 검증 결과가 아니다. 치수선 위치·면의 원근보다 이 문서의 숫자를 기준으로 검증한다.

## 검증 상태

실내 길이 합계, 폭 합계, 테이퍼 면적, 램프 삼각 계산을 확인했다. 이미지에서 전방 유리와 콘솔, 후방 램프, 양방향 장비 배치를 시각 검토했다. 이전 7.6m 실내 폭 오기는 6.4m로 수정했다. 실제 메시에 맞춘 실측·조작 검증은 미실시다.

- [ ] 외부·내부 동일 블록에서 창문·바닥·천장·기수·램프 정합성 확인.
- [ ] 실제 눈높이에서 창 밖이 보이고 콘솔이 시야를 막지 않는지 확인.
- [ ] 4인 진입·상자 0.8×0.65×0.65m 운반·교차·내려놓기 확인.
- [ ] 좌석 펼침·장비 꺼내기 이후 접근 공간 확인.
- [ ] 사용자 내부 외형 검토 후 제작 구조 확정.
