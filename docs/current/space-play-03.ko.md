# SPACE-PLAY-03 — 소음·다운·구조 실험

[English](space-play-03.en.md)

2026-09-13 · 검증용 제안 수치. 기존 운반·배송 모드를 보존하고 `--hazard`에만 적용한다. 최종 아트나 전체 출시 범위가 아니다.

## 구현 계획과 통과 조건

1. LISTENER는 북쪽 작업장(z≥3)에서 순찰한다. 일반 걸음은 6m, Q 소리내기는 12m, 화물 내려놓기는 10m 이내에서 마지막 소음 위치를 조사하게 한다. Shift 조용히 걷기는 1.5m/s, 화물 운반 중 1m/s이고 걸음 소음을 내지 않는다. 정지·조용히 이동·동료 유인이 기본 해법이다.
2. 생물은 장애물을 제외한 작업장 격자 경로로 이동한다. 순찰 1.4m/s, 조사 2.5m/s. 근접 시 1.2초 경고 후 1.5m와 가시선 안의 직원만 다운시킨다. 공격 후 4초 회복. G 빈손 밀치기는 거리 2.5m·시야 65도·가시선 조건으로 3초 저지하고 6초 재사용 대기를 갖는다. 살해·최종 장비는 포함하지 않는다.
3. 다운 시 이동·집기·출항을 막고 화물을 놓는다. 동료 2m 이내에서 빈손으로 R을 2.5초 유지하면 구조한다. 거리 이탈·키 해제·장애물·구조자 다운 시 진행을 취소한다. 구조 후 4초 보호. 전원 다운 상태가 3초 지속되면 미배송은 무보수, 확보한 보수는 유지한 채 선내 정산으로 복귀한다. 사망·직원 업기·영구 저장은 후속 작업이다.
4. 방장이 소음·추적·공격·밀치기·다운·구조·정산을 결정하고 두 실행본에 복제한다. 새 HUD와 조작 안내는 한국어 기본·영어 전환을 유지한다. 생물 색과 임시 경고음을 함께 제공하지만 실제 소리 전달력은 사람 평가가 필요하다.
5. 자동 검사는 조용한 접근, 소음 반응, 공격 전 경고, 다운·화물 해제·이동 제한, 원거리 구조 거절, 구조 취소·완료, 밀치기·재사용 제한과 전원 다운 복귀를 확인한다. 기존 배송 보수도 회귀 검사한다. 실제 재미·공포·동선 이해는 자동 검사와 구분한다.

구현 파일: CarryThreat(행동·복구·임시 표시), CarryRoom(입력·운반 연결), CarryWire(복제 상태), CarryLanguage(한영 HUD), test_hazard_build.py(실제 실행본). 런타임 격자는 현재 임시 작업장 전용이며 CINDER DEPOT 최종 맵의 경로 시스템 확정이 아니다.

## 실행·현재 범위

[06_Play_Listener_Test.cmd](../../06_Play_Listener_Test.cmd)에서 방 만들기, [07_Join_Local_Listener.cmd](../../07_Join_Local_Listener.cmd)로 같은 PC 참가. F 두 번으로 항로 선택·도착 후 북쪽 통로로 이동한다. 크리처가 멈추며 붉어지면 뒤로 피하거나 빈손 G로 저지한다. 동료가 다운되면 E로 화물을 내려놓고 가까이서 R을 유지한다. 한국어 기본·메뉴 한영 전환을 유지한다.

범위는 작업장 안의 일반 크리처다. 외곽 STRIDER·억제장치·간접 제한시간은 아직 없다. 경고음과 몸 형태는 임시다. 크리처 몸에는 직원·화물용 물리 콜라이더를 두지 않고 근접 공격 거리로 접촉 위험을 판정한다. 작업장 격자는 정적 지형용이며 이동 화물·직원은 경로 장애물로 사용하지 않는다. 가시선은 고정 장애물 기준이다. 선내 소음은 무시하고, 선외 소음에는 작업장 경계까지 접근할 수 있다.

정상 귀환은 서 있는 전원이 선내에 모여야 한다. 구조자·구조 대상은 움직임 제한과 조준 표시만 바뀌며 최종 애니메이션이 아니다. 긴급 회수는 이번 근무를 정산 상태로 끝내므로 F로 새 근무를 시작한다. 이미 지급한 보수는 유지하지만 귀환 보너스는 지급하지 않는다. 기존 세션 메모리 지갑이며 영구 저장은 없다.

프로토콜은 3이다. 연결되는 실행본은 모두 같은 버전을 사용한다. 입력·다운·구조 진행·소음 위치·생물 상태·보수를 방장이 판정하고 참가자는 결과를 표시한다.

## 검증 근거

[두 실행본 검사](../../artifacts/space-play-03/latest.json)는 실제 이동·키 입력을 사용한다. [검사 도구](../../tools/test_hazard_build.py)에는 순간이동·직접 다운 주입을 넣지 않았다. 확보 보수 유지에 대한 Unity 근무 규칙 검사와 실제 배송·구조 플레이 검사는 구분한다. 실제 사람의 무서움·조작감·경고음 전달력·협동 재미는 미검증이다.
