## 2026-09-13 — Unity 약관 창과 라이선스 연결 조사

보이지 않는 Software Terms 기록을 재조사했다. Windows 창 목록에 Unity가 없었고 CLI는 STATUS_NO_INSTANCES를 반환했다. 프로젝트 열기를 다시 실행해 시작 창을 표시했으나 Connection Lost 대화 상자가 Unity Licensing Client 연결 끊김을 명시했다. Editor.log에는 연결 거부와 60.01초 시간 초과가 있고 라이선스 로그에는 기존 프로세스 때문에 global mutex를 얻지 못했다는 기록이 있다. 약관 미동의만을 확정 원인으로 간주하지 않는다.

Retry와 라이선스 보조 프로세스 재시작을 시도했다. 종료 명령은 오류를 반환했으므로 정상 재시작 완료로 기록하지 않는다. 시작 창은 표시됐지만 에디터 ready·에셋 가져오기·컴파일은 아직 확인되지 않았다. 약관 버튼을 직접 누르거나 동의 설정을 편집하지 않았다. 게임 코드·씬·실행본 변경 없음. 한영 기록과 문서 링크·체크 상태를 검사한다. 현재 차단은 라이선스 연결 복구 미확인이다.

## 2026-09-13 — Unity 시작 차단 복구 확인

사용자 재시도 요청으로 라이선스 중복 잠금과 연결 거부를 다시 확인했다. 응답하지 않던 Unity.Licensing.Client PID 18392를 지정 종료하고 새 보조 프로세스를 시작했다. 시작 단계에 멈춘 이 프로젝트의 Unity PID 45992·46472도 지정 종료한 뒤 프로젝트를 다시 열었다. 전체 Unity 프로세스 일괄 종료나 라이선스 파일 삭제는 하지 않았다.

Unity 6000.6.0f1 PID 44980이 ready로 연결됐으며 editor_status 명령에서 compiling=false, domainReloadInProgress=false를 확인했다. Windows 에디터 화면을 직접 확인하고 앞으로 표시했다. 현재 장면은 Untitled이며 플레이는 정지 상태다. 이번 실행에서 약관·Connection Lost 창은 나타나지 않았고 라이선스 권한 조회가 성공했다. 이전의 시작 차단은 현재 복구됨으로 갱신한다. 최초 약관 창 발생 원인과 재발 여부는 미확인이다.

게임 코드·씬·0.8.2 실행본 변경 없음. 에디터의 일반 에셋 갱신은 완료됐지만 PSX 6종의 개별 가져오기 품질·게임 플레이·빌드 검증은 수행하지 않았다. 약관 동의 설정을 직접 편집하지 않았다. 한영 문서와 링크·체크 상태 검사를 수행했다.
