기록은 로컬 `artifacts/`에 있으며 Git에는 포함하지 않는다. 파일이 없거나 다른 버전으로 덮였으면 해당 증거를 재확인한다. 자동 검사와 표본 검토는 장시간 사람 플레이를 대체하지 않는다. 시스템 인증서 읽기 경고가 있었으므로 모든 로그가 무경고였다고 주장하지 않는다.

## 변경별 검사

| 변경 | 필요한 검사 |
|---|---|
| 문서 | 한영 대응·상호 링크·경로·버전·숫자·상태 일치 |
| 규칙·수치 | 관련 행동 검사, 기존 규칙과 변경 의도 비교 |
| 물리·운반·애니메이션 | 재현 실패→수정 통과, 실제 연속 동작과 접촉 검토 |
| 맵 | 시작점·경계·충돌·카메라·경로·배송·쥐 및 실제 협동 동선 |
| 통신 | 관련 2인/4인 시나리오, 버전·맵 불일치, 중복·지연·이탈 |
| 배포 | 내보내기·포함 파일·해시·패키지 실행, 변경된 사용자 문서 포함 |

문서 검사: `python tools/check_docs.py`. 전체 자동 검사: `python tools/run_tests.py`. 배포: `python tools/build_windows.py` 또는 `BUILD.cmd`. 테스트 실패를 수치 완화로 숨기지 않는다. 검증 결과에 명령·빌드·날짜·성공/실패·한계를 남긴다.
