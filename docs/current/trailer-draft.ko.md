## 실제 제작

사용자가 기존 이미지 시안을 참고해 Higgsfield로 트레일러 초안을 요청했다. [채용 광고형 75초 원안](trailer-recruitment.ko.md)의 대사와 큰 흐름을 사용했다. 형식은 1280×720, 24fps, 75초이며 영어 임시 음성·한국어 화면 자막·한영 SRT를 포함한다.

Higgsfield Kling 3.0으로 배송 이동과 외곽 생물 접근을 각각 6초 생성했다. 나머지는 기존 시안 10개 장면의 크롭·카메라 이동, 광고 카드·암전이다. Higgsfield의 Higgsedit에서 컷과 타이틀을 편집하고 FFmpeg로 음성·자막을 합쳤다. 임시 음성은 Microsoft Zira이고 음악·저음·확인음은 직접 합성했다. 생성 영상 환경음도 혼합했다. Seedance는 현재 플랜에서 거절되어 생성하지 않았다.

원안의 지구 일상 기록 필름은 기존 외부 시안과 회사 카드로 대체했다. 협동 유인·구조를 실제 연속 동작으로 촬영하지 않았다. 화면 전체에 콘셉트 영상·실제 게임 아님 표시를 유지한다. 우주선과 단말기의 구형 시안은 최신 모델의 구현 증거가 아니다. 게임 코드·장면·모델 변경은 없다.

## 검증과 남은 일

- [x] 생성 영상 2개 완료·로컬 저장, 각 1초 간격 프레임의 직원·생물 움직임 검토.
- [x] 75초, 1280×720, 24fps, 1800프레임 및 스테레오 음성 트랙 확인.
- [x] 전체 파일 디코딩·음량 검사. 최대 -4.5dB, 평균 -24.9dB; 전체 청취를 대신하지 않는다.
- [x] 정지 시안 축소 배치 오류를 검출하고 화면 채우기 방식으로 재출력.
- [ ] 사람이 처음부터 끝까지 재생·청취하며 분위기와 전달력을 평가.
- [ ] 생성된 화물·직원 동작 연속성 수정, 실제 협동 플레이 촬영으로 교체.
- [ ] 최종 성우·음악·상점 공개용 권리와 게임 표현 검토.

검증 원본은 제작 폴더 validation.json, contact-sheet.jpg 및 재현 스크립트다. SRT 8개 구간의 한영 타이밍을 맞췄고, 설명서·출처·변경 이력도 함께 관리한다. 이 초안은 Steam 공개용 최종 트레일러가 아니다.

원본·스크립트를 포함한 전체 편집 프로젝트 ZIP의 외부 업로드는 자동 승인 검토가 거절했다. 그 업로드는 수행하지 않고 제작 소스는 로컬에 보관했다. 허용된 결과 영상만 클라우드에서 내보냈다.
