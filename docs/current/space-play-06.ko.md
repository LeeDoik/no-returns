# SPACE-PLAY-06 — 현장 단서와 공용 기록

[English](space-play-06.en.md)

2026-09-13 · 0.7.0 구현과 검증용 제안. 미스터리 정체·결말은 확정하지 않는다.

## 플레이와 규칙

- 리스너 모드의 입구 동쪽 관리 단말과 수령소 서쪽 기록기에 단서 2개를 둔다. 폐쇄된 시설의 최근 사용 흔적, 도착보다 앞선 수령 기록으로 질문을 만든다. 임시 소품이며 최종 아트 승인을 대신하지 않는다.
- I로 바라보는 소품을 2.4m 이내에서 조사한다. 실제 조준선의 첫 충돌을 확인하므로 거리 밖·벽 뒤·반대 방향·다운 상태에서는 조사하지 못한다. 배송 전에는 두 번째 기록이 잠겨 있다.
- 배송 완료 시 수령 기록기의 표시등이 바뀌고 종이가 나온다. 한 직원의 발견은 방장이 확정해 동료에게 공유한다. 중복 조사는 보수를 추가하거나 상태를 누적하지 않는다. 단서는 배송의 필수 조건이 아니다.
- Tab으로 공용 현장 기록을 열고 Tab·Esc 또는 닫기 버튼으로 돌아간다. 기록을 읽는 직원의 이동·운반 조작은 멈추지만 온라인 세계·크리처는 계속 움직인다. 현장에서는 짧게 조사하고 우주선에서 읽도록 안내한다.
- 기록은 현재 근무 단위다. 정산·다음 근무 준비 중에는 유지되며 다음 도착 때 초기화한다. 실행 종료 후 단서 기록을 복원하는 영구 도감은 이번 범위 밖이다. 기존 잔액·사용권·배송 해금 저장은 유지한다.
- 모든 문구는 영어 원문과 한국어 대응을 제공한다. 이번 창·소품은 읽힘 검증용이며 억제장치·제한시간·새 전체 맵은 추가하지 않는다.

## 통과 조건

실제 두 프로세스에서 원격·반대 방향·배송 전 거절, 참가자 조사와 방장 기록 일치, 배송 후 기록기 변화와 두 번째 발견, 중복 보수 없음, 기록창의 로컬 입력 차단과 세계 진행, 언어 독립 전환, 귀환 후 열람과 다음 도착 초기화를 검사한다. 자동 상태 검사는 호기심·공포·문구 이해의 사람 평가와 구분한다.

## 위치와 제작 근거

첫 단말 중심은 (7.7, 1.35, 0), 두 번째 기록기는 (-7.8, 1.35, 10.6)이다. 착륙 후 입구 오른쪽 통로에서 첫 단말을 찾고, 배송한 뒤 금색 수령대 뒤쪽 서벽 옆 기록기를 조사한다. 금색 수령대와 기존 운반 경로는 유지한다.

[CarryClues](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryClues.cs)는 임시 소품·조준선·배송 조건·단서 비트를, [CarryRoom](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryRoom.cs)은 입력·기록창·동기화를, [CarryLanguage](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryLanguage.cs)는 한영 문구를 담당한다. 통신 규약은 5이며 두 플레이어 모두 [0.7.0 빌드](../../NoReturns/Assets/_NoReturns/Editor/CarryBuild.cs)를 사용한다. 저장 파일 형식은 기존 1을 유지하며 단서 비트를 저장하지 않는다.

## 현재 검증

- [Unity 물리·규칙 검사](../../artifacts/space-play-06/rules-result.json) 11개 통과: 거리·반대 방향·벽 가림·조사 단계·배송 전 잠금·중복·초기화. 실제 조준선이 기록기를 맞힌 상태에서 배송 전 거절도 별도로 확인했다.
- [실제 두 프로세스 검사](../../artifacts/space-play-06/latest.json) 23개 통과: 참가자 발견 공유, 기록창 입력 차단과 세계 진행, 언어 독립 표시, 배송 후 발견, 보수 420 CR 유지, 귀환 열람과 다음 도착 초기화. 캡처 파일 생성 검사는 픽셀 검증과 구분한다.
- 숨긴 창의 전체 캡처는 검게 나왔다. 별도의 표시된 창에서 [한국어 기록창 실제 화면](../../artifacts/space-play-06-ui/run-20260913-020950/host/screen.png)을 얻고 제목·본문·줄바꿈·닫기·언어 버튼을 시각 확인했다. 첫 단서 발견 상태이며 모든 해상도·두 단서 전체 배치의 승인은 아니다.
- 첫 실행 검사는 기록창 닫기 요청이 다음 이동 요청에 덮여 실패했다. 게임 조작 코드를 완화하지 않고 검사 도구가 닫힌 상태를 확인하도록 수정했다. 실패 기록을 보존했다.
- 사람의 호기심·공포·문구 이해, 현장에서 읽다가 위험을 느끼는지, 최종 아트 품질은 미검증이다. 억제장치·시간 압박은 여전히 후속 구현이다.

실행은 [리스너 실험](../../06_Play_Listener_Test.cmd)과 [동일 PC 참가](../../07_Join_Local_Listener.cmd)를 사용한다. 검사 도구는 [test_clues_build.py](../../tools/test_clues_build.py)와 [check_clue_rules.py](../../tools/check_clue_rules.py)다.
