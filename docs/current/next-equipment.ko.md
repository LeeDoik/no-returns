0.8.13 · 내장 디스플레이 모델 적용.

- 기본 지급, 빈손에서 자동으로 들며 왼쪽 마우스 클릭으로 사용한다. 화물·신호기 운반, 다운·구조 중 외형을 숨긴다. E/Q는 유지한다.
- 횟수 제한 없음, 쿨타임 6초. 리스너 저지 거리 2.5m·각도 65도·지속 3초. 이미 저지 중인 시간을 연장하지 않고 회복 후 2초간 재저지에 저항한다. 저항 2초는 플레이 검증값이다. 외곽 생물은 면역이다.
- 승인 시안으로 Tripo 비공개 모델을 새로 생성했다. 65+20=85크레딧, 잔액 975→890. 원본과 이전 모델은 보존한다.
- 화면 유리 영역 357개 면을 제거하고 모델 안에 별도 BatonScreen 메시·UV를 구성했다. 0.68m 길이, 몸체 512 텍스처. 기존 외부 화면 부품은 제거했다.
- 매립 화면 재질에 48×96 텍스처 13장을 교체한다. 주황색 막대가 차오르고 준비 완료는 초록색 체크다. 방장의 남은 쿨타임으로 표시한다.
- 전극 사이 전기선은 항상 18Hz로 모양·굵기를 변조한다. 사용 직후 0.18초간 굵어진다. 장비가 숨겨지면 함께 숨긴다. 전기는 장식이며 충전 완료는 화면으로 판단한다.

## 제작·검증

Windows 빌드 성공. Blender 앞면 및 FBX 재가져오기에서 몸체/화면 메시 2개와 UV를 확인했다. 실제 실행의 준비·중간 충전 화면에서 외부 부품 없이 매립 화면만 바뀌는 것을 확인했다. 두 프로세스 표시·충전 11개 검사 통과. 저지 연장 방지·회복 저항·저항 만료 3개 Unity 로직 검사 통과. 실제 마우스 하드웨어·사람의 타격감·4인·전체 성능 검증은 남아 있다.

## 디스플레이 구현 선택지

현재는 미리 만든 텍스처를 교체한다. 셰이더로 충전량을 직접 그리거나, UI를 RenderTexture에 그려 모델 재질에 입히거나, World Space Canvas를 사용할 수도 있다. 질문에 대한 설명이며 방식 변경은 하지 않았다. 작은 충전계는 셰이더가 적합한 후보이고 복잡한 터미널은 UI/RenderTexture를 검토한다.
