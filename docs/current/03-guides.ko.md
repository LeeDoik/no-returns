## 프로젝트 사용

[01_Open_Project.cmd](../../01_Open_Project.cmd)로 새 Unity 프로젝트를 연다. 프로젝트는 `NoReturns/`이며 코드·씬·에셋은 `Assets/_NoReturns/` 아래에 둔다. 장면·프리팹·머티리얼은 Unity 편집기 또는 공식 MCP를 통해 수정한다. 현재 Bootstrap은 빈 출발점이다.

`powershell -NoProfile -File tools/unity.ps1 check`는 기반 설정을 검사한다. `setup`은 초기 기반을 구성하는 명령이며 사용자 제작 장면을 대신하는 게임 생성 명령이 아니다. `python tools/unity_mcp.py editor_status`로 연결을 확인한다. MCP는 게임 멀티플레이 서버가 아니다.

기존 루트 Git 저장소를 유지한다. `.meta`를 에셋과 함께 관리하고 Library·Temp·Logs·UserSettings·빌드는 제외한다. 원격 저장소를 생성하거나 푸시하지 않았다. Unity 버전이나 렌더 파이프라인 변경은 별도 결정으로 기록한다.

## PSX 아트 파이프라인

방향 기준은 낡은 우주 배송 산업과 정체를 알 수 없는 현장이다. 모든 에셋은 공통 팔레트, 텍스처 밀도, 모서리·실루엣, 조명과 UI 가독성을 함께 확인한다. 과거 장난감풍 리소스는 사용하지 않는다.

진행 순서: 한 장의 대표 장면과 직원·화물·시설 콘셉트 → 사용자 이미지 승인 → 모델·텍스처 제작 → 스케일·충돌·애니메이션·라이선스 검사 → Unity 장면에서 함께 검토.

낮은 해상도의 월드 표현과 읽기 쉬운 UI를 분리한다. 텍스처 필터링, 내부 렌더 해상도, 팔레트, 디더링·흔들림의 강도는 시각 비교로 정하며 지금 숫자를 최종 규격으로 고정하지 않는다. 안개가 배송 표식이나 생물의 위험 신호를 가려서는 안 된다. PSX 효과용 셰이더와 모델은 아직 제작하지 않았다.

## SPACE-ART-02 — 화풍 참고 변경

사용자 요청에 따라 [Mouthwashing 공식 Steam 페이지](https://store.steampowered.com/app/2475490/Mouthwashing/)를 화풍 참고로 지정했다. [콘셉트 02](../art/space-concepts/concept-02.png)는 기존 배송·우주선·크리쳐와 장면 구성을 유지하고 누런 패널, 보랏빛 안개, 붉은 그림자와 형광등 조명으로 수정한 검토용 생성 이미지다. 내장 이미지 편집 도구에 기존 보드를 입력했다. 편집 지시의 핵심은 같은 구도와 화물 운반을 유지하면서 저폴리곤 형태·저해상도 표면·평평한 조명으로 바꾸는 것이다. 생성 결과에는 촘촘한 표면 노이즈가 일부 남아 있으며 최종 텍스처 밀도는 미정이다. 참고 작품의 캐릭터·서사는 도입하지 않았다. 화풍 참고 선택은 확정됐으나 이 이미지의 모델 제작 승인은 아직 없다.

## SPACE-ART-03 — 대응 장비 시각 제안

사용자는 콘셉트 02에 긍정적인 의견을 주고 전투 장비 이미지를 요청했다. 이를 전체 아트나 모델 제작 승인으로 확대하지 않는다. [장비 보드](../art/space-concepts/equipment-01.png)는 같은 화풍의 미승인 제안이다. 산업용 충격봉(Shock Baton)은 근거리 저지, 압축가스 발사기(Pressure Caster)는 거리 확보, 유인 신호기(Decoy Beacon)는 동료 배송을 위한 주의 분산을 표현한다. 실제 효과·피해량·자원·오발·아군 영향은 미정이며 전투 비중도 확정하지 않았다.

내장 이미지 생성 도구에 콘셉트 02를 화풍 참고로 제공했다. 핵심 지시는 누런 산업용 외장·적갈색 손잡이·저폴리곤 표현을 공유하는 서로 다른 장비와 협동 사용 장면을 제작하는 것이다. 이미지에서 장비 실루엣·색·사용 예시를 확인했다. 기능 검증이나 모델 제작은 하지 않았다.

## SPACE-ART-04 — 연속 플레이 화면 목업

[탐색](../art/space-concepts/gameplay-01.png) → [크리쳐 조우](../art/space-concepts/gameplay-02.png) → [배송 완료](../art/space-concepts/gameplay-03.png). 같은 장소·카메라·HUD 배치를 유지한 생성 이미지이며 실제 게임 캡처가 아니다. 콘셉트 02를 참고해 내장 이미지 도구로 첫 화면을 생성하고 후속 화면을 순차 편집했다. 핵심 지시는 같은 공간에서 운반, 동료 배송 중 크리쳐 저지, 수령 확인 후 귀환을 보여주는 것이다.

SUIT·STAMINA, E·LMB·TAB 조작 안내, 인원 표시, 수령소 번호, 운반 화물 수와 전투 효과는 시각 제안이며 확정된 규칙이나 구현이 아니다. 구성·배송 목표 변경·식별색을 시각 확인했다. 생성 편집의 한계로 마지막 장에도 먼 생물 실루엣이 남고 일부 배경 화물 배치가 달라졌다. 프레임 단위로 정확한 상태 일치를 검증한 자료가 아니다. 외형 승인·실제 HUD 가독성·조작감·온라인 검증은 미완료다.

## SPACE-ART-05 — 직원 시트

[직원 시트](../art/space-concepts/employee-01.png)는 정면·측면·후면, 주황·청록·겨자·보라 식별색, 운반·장비 지지·운반 보행 자세를 포함한 미승인 이미지다. 기존 플레이 목업을 내장 이미지 도구의 외형 참고로 사용했다. 지시는 같은 직원의 형태를 여러 방향에서 정리하고 넓은 색면·저해상도 표면을 유지하며 손과 화물의 관계를 보여주는 것이다. 등은 작업복과 평면 표식으로 표현하며 돌출 판자나 배낭을 추가하지 않는다.

시트의 방향별 형태·식별색·사용 자세를 시각 확인했다. 장비 자세의 발사기 형태는 기존 장비 보드와 차이가 있어 확정 장비 기준으로 사용하지 않는다. 생성 이미지의 방향별 비율·봉제선 정합성은 모델 제작 전 추가 검토 대상이며 리깅·애니메이션·관통 방지는 아직 검증하지 않았다. 직원 외형 승인 전 모델을 제작하지 않는다.

## SPACE-ART-06 — LED 표정 시트

[표정 시트](../art/space-concepts/expressions-02.png)는 같은 직원 헬멧의 검은 바이저에 호박색 사각 도트로 무표정·웃음·놀람·짜증·가운데손가락(FLIP OFF)·오류를 표현한 미승인 제안이다. 직원 시트를 외형 참고로 내장 이미지 도구에 제공했다. 핵심 지시는 헬멧·조명·구도를 유지하고 바이저 표정만 바꾸는 것이다. 팀 식별은 작업복 색으로 유지한다.

이미지에서 표정 구분, 공통 헬멧 형태와 발광색을 확인했다. 픽셀 격자·밝기·실제 거리에서의 가독성은 확정하거나 검증하지 않았다. 수동 선택과 짧은 자동 반응의 병행, 수동 선택 우선은 설계 제안이며 발동·지속·우선순위·온라인 동기화 규칙은 미정이다. 코드·모델·애니메이션 변경 없이 시각화만 했다. 이미지 승인 전 모델 제작하지 않는다.

사용자 요청으로 HELP를 가운데손가락 도트 이모티콘으로 교체했다. 이전 시트는 이력으로 보존했다. 내장 이미지 편집에서 하단 중앙 바이저와 이름 변경을 지시했고 다른 표정의 의미와 배치를 시각 확인했다. 생성 편집 결과의 재질은 원본과 완전히 동일한 픽셀은 아니다.


## SPACE-ART-07 — 첫 크리쳐 행동 시트

[행동 시트](../art/space-concepts/creature-01-behavior.png)는 기존 조우 목업의 긴 팔다리 생물을 참고한 미승인 시각 제안이다. 임시 이름은 THE LISTENER이며 소리에 반응하는 창고 배회자로 제안한다. 배회 → 소리 감지 → 접근 → 공격 예고 → 팔 휘두르기 → 밀려남·재탐색의 자세를 비교한다. 최종 상태 전이도나 애니메이션 명세는 아니다.

배회 중에는 고개와 팔을 늘어뜨리고, 소리 감지 시 멈춰 고개를 돌린다. 접근 시 상체를 숙이고, 공격 직전에는 한쪽 팔을 뒤로 크게 당긴다. 넓게 휘두른 뒤에는 동작을 마무리하며 압축가스에 맞으면 균형을 잃고 재탐색하는 후보 반응을 표현한다. 조용한 이동·소리 유인·밀어내기는 대응 후보이며 감지 거리, 공격 시간·범위·피해, 회복 조건, 솔로 해법과 온라인 판정은 미정이다.

내장 이미지 도구에 gameplay-02를 외형 참고로 주고 같은 생물의 구별되는 전신 자세와 대응 단서를 요청했다. 자세 구분·팔 예고·유인 및 밀려남을 시각 확인했다. 이미지가 덧붙인 1.8 m·2.4 m와 하단 영문 슬로건은 생성 도구의 임의 제안이며 승인된 규격·상점 문구가 아니다. 유인기 외형도 기존 장비 시트를 대체하지 않는다. 외형·동작 승인, 리깅과 실제 플레이 가독성은 미검증이며 코드·모델을 제작하지 않았다.

## SPACE-ART-08 — 우주선 내부 구조 제안

[내부 구조 시트](../art/space-concepts/ship-interior-01.png)는 단층 평면 배치와 양방향 내부 투시를 함께 보여주는 미승인 제안이다. 앞쪽 항로·계약 단말기, 중앙 왼쪽 장비 랙과 오른쪽 접이식 좌석, 뒤쪽 양측 화물 구역, 중앙 통로와 후방 램프로 구성한다. 좌우는 배의 앞을 바라보는 기준이다. 항로 선택 후 자동 이동·착륙 원칙을 유지한다.

같은 배 안에서 4명이 준비할 수 있도록 장비와 화물을 벽 쪽에 배치하고, 중앙은 상자를 든 직원들이 지나갈 공간으로 비우는 방향이다. 통로 폭·화물 용량·좌석 수는 최종 규격이 아니다. 그림의 화살표는 이동 안내이며 일방통행 규칙이 아니다.

내장 이미지 도구에 콘셉트 02를 화풍 참고로 주고 하나의 공간을 평면·정방향·역방향으로 표현하도록 요청했다. 주요 기능 구역과 통로, 반대 시점에서 좌우가 바뀌는 구성을 시각 확인했다. 일부 소품 배치와 좌석 표현은 시점 간 차이가 있어 정확한 제작 도면이 아니다. 이미지가 추가한 회사 슬로건은 승인된 게임 문구가 아니다. 실제 치수·충돌·카메라·4인 통행·적재 검증은 미완료이며 코드·맵·모델 변경 없음.

## SPACE-ART-09 — 항로 터미널 UI 제안

[항로 터미널 이미지](../art/space-concepts/route-terminal-02.png)는 목적지 목록·항로 지도·배송 조건을 좌우로 비교하는 미승인 화면 목업이다. 어두운 바탕의 저해상도 비트맵 UI에 선택 항로와 주의를 호박색으로 표시했다. 왼쪽 목록의 CINDER DEPOT, 지도 선택점, 오른쪽 상세 이름이 일치하는지 시각 확인했다. 화물·취급 조건·수령 방식·보수·알려진 위험·미확인 보고를 제시한다. CONFIRM ROUTE는 항로 선택 확인 제안이며 즉시 출발이나 전원 준비 규칙을 확정하지 않는다. 자동 이동·착륙은 기존 확정 방향이다.

내장 이미지 도구에 우주선 내부 시트를 참고로 주고 화면 중심의 세 열 UI, 높은 글자 가독성, 같은 목적지 선택 상태를 요청했다. RELAY 04·CINDER DEPOT·DEEP ARRAY, 240 CR, 경로·잠금 조건·취급 조건·벽면 슬로건은 검토용이며 승인된 콘텐츠·경제·문구가 아니다. 실제 조작·한글 표시·다른 해상도·게임 내 거리·협동 선택 동기화는 미검증이다. 코드·UI 장면·모델 변경 없음.

사용자의 너무 깔끔하다는 의견에 따라 터미널을 굵은 비트맵 글꼴, 사각 노드, 계단진 항로, 디더링과 평면 선택 막대로 수정했다. 기존 목적지·보수·자동 이동 정보는 유지했다. 내장 이미지 편집으로 제작했으며 원본은 비교용으로 보존했다. ESC·ENTER 안내는 미승인 조작 제안이다. 이미지에서 시각적 변경과 정보 유지를 확인했으며 실제 렌더 해상도나 폰트 규격을 확정한 것은 아니다.

## SPACE-ART-10 — CINDER DEPOT 첫 배송지 구조

[동선·투시 시트](../art/space-concepts/cinder-depot-layout-01.png)는 사용자 요청에 따른 임시 첫 배송지의 미승인 공간 제안이다. 남서쪽 착륙·귀환 지점과 북동쪽 BAY 04 수령소를 건물 모서리와 화물 더미로 분리한다. 청록 실선은 서쪽 창고 외곽과 북쪽 통로를 도는 긴 우회로, 노란 점선은 중앙 Listener 구역을 거치는 위험한 지름길이다. 북쪽 사무실은 선택적으로 최근 사용 흔적을 발견하는 가지 공간이다.

오른쪽 A는 소리 유인으로 화물 운반을 돕는 상황, B는 무인 수령 단말기, C는 의자·머그잔·출력된 영수증이 남은 사무실이다. 단서는 최근 사용을 암시하는 제안이며 서사 정답은 확정하지 않는다. 두 경로 모두 왕복을 의도하며 그림의 화살표는 일방통행 규칙이 아니다.

내장 이미지 도구에 gameplay-01을 화풍 참고로 주고 착륙·두 경로·수령·단서와 주요 장소 투시를 요청했다. 주요 위치와 경로 구분, A/B/C 대응을 시각 확인했다. 생성 지도에는 우회로 계단, 문턱과 일부 불명확한 연결이 남아 있어 실제 운반 가능성이나 지름길 시간 이점을 검증한 도면이 아니다. 안전한 우회로는 도구·점프 없이 운반 가능한 경사로와 충분한 출입 폭으로 회색 도형 검증해야 한다. 치수·속도·크리쳐 감지 범위·유인기 외형은 확정하지 않는다. 코드·맵·모델 변경 없음.

## SPACE-ART-11 — 억제장치 통합 시각화

[통합 시트](../art/space-concepts/cinder-depot-suppression-01.png)는 두 배송 경로·착륙·수령·선택 사무실, 억제장치 범위, 외곽 위험 생물, 가동 전후와 간접 상태 변화를 함께 표현한다. 내장 이미지 도구에 기존 배송지 지도를 참고로 주고 같은 공간에 보호 범위·외곽 진입·숫자 없는 단계 신호를 결합하도록 요청했다.

정확한 카운트다운 대신 표시등·소리 패턴·생물 접근으로 가동 상태를 보여준다. STABLE·UNSTABLE·CRITICAL·OFFLINE은 상태 표시 후보이며 HUD 상시 표시는 확정하지 않는다. 지도 경계·경로·진입 화살표와 음파 아이콘은 설명용이다. 배송 후에도 장치 소모가 지속되는 안이며 수령소는 정지 후에도 작동한다. 외곽 생물의 외형과 장치 수는 미승인이다.

시각 검토에서 주요 구역과 상태 비교를 확인했다. 생성된 진입 화살표 일부는 밖을 향하고 FIELD LOST의 직원도 완전한 후퇴 자세는 아니므로 최종 동선·행동 도면으로 사용하지 않는다. 장치 정지 후 외곽에서 안으로 진입하고 경고 후 탈출 기회가 있는 것이 의도다. 코드·맵·모델 변경 없음. 소리·가독성·운반·온라인·생존 가능성은 실제 검증하지 않았다.

## SPACE-ART-12 — 외곽 생물 코즈믹 호러 후보

사용자가 외곽 생물 시안에 이어 코즈믹 호러 방향을 요청했다. [초기 동물형 비교](../art/space-concepts/outer-threats-01.png)를 보존하고 [최신 비교 시트](../art/space-concepts/outer-threats-03.png)로 형태를 재탐색했다. A THE ABSENCE는 몸 중심의 빈 어둠, B THE INVERSION은 뒤집혀 접힌 몸, C THE INTERVAL은 분리된 듯한 몸의 간격을 중심으로 한다. 세 종 확정이 아닌 하나의 외곽 위협을 위한 대안이다. 이름·크기·재질·행동과 모델 제작은 미승인이다.

내장 이미지 도구에 억제장치 시트를 참고해 첫 후보를 만들고, 그 결과를 편집해 동물형에서 비정상적인 빈 공간·접힘·분절로 바꾸도록 요청했다. 세 실루엣과 같은 환경의 원거리 모습을 시각 확인했다. 결과에 암석 같은 표면과 C의 가는 연결부가 남아 있어 공포 효과나 물리적으로 불가능한 형태를 검증한 것은 아니다. 실제 동작·부분 노출·소리·시야와 결합해 평가해야 한다. 코드·모델 변경 없음.

사용자의 더 기괴한 형태 요청으로 최신 시트를 다시 편집했다. 암석형 표면을 줄이고 창백하게 접힌 외피, A의 내부에 매달린 작은 몸, B의 뒤틀린 지지 다리, C의 빈 몸통과 연결 조직을 표현했다. 내장 이미지 편집으로 제작하고 이전 시트를 보존했다. 형태 변경을 시각 확인했으나 실제 공포 반응은 미검증이다. 이후 사용자가 A를 선택했다. 단순화한 외형과 모델 제작은 후속 검토 대상으로 남는다.

사용자가 지정한 초기 비교 시트의 갈색 A THE STRIDER가 현행 선택이다. 하얀 THE ABSENCE와 관련 제작안은 폐기됐다. [새 제작 시트·가이드](../art/space-concepts/strider-production.ko.md)에 사족형 다방향 모습, 리깅 개념, 접지와 동작 제안을 정리했다. 실제 모델·리그는 아직 없다.

## SPACE-ART-15 — 화물·수령 장치·단서

[통합 소품 시트](../art/space-concepts/cargo-receipt-clues-01.png)는 밀봉 화물, 수령 선반·단말기, 최근 사용 흔적과 영수증 단서를 연결한 미승인 제안이다. 내장 이미지 도구에 기존 수령소 화면을 참고로 주고 동일한 상자 표식·장치·기록과 내려놓기 → 확인 → 영수증 수령 흐름을 요청했다.

화물에는 운반 손잡이·봉인·방향 표식·목적지 라벨을 둔다. 단말기는 PLACE PARCEL에서 ACCEPTED로 바뀌며 종이 영수증을 출력하는 안이다. 물리적으로 종이를 집는 행위는 배송 성공의 필수 조건으로 확정하지 않는다. 미스터리는 빈 사무실의 따뜻한 머그잔, 새 영수증의 수령인 공란, 과거 전표와 같은 화물 코드 NR-041이다. 예시 코드·내용·단서는 검토용이며 시간 순환이나 회사 음모를 확정하지 않는다. 단서를 놓쳐도 배송할 수 있는 방향을 유지한다.

시각적으로 코드 반복, 선반과 단말기 상태, 손잡이와 봉인을 확인했다. 작은 라벨 일부와 세부 배치는 생성 이미지 간 일관성이 완전하지 않다. 실제 상호작용·운반·온라인 일치·단서 가독성·재미는 미검증이며 코드·모델 변경 없음.

## SPACE-ART-16 — 장비 상점·귀환 정산

[장비 구매·개조 화면](../art/space-concepts/equipment-shop-01.png)과 [귀환 정산 화면](../art/space-concepts/shift-report-01.png)을 기존 PSX 항로 단말기 스타일로 제작했다. 거친 픽셀 글꼴, 제한된 색, CRT 표면을 유지하고 영문 게임 문구를 사용했다. 기존 잔액 180 + 이번 보수 360 = 540 CR, 발사기 구매 후 240 CR로 두 화면을 연결했다. 개조는 라이선스 구매 뒤 열리는 별도 거래다.

[보수·실패·장비 경제 초안](economy.ko.md)가 금액과 손실 규칙의 제안 근거다. 내장 이미지 생성 도구로 제작해 금액과 선택 상태를 시각 확인했다. 이미지 외형은 사용자 승인 전이며 실제 UI 가독성·입력·컨트롤러·접근성은 미검증이다. 모델·게임 코드 변경 없음. 이미지 승인 없이 모델 제작으로 진행하지 않는다.

## SPACE-ART-17 — 실제 플레이 화면·HUD 시안

[운반·조우 비교 시안](../art/space-concepts/gameplay-hud-01.png)을 제작했다. 왼쪽은 화물 운반, 오른쪽은 THE LISTENER를 보고 멈춘 상태다. 직원·기존 플레이 장면·LISTENER·화물 시트를 참고해 내장 이미지 생성 도구로 만들었다. 실제 Unity 캡처가 아니다.

생성 지시: 동일한 주황 직원과 밀봉 화물, 3인칭 어깨 뒤 카메라, 굴곡진 CINDER DEPOT 서비스 통로, 청록 동료 식별, PSX 저해상도 재질과 픽셀 글자, 동일 배치의 최소 HUD를 두 화면에 유지한다. 목표·동료·SUIT·내려놓기·보관 중 발사기 잔량만 표시하고 정확한 타이머·미니맵·적 체력바는 제외한다. 오른쪽은 엄폐물 너머 LISTENER를 관찰한다.

화물은 양손 운반을 의도하고 무기는 보관 상태인 STOWED로 표시한다. SUIT 막대, 잔량 블록, 입력 E와 동료 이름 MOSS는 UI 제안이며 실제 체력·사용 횟수·키 배정 확정이 아니다. 시각 검토에서 두 장면의 카메라 방향·주요 문구·동료 색상·생물 실루엣을 확인했다. 오른쪽 엄폐물과 화물의 여유, 가려진 손의 접촉, 실제 화면 크기에서 작은 글자 판독은 게임에서 검증해야 한다. 정지 이미지로 관통·조작감·은신 판정·긴장감을 검증하지 않았다.

사용자 외형 승인 대기. 모델·게임 코드 변경 없음. 억제장치 단계 비교·구조·장비 효과·연속 배송 시트는 아직 작업 대기다.

## SPACE-ART-18 — 1인칭 상황 비교

[1인칭 시트](../art/space-concepts/gameplay-first-person-01.png)를 내장 이미지 생성 도구로 제작했다. 위 SPACE-ART-17의 3인칭 카메라는 교체된 과거안이다.

생성 지시: 기존 직원·장비·화물·플레이 HUD 이미지를 외형 참고로 사용하되 카메라를 직원 눈높이로 바꾼다. PSX 재질과 CINDER DEPOT 통로를 유지하며 빈손 탐색, 양손 화물 운반, 충격봉 준비, 압축가스 밀치기의 4개 장면을 구성한다. 자신의 머리·등은 보이지 않고 장갑과 소매만 필요할 때 보인다. 화물과 무기를 동시에 들지 않으며 숫자 타이머·적 체력바를 제외한다.

화물은 화면 하단에 두어 전방을 보게 하고 양옆 손잡이를 잡는 안이다. 장비 준비·사용은 오른쪽 아래에서 보이고, 동료의 전신·팀 색·LED는 유지한다. 억제장치 간접 징후는 유지하며 무기 효과는 일반 LISTENER를 밀치는 표현이다. 외곽 생물 처치 가능성을 뜻하지 않는다. FOV 조절·약한 머리 흔들림·카메라와 물리 흔들림 분리는 구현 검토 제안이며 수치는 미정이다.

시각 확인: 네 장면 모두 1인칭이며 화물과 무기를 분리했고 주요 UI 문구와 장비 형태가 읽힌다. 탐색 장면의 OPEN은 중앙 점과 떨어진 문에 표시되어 상호작용 거리·초점의 확정 예시로 사용하지 않는다. 압축가스 장면 동료 화물은 가려져 운반 성공 증거가 아니다. 실제 발밑 시야, 손잡이 접촉, 벽 관통, 가스 효과 범위, 화면 크기별 글자와 멀미는 미검증이다. 입력 E·LMB, SUIT·잔량 블록은 제안이며 실제 수치·키 확정이 아니다. 이미지 승인 대기, 모델·게임 코드 변경 없음.

## SPACE-ART-19 — 동일 장소 억제장치 단계 비교

[4단계 시트](../art/space-concepts/suppression-stages-01.png)는 같은 눈높이 1인칭 구도에서 정상·불안정·붕괴 임박·정지를 비교한다. 내장 이미지 생성 도구에 기존 1인칭 시안, STRIDER 제작 시트, 억제장치 통합 시트를 참고로 제공했다. 생성 지시는 구조·카메라를 유지하고 표시등·설비 조명·외곽 생물 접근으로 단계 차이를 표현하며 숫자 타이머를 제외하는 것이다.

| 단계 | 시각 신호 제안 | 소리 제안 |
|---|---|---|
| 정상 | 표시등 모두 켜짐, 작업등 유지, 외곽의 먼 실루엣 | 일정한 작동음 |
| 불안정 | 일부 표시등 소등, 배기·연기, 외곽 접근 | 끊기는 작동 리듬 |
| 붕괴 임박 | 적색 표시등만 유지, 비상 조명·스파크, 경계 앞 생물 | 힘겨운 반복 작동음 |
| 정지 | 장치 표시등 소등, STRIDER 내부 진입, 비상등 유지 | 장치음이 멎고 발소리가 들림 |

단계 제목과 AUDIO 문구는 설명용 주석이며 상시 HUD·실제 음원·구현된 자막이 아니다. 수령 단말기 READY와 SHIP 방향 통로는 정지 후에도 유지한다. 단계 길이·정확한 경계·추적 속도는 확정하지 않았다. 외곽 위협을 죽이는 장면이나 무경고 즉사를 추가하지 않았다.

주요 구조·표시등 수·비상 조명·진입 방향을 시각 확인했다. 생성 결과는 뒤 능선 실루엣을 남긴 채 앞쪽 생물을 추가하므로 한 개체의 연속 이동을 정확히 표현하지 못한다. 생물 수를 확정한 시트가 아니다. 정상 단계의 가운데 표시등은 황색이므로 모든 표시등이 녹색이어야 한다는 색상 규격으로 사용하지 않는다. 미세한 원근·소품 차이는 실제 동일 카메라 렌더 검증이 아니다. 단계 판독·색각 접근성·소리·탈출 가능성·공포는 플레이 검증 대기다. 이미지 승인 대기, 게임 코드·모델·오디오 변경 없음.

## SPACE-ART-20 — 다운·구조·긴급 귀환

[구조 시트](../art/space-concepts/rescue-extraction-01.png)는 발견 → 화물 내려놓기 → 부축 이동 → 선내 귀환 확인을 1인칭으로 연결한다. 내장 이미지 생성 도구에 기존 1인칭 화면·직원·우주선 내부를 참고로 제공했다. 생성 지시는 주황 구조자, 청록 다운 직원 MOSS, 노랑 경계 직원 ROOK의 역할을 유지하고 PSX 화풍으로 손의 점유와 구조 순서를 보여주는 것이다.

이번 시안은 3인 상황이며 최소 인원 규칙이 아니다. 부축은 구조 방법 후보로, 다운 직원이 스스로 조작 가능한 상태로 회복됐다는 뜻이 아니다. 구조자는 화물을 먼저 내려놓고 장비를 사용하지 않은 채 동료를 지원한다. 다른 직원은 경로를 확보한다. 선내에 생존 상태로 들어온 동료는 기존 경제 초안의 귀환 인원에 포함하는 방향이며 자동 출발이나 즉시 완치로 표현하지 않는다. 놓고 온 미배송 화물은 자동 회수·배송되지 않는다. 미배송 귀환에는 배송 보수가 없다는 경제 초안을 유지한다.

DOWNED·ASSIST·SUPPORTING MOSS·LOWER·CONFIRM RETURN, 입력 E와 상태 막대는 검토용 UI다. 실제 구조 시간·속도·중단·사망 전이·선내 회복 조건은 미정이다. 얼굴 LED의 켜진 눈은 생존 표현 후보이며 새 확정 표정 규격은 아니다.

시각 확인에서 청록 직원의 연속성, 화물 내려놓기, 빈손 지원, 선내 인원 확인을 확인했다. 부축 장면은 손이 상완 부근에 보이며 체중 지지와 팔 연결을 완전히 증명하지 않는다. 선내에서도 RETURN TO SHIP 목표가 남아 있으므로 실제 구현은 탑승 후 목표를 갱신해야 한다. 손·벽 관통, 계단·경사 운반, 소수 인원 구조, 동기화·긴박감은 미검증이다. 이미지 승인 대기. 게임 코드·모델·애니메이션 변경 없음.

## SPACE-ART-21 — 장비 사용 전후 비교

[장비 비교 시트](../art/space-concepts/equipment-before-after-01.png)는 충격봉·압축가스 발사기·유인 신호기 각각의 사용 전후를 1인칭으로 비교한다. 기존 장비·1인칭 화면·LISTENER 행동 시트를 참고해 내장 이미지 도구로 제작했다. 생성 지시는 행마다 구도·장소를 유지하고 자세·거리·관심 방향 변화로 효과를 구별하며 PSX 재질과 직원·장비 외형을 유지하는 것이다.

| 장비 | 사용 전 → 후의 의도 | 한계·검증 대상 |
|---|---|---|
| 충격봉 | 근접 공격 준비 → 접촉으로 공격을 잠깐 중단 | 접근 위험·사용 후 빈틈·연속 경직 가능성 |
| 압축가스 발사기 | 생물이 통로 점유 → 뒤로 밀어 운반 틈 확보 | 사거리·가스 소모·벽 충돌·다른 물체 영향 |
| 유인 신호기 | 배송 경로 감시 → 신호기 방향으로 관심 전환 | 소리 감지·다른 소음과 경쟁·지속 시간 |

대상은 일반 LISTENER이며 STRIDER 처치나 모든 생물에 같은 효과를 보장하지 않는다. 영구 무력화가 아닌 배송·회피를 위한 일시적 기회라는 제안이다. 입력·수치·효과 시간·충전량은 미정이다. 신호기의 빛은 켜짐 표시이며 빛 자체에 유인된다는 규칙을 확정하지 않는다.

시각적으로 근접 접촉·밀침 자세·신호기 점등과 생물 방향 변화를 확인했다. 압축가스 장면은 효과 구름이 거리를 가리므로 밀침 크기의 근거가 아니다. 유인기 전후 위치·장비 세부와 동료의 화물 가림에 차이가 있어 정밀 연속 장면이나 운반 성공 증거로 쓰지 않는다. 실제 소리·가스·충돌·사거리·온라인 결과·협동 재미는 미검증이다. 사용자 이미지 승인 대기. 게임 코드·모델·애니메이션·오디오 변경 없음.

## SPACE-ART-22 — 첫 배송 연속 장면

[첫 배송 시트](../art/space-concepts/first-delivery-01.png)는 착륙·운반·대기·수령·단서·귀환을 연결한 1인칭 시안이다. 기존 1인칭, 화물·수령·단서, 우주선 시트를 참고해 내장 이미지 도구로 제작했다. 생성 지시는 같은 주황 직원의 손, 청록 동료, 밀봉 화물 NR-041과 PSX 화풍을 유지하고 화물 상태와 목표가 배송 이후 바뀌게 하는 것이다.

| 장면 | 의도 |
|---|---|
| ARRIVAL | 자동 착륙 후 우주선 경사로로 출발; 비행 조작 없음 |
| CARRY | 화물을 들고 굴곡진 통로의 표식을 따라 이동 |
| WAIT FOR IT | LISTENER가 지나갈 때까지 관찰·대기; 구매 장비 없이 가능한 해법 |
| ACCEPTED | 화물을 선반에 두고 수령 확인; 목표는 귀환으로 변경 |
| RECENT USE | 선택 사무실에서 새 영수증과 같은 코드의 옛 전표·사용 흔적 발견 |
| RETURN | 화물을 다시 가져오지 않고 우주선에서 동료 탑승·귀환 확인 |

두 직원의 정상 배송 예시이며 인원수·첫 근무의 필수 사건·고정 진행 순서를 확정하지 않는다. 단서 발견은 생략 가능하며 미스터리의 정체를 설명하지 않는다. 억제장치는 배송 후에도 소모되지만 정지·추격을 매번 강제하지 않는다. 새 구매 장비를 지급하거나 영수증 집기를 배송 성공 조건으로 추가하지 않는다.

시각 확인: 같은 코드와 주요 화물 외형, 운반 중 양손, 수령 후 귀환 목표, 새·옛 전표 연결을 확인했다. LISTENER의 후면·이동 방향은 완전히 명확하지 않으므로 실제 AI 동선 근거가 아니다. 귀환 장면의 동료 방향과 문턱 위치는 탑승 완료를 명확히 증명하지 않으며 실제 게임에서는 전원 선내 판정 뒤 확인한다. 사무실·선내의 배경 상자는 해당 배송 화물의 복제로 해석하지 않는다. 조명 변화만으로 억제장치 단계 판독을 검증하지 않았다. 실제 지도 연결·이동 시간·운반·수령·온라인·단서 이해·재미는 미검증이다. 사용자 이미지 승인 대기. 게임 코드·모델·애니메이션 변경 없음.

[1인칭 운반 실험 제작·실행 안내](carry-test.ko.md): Unity MCP·Windows 빌드·두 프로세스 검사 통과. 실행·연결 경로와 한계는 안내 참조.

## SPACE-ART-24 — CINDER DEPOT 전체 조감 구상

[전체 조감도](../art/space-concepts/cinder-depot-overhead-01.png) · [생성·수정 프롬프트](../art/space-concepts/cinder-depot-overhead-01.prompt.txt)

사용자 요청에 따라 개별 모듈 제작보다 전체 배치를 먼저 검토한다. 최근 환경 모듈 시트와 기존 배송지 배치도를 참고해, 내장 이미지 생성으로 위에서 내려다본 지붕 절개형 구상도를 제작했다. 01 우주선·귀환, 02 서쪽 보관 우회로, 03 중앙 분류장, 04 배송 수령소, 05 선택 사무실 단서, 06 동쪽 억제장치, 07 외곽 진입문을 표시한다. 청록 실선은 긴 차폐 우회로, 황토 점선은 일반 생물을 지나는 짧은 경로다. 두 경로는 같은 수령소에 합류한다. 청록 경로도 외곽 생물 진입 후 안전을 보장하지 않는다.

초안에서 불명확했던 동쪽 정비 통로·외곽 다리의 연결부를 추가 이미지 편집으로 보완했다. 구조와 색감은 이미지로 확인했지만, 출발부 화살표의 세부 연결·문턱 통과·정확한 운반 폭·모든 통로의 실제 이동 가능성은 미검증이다. 실제 맵 제작 시 평면 연결도를 다시 확인해야 한다. 바닥 얼룩 밀도 역시 실시간 화면에서 조정할 항목이다.

현재 32×44m 검증 맵의 정확한 재현이나 치수 도면이 아닌 배치 제안이다. 사진측량·메시·모델·게임 적용은 하지 않았다. 0.8.2 실행본과 기존 이미지를 보존한다. 전체 배치와 개별 모듈의 사용자 승인은 각각 대기 상태다. 문서는 한국어·영어로 갱신하고 링크를 검사했다.
