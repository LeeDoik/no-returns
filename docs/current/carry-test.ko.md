## 실행

[02_Play_Carry_Test.cmd](../../02_Play_Carry_Test.cmd)를 열고 HOST를 누른다. 같은 PC에서 [03_Join_Local_Carry_Test.cmd](../../03_Join_Local_Carry_Test.cmd)를 열면 참가한다. 실행본은 `builds/CarryTest/NoReturns.exe`이며 옆의 데이터 폴더를 함께 유지한다. 메뉴의 JOIN에는 다른 PC 방장의 LAN 주소를 입력할 수 있지만 이번 검증은 같은 PC의 두 프로세스다. TCP 27841 직접 접속이며 Steam 초대·인터넷 중계는 없다.

WASD 이동, 마우스 시점, E 들기/내려놓기, Space 빈손 점프, Esc 메뉴, R 방장 초기화. 메뉴에서 FOV를 조절한다. 각 창을 클릭한 뒤 조작한다. 방장이 종료되면 참가자는 연결 해제를 표시하며 자동 방장 이전은 없다. 참가자가 나가면 들고 있던 화물을 놓는다.

## 개발 환경과 빌드

Unity가 격리 계정으로 실행되어 사용자에게 보이지 않았던 문제를 사용자 계정 실행으로 해결했다. 보이지 않는 약관 창을 찾도록 안내한 이전 진단은 부정확했다. 한글 경로의 Mono 어셈블리 경로 변환 오류는 원본을 이동하지 않고 `C:/Users/LeeDoik/Documents/NoReturnsUnity` 연결 경로로 열어 해결했다. `tools/unity.ps1`과 `tools/unity_mcp.py`는 대상이 원본과 일치하는 연결 경로를 사용한다.

[CarryBuild.cs](../../NoReturns/Assets/_NoReturns/Editor/CarryBuild.cs)의 `NO RETURNS/Build Carry Test` 메뉴로 빌드한다. 로컬 `NoReturns/CarryWorkspace.txt`는 원본 작업 폴더를 지정하며 Git에서 제외한다. 셰이더 누락을 막기 위해 Resources/CarrySurface.mat를 빌드에 포함한다. 테스트 입력 `--test-dir`는 `CARRY_TEST_AUTOMATION` 또는 `UNITY_EDITOR`에서만 활성화된다. 현재 내부 빌드는 전자를 포함하므로 일반 출시용으로 배포하지 않는다.

## 2026-09-13 — 안내 언어 (0.3.1)

첫 실행은 한국어다. 시작 메뉴 또는 Esc 메뉴 아래의 **한국어 / English** 버튼으로 즉시 전환하며 다음 실행에도 유지된다. 각 플레이어의 로컬 설정으로, 동료에게 전파하지 않는다. 게임 원문은 영어로 유지하고 메뉴·조작·배송 목표·보수·접속 상태 및 오류 안내를 한국어로 번역한다. 배송 모드의 조작 안내는 R 초기화 대신 F 선내 행동을 표시한다.

[CarryLanguage.cs](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryLanguage.cs)의 영어 원문·한국어 대응 표를 함께 수정한다. Windows 맑은 고딕을 사용하며 다른 운영체제·글꼴 없는 환경은 미검증이다. 글꼴 파일을 프로젝트에 복사하거나 재배포하지 않는다. 설정은 PlayerPrefs의 NoReturns.Language에 저장하고 게임 지갑 저장과는 구분한다. 자동 검사 설정은 별도 테스트 키로 분리한다.

언어 검증: 두 Windows 프로세스 자동 검사 9개 통과(기본 한국어·한글 글꼴·독립 전환·재실행 유지). 창 캡처가 게임 화면을 안정적으로 가져오지 못해 실제 화면의 줄바꿈·버튼 가독성은 시각 검증 미완료로 남긴다.
