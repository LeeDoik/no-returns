# SPACE-PLAY-04 — 보급과 위험 계약 실험

[English](space-play-04.en.md)

현재 0.6.0부터 방장 진행 저장을 지원한다. 잔액·신호기 사용권·배송 성공 횟수를 복원하며, 근무는 우주선에서 다시 준비한다. 이전 절의 세션 전용·저장 미구현 표기는 0.5.0까지의 상태다. [저장 규칙과 검증](space-play-05.ko.md).

2026-09-13 · 검증용 제안값을 구현하는 단계다. 출시 경제 확정이나 영구 저장을 포함하지 않는다.

## 계획과 통과 조건

기존 리스너 실험에서 배송 → 귀환 → 구매 → 다음 근무의 장비 활용 → 위험 계약 선택을 연결한다. 운반·구조와 기존 실행 경로를 보존한다.

- B: 방장이 우주선의 준비 또는 정산 단계에서 120 CR로 신호기 사용권을 구매한다. 중복 구매·잔액 부족·참가자 구매는 거절한다. 사용권과 잔액은 세션 동안 유지한다.
- F: 기존 항로 선택과 도착. 도착할 때 구매한 신호기의 공용 횟수를 2회로 채운다. V: 빈손으로 8m 안 작업장 바닥을 바라보고 설치한다. 활성 장치는 1개이며 8초 동안 1초마다 12m 범위의 리스너에게 설치 위치의 소리를 전달한다. 벽·하늘·범위 밖·운반 중·다운 상태의 사용은 횟수를 소비하지 않는다.
- 작업장 범위는 x=-8~3, z=3~13, 바닥 높이 0.4m 이하, 위쪽 법선 0.65 이상이다. 임시 맵 전용 제한이다. 신호기는 임시 원기둥으로 표시한다. 정산 시 활성 신호를 종료한다.
- 첫 배송 성공 후, 우주선에서 항로를 선택한 상태에 방장이 T로 일반·위험 계약을 전환한다. 현장에서는 변경할 수 없다. 일반 배송·귀환 보수는 300+120 CR, 위험은 450+180 CR다. 새 근무는 일반 계약으로 돌아간다.
- 위험 계약은 같은 지역에서 순찰 1.8m/s, 조사 3.2m/s, 발걸음 감지 8m, 공격 예고 0.9초를 사용한다. 일반은 1.4m/s, 2.5m/s, 6m, 1.2초를 유지한다. 밀치기·구조·보상 보존 규칙은 유지한다.
- Esc 보급 패널에서 가격과 계약 보수를 확인한다. 모든 안내는 한국어 기본과 영어 전환을 제공한다. 방장이 구매·설치·계약·보수를 결정하고 두 프로세스로 복제한다.

## 구현 근거와 검증

[CarryMission](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryMission.cs), [CarryEquipment](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryEquipment.cs), [CarryRoom](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryRoom.cs), [CarryThreat](../../NoReturns/Assets/_NoReturns/Runtime/CarryLab/CarryThreat.cs)가 규칙 근거다. 빌드 0.5.0, 통신 규약 4.

자동 검사는 실제 두 실행파일의 배송·구매·설치 상태 일치와 거절 조건을 확인한다. 컴파일·규칙 검사와 실행파일 검사를 구분한다. 조작감, 소리의 전달력, 장비 가격, 위험 계약의 재미는 사람의 플레이 검증이 필요하다. 검증 결과는 작업 완료 시 기록한다.

실행: [리스너 실험](../../06_Play_Listener_Test.cmd), [동일 PC 참가](../../07_Join_Local_Listener.cmd). 영구 저장·실제 상점 아트·새 배송지·4인·억제장치는 포함하지 않는다.

- 실제 두 Windows 프로세스의 [진행 검사](../../artifacts/space-play-04/latest.json) 24개 통과. 정상 배송 후 빠른 귀환으로 420 CR 확보 → 120 CR 구매 → 300 CR 잔액 공유 → 위험 계약 → 참가자 신호기 설치·원격 유인·소멸까지 검증했다.
- 기존 [구조 검사](../../artifacts/space-play-03/latest.json) 21개, [언어 검사](../../artifacts/language/latest.json) 9개 통과. 숫자는 각 검사 범위이며 사람 평가 횟수가 아니다.
- 첫 진행 검사에서는 화물을 내려놓은 소리를 들은 크리처에게 느린 귀환 중 붙잡혔다. 보수 300 CR는 보존됐다. 게임 규칙을 완화하지 않고 검사 귀환 경로를 작업장 뒤쪽의 빠른 이동으로 변경했다. 이전 실패 실행 기록은 보존했다.
- 신호기에는 임시 공간 비프음과 맥동하는 원기둥을 적용했다. 이번 검사에서 전체 HUD·보급 패널 캡처와 실제 청취 평가는 완료하지 않았다. 자동 입력의 카메라 캡처 요청은 후속 이동 입력에 덮여 파일이 생성되지 않았으며 이미지 승인으로 처리하지 않는다.
