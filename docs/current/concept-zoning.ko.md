첨부 exec-c3d9d407-ad3f-4af5-8675-89221626a2b6.png를 직접 확인해 배치를 해석했다. 중앙 창고, 북쪽 사무실, 북동 수령소, 동쪽 설비동, 남쪽 보관동을 파랑 실내로 표시한다. 중앙 마당과 지름길은 야외, 서쪽 긴 동선은 지붕 통로, 녹색 점선은 억제 범위다. 원본의 inside 표기를 건물 내부로 단정하지 않는다. 실내 구획과 설비동·보관동 용도는 제안이며 실측 도면이 아니다.

건물 클릭 설명, 내부 구획 표시 전환, 동선 표시 전환, 억제 4단계, 한영 전환을 제공한다. 기존 플레이 지도는 보존하며 이번 산출물은 이동 게임이 아닌 인터랙티브 개념도다. Unity 변경 없음.

검증: 브라우저 렌더 확인, 내부 표시 및 억제 단계 버튼 동작 확인, 콘솔 오류 0건. 실제 치수·충돌·게임플레이·온라인은 미검증.
