# Cinder 방문 장부·부활·철수 — 0.9.23

[English](visit-settlement.en.md)

2026-10-05 · 구현 기준: 게임 0.9.23 / 프로토콜 14 / TCP 27842

## 구현한 범위

[통합 기획](coop-design-v1.ko.md)의 첫 구현 단계다. Cinder 일반 배송/위험 모드에만 새 방문 상태를 연결했다. 구형 실험실과 위험 없는 자동 동료 연습의 구조 동작은 유지한다. 새 게임 전체 기획의 완료를 뜻하지 않는다.

- 영수증을 회수하면 **420 CR**이 미정산 장부에 등록된다. 기존 300+120 총액을 보존하되 귀환 보너스 별도 지급을 없앴다. 반복 회수는 장부를 중복 증가시키지 않는다. 기존 팀 자금은 출발 정산 전까지 변하지 않는다.
- 선내 생존자가 단말기에서 탈락자를 선택하면 미정산 **100 CR**을 즉시 차감하고 **10초** 후 선내에서 부활한다. 잔액 부족/동시 진행/유효하지 않은 대상은 거절한다. 누구나 조작하고 한 명씩만 처리한다. 기존 팀 자금은 부활에 사용할 수 없다.
- 누구나 수동 출발을 시작/취소할 수 있다. **12초** 후 이륙 순간의 탑승 상태로 정산한다. 미수령 배송은 기존 두 번 누르기 확인을 유지한다. 밖에 남은 동료당 **100 CR** 공제, 지급 최저 **0 CR**. 전원 미탑승/유효한 부활 대상 없음은 **0 CR** 실패다.
- 진행 중인 부활은 마지막 생존자 탈락에도 계속되고, 출발 시 탑승자로 인정한다. 부활 비용과 복귀 비용을 같은 사람에게 중복 부과하지 않는다. 선내 다운자도 탑승자로 인정하며 낮은 체력으로 구조된다. 출발 후 직원들은 선내로 이동한다.
- 최대 체력 **100**, 현재 생물 타격 **60**. 첫 다운은 **45초** 안에 구조할 수 있고, 구조 후 **30** 체력·**4초** 보호. 두 번째 다운 또는 구조 시간 초과는 탈락이다. 기존 근접 구조 유지 시간 **2.5초**는 이번에 유지했다(기획 초기값 3초와 다름). 선내 부활은 체력과 다운 횟수를 초기화한다. 생존자의 체력은 다음 착륙에도 유지하며 다운 횟수만 초기화한다.
- 솔로는 착륙당 자가 소생 **2회**, 다운 후 **3초** 경과 뒤 사용 키를 **2초** 유지한다. 체력 **30**·보호 **4초**, 모두 소비한 뒤 다시 쓰러지면 현장 실패. 여러 명이 모두 다운되고 진행 중 부활이 없으면 실패한다.
- 방문 장부에는 **17분** 자동 출발 예고·**18분** 강제 출발 판정도 추가했다. 현재는 HUD 문구로 표시하며 정확한 남은 출발 시간은 노출하지 않는다. 방송·경적·엔진 연출과 안개/제어기 단계의 시간 재조정은 **미구현**이다. 기존 위험 단계 90/135/180초·외곽 진입 188초는 유지된다. 따라서 아직 15~20분 체류 균형이 검증된 게임이 아니다.

## 화면과 사용

우주선 안에서 사용 키(기본 E)로 단말기를 연다. 착륙 중 오른쪽은 직원별 부활 버튼, 비용 부족/부활 진행 안내다. 왼쪽은 탑승 인원·기존 자금·미정산 보상·출발/취소. 귀환 뒤에는 총보상·부활 공제·복귀 공제·실제 지급액을 보여준다. 일반 HUD에 체력과 미정산 보상을 추가하고 탈락/구조 대기 상태를 구분한다. 한영 문구를 함께 제공한다. 자동 동료 연습은 배송/탈락/유료 부활 검증용이 아니다.

## 검증과 한계

검사 결과는 [기록](../validation/visit-settlement-0.9.23.json)에 둔다. 초기 구조 검사에서 참가자 접속 직후 비어 있는 방문 스냅샷을 HUD가 읽어 예외가 났다. 유효한 배열이 있는지 검사하도록 수정한 뒤 재검사했다. 연속 클라이언트 실행의 TCP 포트 종료 대기도 발생했으며 사용 중인 세션을 강제 종료하지 않고 기다렸다.

이번은 기존 한 건 배송의 규칙 통합이다. 여러 계약/구역 보너스/장비 5종/치료품/카트/끌기/관전/음성/선박 침입은 아직 기획 상태다. 소모품 복원 규칙은 새 개인 소지품 시스템과 함께 후속 구현한다. 기존 공유 신호기와 구매 권한/수량은 그대로다. Cinder 진행은 여전히 세션 메모리이며 저장·중도 복원·재접속·세이브 이행은 미구현이다. 참가자 연결 종료 시 기존 현장 실패 처리도 유지한다. 사람이 테스트한 조작감·화면 가독성·재미, 18분 실제 자동 출발, Windows/LAN/성능은 미확인이다.

Unity 6000.6.4f1 정식판, CLI 1.0.0-beta.12, Pipeline 0.8.0-exp.1은 공식 CLI 조회에서 최신으로 확인했다. 최초 Editor 연결이 종료되어 재연결한 뒤 검사했다. 모델·재질·Blender는 수정하지 않았다. 수동 플레이 창은 열지 않았다.
